## RSI で書くとこうなります（値は例です。本当の値は T-2・T-3 で資料から写します）

**② 指標の記録（RSI が何か）**
- 計算の関数：_rsi。出力：1本
- パラメータの軸：期間（意味＝窓・種類＝本数・範囲＝2〜21・代表の値＝スキャル／デイトレ）
- 値の単位：0〜100
- 教科書の役割：行き過ぎ・勢い（複数持てる）
- 確定に要る本数・未来を使わない作りか
- オン／オフ

**③ 使い方の記録（RSI をどう使うか）**
- RSI × 入る合図：向き＝上側（ショート）・閾値＝値の形で 70・時間足＝5分足
- RSI × 出口の反転：向き＝下へ抜ける・閾値＝50
- RSI × 場面の判定：パラメータを長めにする（法則 C8）・閾値＝分位の形

③に値が書いていない要素は、②の値を使います。例えば、パラメータの代表の値を③に書かなければ、②の「スキャルなら◯」を使います。こうすると、ふだんは②の1か所を直せば全部の使い方に届きます。使い方ごとに変えたいときだけ、③に書きます（決定①＝代表の値は使い方ごとに持ってよい）。

## 足す・消す・止めるは、こう動きます

| やりたいこと | 直す所 |
|---|---|
| 新しい指標を足す | ②に1件足す（計算の関数はコードに置き、記録が名前で指す） |
| 指標を止める | ②のオン／オフ。その指標の使い方は、全部止まる（要件 :86） |
| ある使い方だけ止める | ③のオン／オフ（例：RSI を入口には使い、場面の判定には使わない） |
| 新しい種類の要素を足す（例：使える期間） | ①に1行足す。②③の全部の記録に欄ができ、値は「未設定」から始まる |
| 要素の種類を止める | ①のオン／オフ。読む口（indicators.py）が、その要素を返さなくなる |
| 値を直す（教科書の誤りなど） | ②か③の1か所。読む口を通る全部のプログラムに、次の走行から届く（要件 :95〜96） |

あわせて、値の1つずつに出どころ（教科書の URL・決定の日）を持たせます。教科書が誤っていたとき、どの値を直すかを探せるようにするためです（要件 :93）。

①の表には、要素ごとの「形の決まり」も書きます（例：閾値は「値・分位・前提つき」のどれか）。読む口は、決まりに合わない値を止めます。
