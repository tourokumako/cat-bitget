**この理由を、5列すべての「流儀」の欄に書きました**（次に読む人が同じ所で悩まないため）。

## §12 ★このセッションで足した「やり方」（前の13に足す）

14. **ライブラリの関数は、ソースの1行1行を教科書の式と突き合わせる。**特に **`sin`/`cos` に入れている数字が「度」か「ラジアン」か**を見る。名前と説明では分からない（`ebsw` の実例）。
15. **「同じ形の指標の本数違い」は、スピアマン相関（順位）で判定する。**定数倍でも相関 0.999 でもなく、**順位が完全に一致するかどうか**が「『値 ≥ 閾値』の条件として同じ」の判定基準（`dsp`・`cdl_z` の終値の実例）。
16. **0/1 の列を足すときは、その 0/1 が「構造」か「閾値」かを分ける。**構造（包み足・内側バー＝4本値の関係だけ）は入れる。**閾値（十字線＝実体が平均値幅の10%以下）は入れない＝中身の連続値を入れる**（教訓 L-408）。
17. **既知答えは、定義で枝が決まるときだけ使う。**実部も虚部も 0 になるような場合は、実測が毎回 同じでも使わない（小数の丸めの符号で決まっているだけ）。
