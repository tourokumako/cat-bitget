## 確かめられなかった物と、その理由

1. **web.archive.org。** 多くの担当で接続が切れて開けませんでした。MACDヒスト%・EMA傾き・MMI の担当では、Claude Code の自動の判定が確認の実行を拒否したため、回り込まず、開いていません。開けなかったページは、確かめの強さを「未確認」にして、`探した記録` に HTTP の番号を残しています。
2. **HWC幅%とHWC位置は、使い方の記録を空にしました。** HWC（Holt-Winters Channel）について使い方を書いた文が見つかりませんでした。「見つからなかった」だけの行を置くと、読む口が「どの場面でも使える候補」と読むおそれがあるため、行を置いていません。TradingView の「Holt-Winters Forecast Bands」は式の違う別の指標なので、混ぜていません。
3. **403 や 404 で開けなかったページ。** Fidelity・Barchart・traders.com・nexusfi・TradersUnion・atrindicator.com・quantvps（429）ほか。前の調べの引用は、確かめの強さを「未確認」にして残しました。新しい文としては使っていません。
4. **Chromium が開けなかったページ。** MQL5（Chromium だけ404）、pandas-ta の配布物（zip）、LuxAlgo の折りたたみの中の FAQ。curl か DOM の本文で逐語を確かめ、注記に理由を書きました。
5. **中心線・遅れの長さ・先行か遅行か。** 上の表の「見つからなかった指標」は、文を探しても書いた文が見つかりませんでした。
6. **指標データとの食い違い。** realized_vol（教科書は年率、指標データは年率にしない）・Donchian幅（指標データは終値で割る%、LuxAlgo の既定は中心線で割る形）ほか。消さずに候補に並べ、注記に書きました。どちらが正しいかは書いていません。
