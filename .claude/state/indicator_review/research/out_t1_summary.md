## 取り込みの前に確かめてほしいこと（形の揺れ）

1. **使い方の閾値の「既定」の箱。** 足もスタイルも名指ししない閾値を、ADX・DI差・CHOP・ER は使い方の `閾値` に足した `既定` の箱に入れた（依頼書の決まり 3 に沿う）。ほかの 16 種は、見本の出口の行と同じく `スキャル` に入れて注に「名指しは無い」と書いたか、`閾値の範囲の文` に置いた。読み込みのテストで `既定` の鍵が通るかを確かめ、どちらにそろえるかを決めてほしい。
2. **使い方の `パラメータの代表の値` の `既定` の枠。** CCI（Woodies の CCI14 と CCI6 の組）で使った。見本は `スキャル` の枠だけ。
3. **単位が null の指標。** 選べる語に当たらない単位は null にした。対象は CCI・CMF（−1〜+1）・AROONOSC（−100〜+100）・HT_DCPHASE（度）・ER（0〜1）・EFI比・EOM比・BB%b。
4. **DPO% と DPO教科書% の分け方。** 指標データの計算の形が違うので、それぞれの行には、その形を書いた出どころの文だけを置いた。前の調べの DPO% の行に在った文の一部は、DPO教科書% の行へ移した。DPO% の `_注` には、pandas-ta-classic の版によって DPO% の形が変わりうることを書いた。
5. **指標データと食い違う値。** 消さずに候補に並べ、注に書いた。
