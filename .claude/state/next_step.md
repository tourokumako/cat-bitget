# §6 やってはいけないこと（★2026-08-08 に3件 追加）

1. **★案を「くじ引き」で作らない（L-408・インシデント #14）。** 条件どうしが法則でつながっていない案は作らない。
2. **★探す値を「点の一覧」で先に限定しない（L-392・L-408）。** 数字は範囲で探す。本当に選択肢のもの（玉の持ち方など）だけメニューでよい。
3. **★検索結果の要約で設計を書かない（L-409）。** 記事本文を開いて逐語を取る。出典が食い違ったら両方 記録して範囲にする。
4. 「まこさんの判断待ち」を「やらない理由」に変換しない（L-403）。根拠を揃えて案を出す。
5. 設計は正本の網羅一覧との全数照合から始める（L-404）。設計の1行目に「何が正本の網羅一覧か」を書く。
6. 自分で合格の条件を引いて自分で満たして「完了」と言わない（L-400）。
7. **「表現できること」を完了の条件にしない。** V9 が組めることは通過点であって、道具の価値ではない（まこさん 2026-08-08）。
8. 承認をもらうときに都合の悪い事実を落とさない。**「入れないもの」を毎回 再掲する。**
9. 作ったものを人が読む形で必ず1本 見る。
10. 報告を小さく縮めない。謝るべきときは説明より先に謝る。
11. 正本に書いてある語でも、説明なしにチャットで使わない（L-405）。**私が作った造語を使わない**（例＝「打ち消す条件」→ 正しくは「ふるい」）。
12. 恒等の一致だけで「書き写せた」と言わない。番人 pass だけで「守られている」と思わない。
13. 採点窓 2026-03〜06 を探索や選定に使わない。
