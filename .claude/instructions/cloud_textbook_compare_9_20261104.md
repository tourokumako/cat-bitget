# 依頼書｜9種の指標の教科書の調べと、指標データを照らす（クラウドのセッション用）

## この作業の目的

engine_tuner は、指標データの役割・パラメータ・閾値を使って条件を組みます。engine_tuner を、まず9種の指標で最後まで通します。9種の値を指標データに埋める工事が、ToDo の222番です。

教科書の調べは、もう終わっています。ただし、調べの結果と指標データを、欄ごとに照らした表はありません。

この作業は、222番の材料として、その表を作ります。

**この作業は、値を決めません。データもプログラムも直しません。** 「どの欄の値が、どの教科書の文と合うか」だけを書きます。値を決めるのは、222番の設計書と監査です。

## 確認の質問をしない

この作業を頼んだ人は、質問に答えられません。確認の質問をせず、最後まで進めます。

- 始めるときに、`git ls-remote origin research/textbook-compare-222` でブランチが在るかを確かめます。在れば、そのブランチの続きから始めます。
- 始めた時刻と終えた時刻を `date -u` で測ります。
- 会話の記録が要約に置き換わったときは、この依頼書の「守ること」と「出す物」を読み直します。

## 照らす欄

| 記録 | 欄の番号と名前 |

②-2 と ④-3 は、`式の文` が指す関数の本体を `SDK/scripts/priority_rebuild/observe_diag.py` で読み、教科書の式と照らします。

## やること

1. 上の欄の1つごとに、下の形で1行を書きます。合う欄も書きます。
2. 判定は、次の6つの語のどれかにします。ほかの語を使いません。

| 判定 | 意味 |
|---|---|
| 合う | 指標データの値が、調べの結果の逐語に書いてある値と同じ |
| 違う | 指標データの値が、調べの結果の逐語に書いてある値と違う |
| 教科書に無い | 指標データに値が在り、調べの結果に当たる文が無い |
| 指標データが空 | 調べの結果に文が在り、指標データの欄が空（null・空の配列・「まだ決めていない」） |
| 指標データに欄が無い | 指標データの記録に、その欄の鍵が無い |
| 両方に無い | 指標データも調べの結果も、値を持たない |

3. 調べの結果の値のうち、1通りの条件で使えそうな文を読み、指標データに行が無い使い方を挙げます。例＝教科書にレンジのショートの入る合図が書いてあるのに、使い方の記録に行が無いとき。使えそうかどうかは、逐語に書いてある語だけで判断します。
4. 調べの結果どうしで値が違うときは、片方に決めず、「調べの結果どうしの違い」に両方を書きます。
5. 逐語を読み、逐語が指す値と、調べの結果に書いた値が合わないときは、「逐語と値が合わない」に書きます。
6. スキャルの値は、調べの結果の「時間足」の欄だけで判断しません。逐語を読み、逐語に書いてある足をそのまま写します。「書いてない」が多いことが分かっています。足が書いてなければ「時間足は書いてない」と書きます。

9種の文書の「いまの値と違う所」は、前の版の指標データと照らした文です。今回の照らしの結果として写しません。

## 守ること

1. データ・プログラム・文書を直しません。作ってよいのは、下の「出す物」の2本だけです。
2. 値を決めません。代表の値と範囲を提案しません。どちらが正しいかを書きません。
3. Web のページを開きません。新しく調べません。調べの結果に無いことは「教科書に無い」と書きます。
4. 調べの結果の中で、確かめの強さが「見つからなかった」の行は、値の根拠にしません。
5. 逐語・URL・指標データの値を、1文字も変えずに写します。
6. 全部の欄を、1件ずつ実物で読みます。要約や、ほかの文書の説明から書きません。
7. 乱数を使いません。
8. engine_tuner・G2・H2・材料の検査を走らせません。5分足のデータがこの環境に無いので、走らせても止まります。
9. hook に止められたら、回り込まず、止まった文を結果に書いて作業を終えます。
10. 短いスクリプトと途中の出力は、リポジトリの外の一時フォルダに置きます。

      "判定": "",

欄の名前を変えません。無いものは空の配列にします。`使い方の行` は、使い方の記録の行のときだけ、配列の何番目か（0 から数える）を書きます。

**2. `out_textbook_compare_222.md`** は、人が読むまとめです。次の順に、結論を先に書きます。

1. 判定ごとの件数と、指標ごとの件数の表。
2. 「違う」の一覧。指標ごとに、指標データの値と教科書の値と逐語を並べます。
3. 「指標データが空」と「指標データに欄が無い」の一覧。
4. 指標データに行が無い使い方の一覧。
5. 調べの結果どうしの違いの一覧。
6. 逐語と値が合わない物の一覧。
7. 確かめられなかった物と、その理由。
8. 始めた時刻と終えた時刻。

コミットとプッシュは、次の順に行います。

1. `jq` で JSON が読めることを確かめます。
2. `行` の数が「件数」の合計と同じことを確かめます。
3. 2本をコミットし、`research/textbook-compare-222` へプッシュします。プッシュが失敗したら、1回だけやり直します。master へは入れません。
