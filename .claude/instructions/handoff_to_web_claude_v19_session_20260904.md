## 1｜何をやろうとして、どこで終えたか

### 1.1 目的（まこさんの完成の条件・逐語 2026-09-03）

> 設計書通りに実装ができる強制ができたら完了だけど。完成のゴールは監査OKではない
> ただし、お前が検査すると絶対不正を働くので、監査に出す
> よって監査が設計書通りに実装ができる強制ができたと判断するまで修正する

### 1.2 完成の定義は、途中で1回 変わりました（まこさん決定 2026-09-04・逐語）

> **完成の定義は「止まるか、記録に残る」。塞ぎ切ることではない。**

**＝「迂回の道を全部 塞ぐ」から、「止めるか、止まらなかったことが記録に残る」へ変わりました。**外の基準では、予防（preventive control）と検知（detective control）を並べる考え方に当たります（NIST CSF の Protect と Detect）。

### 1.3 どこで終えたか

**cp19（2026-09-04）で終了。**判定は **CONDITIONAL-GO**。

| | 中身 |
|---|---|
| まこさんが指名した3件（J-1・J-2・J-3） | **3件とも「直っている」**（監査の判定） |
| cp18 が素通りさせた17通り | **17通りとも止まった**（rc=2・監査が測り直した） |
| 壊し方の記録23本 | **1本の食い違いもなく本物だった**（監査が2者で測り直した） |
| 条件 | **監査が新しく作った15通りが、15通りとも素通りした**（rc=0）。**しかも止まらなかったことは記録にも残らない** |

**監査の逐語**＝「この15通りを『閉じない部分』として確定し、戦略側へ戻るなら、ここで終わりにできます（GO）。」
**まこさんは、その道を選ばれました。**
