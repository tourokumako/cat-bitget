# 依頼書｜9種の指標を教科書で確かめて1本の文書にする（クラウドのセッション用）

## この作業の目的

engine_tuner は、指標の役割・パラメータ・閾値を、教科書を出どころにして使います。engine_tuner を、まず9種の指標で最後まで通します（まこさんの決定 2026-11-02）。その9種の記録を埋める工事が、ToDo の222番です。

いま、9種の教科書の確かめは足りていません。

- RSI・BB幅・BB%b・ATR%・基準線の役割は、ページの語の数を数えただけです。
- 包み足は、資料の表に行がありません。
- どの指標にも、閾値の範囲の値がありません。

この作業は、222番の材料を作ります。値は決めません。値を決めるのは、222番の設計書と監査です。この作業は、「どのページに何と書いてあるか」だけを文書にします。

- 先に通す条件は、レンジの場面・スキャル・ショートです（まこさんの決定 2026-11-02）。
- 銘柄は BTC で、売買の足は5分足です。

## やること

次の9種について、Q1〜Q4 に教科書で答えます。

| 指標 | 調べる相手 | いまのパラメータの範囲 | いまの代表の値（スキャル／デイトレ） |
|---|---|---|---|
| RSI | RSI | n＝2〜21 | 7／14 |
| ADX | ADX | n＝7〜21 | 14／7 |
| DI差 | +DI と −DI（DMI） | n＝7〜21 | 14／14 |
| BB幅 | Bollinger BandWidth | n＝10〜50、s＝1.9〜2.1 | 20／20、2／2 |
| BB%b | Bollinger %B | n＝10〜50、s＝1.9〜2.1 | 20／20、2／2 |
| ATR% | ATR と、ATR を価格で割った形 | n＝5〜21 | 14／14 |
| 基準線 | 一目均衡表の基準線 | k＝13〜26 | まだ決めていない |
| 包み足 | ローソク足の包み足（Engulfing） | 無い | 無い |
| 帯pivot | ピボットの R1 と S1（前の期間から作る線） | 下の注を見てください | まだ決めていない |

帯pivot は、指標を組み合わせて作った部品です。教科書に同じ名前はありません。そのため、元のピボットの R1 と S1 を調べます。

| 番号 | 問い | 分かると何に使うか |
|---|---|---|
| Q1 | その指標は、相場の何を見ているか。向き・強さ・勢い・行き過ぎ・値動きの幅・出来高・位置のどれに当たるか | 役割の記録 |
| Q2 | レンジの相場で、どう使うと書いてあるか。ショートでは、値のどちら側を使うと書いてあるか。書いてなければ「書いてない」と書く | 使い方の記録 |
| Q3 | パラメータの既定の値は何か。短い時間足やスキャル向けの値、デイトレ向けの値、値の範囲は書いてあるか | 代表の値と範囲 |
| Q4 | 閾値は何か（例＝RSI の 70 と 30）。閾値の形は、値・分位・回数・倍率・前提つきのどれか。短い時間足向けの値と、値の範囲は書いてあるか。閾値を持たない指標は「持たない」と書く | 閾値の代表の値と範囲 |

包み足は、Q1〜Q4 に加えて、形の条件（どの足とどの足をどう比べるか）を書きます。帯pivot は、Q1〜Q4 に加えて、R1 と S1 の式と、どの期間（前日・前週など）から作るかを書きます。

## 調べる相手

- 開発者の原典と、定番の教育サイトを使います。どれを使ったかを、1件ごとに書きます。
- 1つのサイトにしか無い値でも、書いてかまいません。そのことを書き添えます。
- 2つ以上の出どころの値が違うときは、片方に決めず、両方を書きます。
- BTC や暗号資産の5分足について書いた資料が在れば、別に分けて書きます。一般の資料と混ぜません。

## 守ること

1. ページの本文を開いて、1つの値ごとに逐語と URL を残します。検索結果の要約だけで書きません。
2. 1つの値ごとに、確かめの強さを書きます。「ページの文で確かめた」「見つからなかった」のどちらかです。語の数を数えただけのものを、確かめたと書きません。
3. 書いてないことは「書いてない」と書きます。推測で埋めません。
4. その値が、どの時間足の話かを書きます。日足の話なら、日足と書きます。書いてなければ「時間足は書いてない」と書きます。
5. 代表の値と範囲を、提案しません。この作業は事実だけを書きます。
6. 乱数を使いません。プログラムを走らせる必要もありません。
7. このリポジトリのほかのファイルを直しません。とくに次のファイルに触りません。
   - v3-bitget-api-sdk/bitget-python-sdk-api/scripts/ の下の全部
   - v3-bitget-api-sdk/bitget-python-sdk-api/config/ の下の全部
   - .claude/state/ の下の全部
8. hook が止めたら、回り込まずに、止まった文を書いて作業を終えます。
