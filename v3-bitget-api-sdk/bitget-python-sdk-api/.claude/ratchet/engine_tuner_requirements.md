#### R3 をどう作るか（設計・まこさんの承認待ち）

**考え方＝条件を1個のデータとして表し、それを組み立てる。** いまは「列に閾値を当てて上か下か」という形が実装に直接書かれている。この形を外に出して、探索が形そのものを選べるようにする。

**条件1つ＝役割・形・材料・側・値 の5つで表す。**（役割の追加＝CP2 監査 4-2 への対応・2026-07-30）

- 役割 … 環境認識・引き金・十分性・位置 の4区分。構成の規則＝引き金はちょうど1本・環境認識と十分性は上限つき（引き金ゼロの発火しない組み合わせを形式の段階で禁止する）

- 形 … 下の表の左列にある書き方のどれか

- 材料 … 列1本、または列2本。ファミリー×期間×時間足の3軸で選ぶ。期間やσ倍率などのパラメータ＝感度は、カタログに在る変種から選ぶ離散の軸にする。同じファミリーの期間違いは隣接として結び、探索が1段ずつ動かせるようにする（CP2 監査 4-1・4-3）

- 側 … 上か下か

- 値 … 閾値、遡る本数、許容幅。閾値＝境界線はここに残し、**範囲で探す**（範囲の上下は値決め窓の分布から決める・パラメータとの書き分け＝KB §1.1／§1.2）

**持たせる形の一覧（出どころ＝材料C の照らし合わせ・V9 はその実例の1つであって到達目標ではない）**

| 傾き | 列のN本前との差 | 無い |

**条件のつなぎ方を3つ持つ。** 全部満たす／どれか満たす／ある条件が成立したときだけ別の条件を要求する入れ子。いまは全部満たすの1つだけ。

**条件の本数そのものを、探索が動かす対象にする。** いまは2個まで。実際に稼いでいるロジック（V9）は P3 が4本・P22 が7本・P4 が9本を重ねている。**★役割（スキャル・デイトレ）で本数を決め打ちしない**（まこさん指示 2026-08-08・逐語＝『スキャルは条件減らしてトレード数を増やすといったチューニングができるようにしたい』＋『一般論であり、中にはスキャルだが条件が多いほうが良い場合もあるかもしれないので、戦略によって条件を分けるということではなく、柔軟にチューニングするということ』）。本数を増やすと1本あたりの精度は上がり件数/日 は減る、という関係が機械出力で出ること。

**方向ごとの共通の事前フィルタを持つ。** 全部の条件の前に置く足切り。いまは無い。

**欠損の扱いを条件ごとに選べるようにする。** いまは欠損なら不成立で固定。通す側を選べる形もある。

**指標と窓の適合の制約を持つ。** その列の有効な標本数が値決め窓の中で下限以上か、を生成の段階で機械検査する。下限の値はまこさん（CP2 監査 4-4・例＝122日の窓に日足50本平均は独立区間が2つしか取れない）。

#### ⑧ 多重検定の補正の適用条件（③ を名前だけで終わらせないため）


**③ は「DSR と PBO を使う」と書いてあるだけで、適用の条件が1つも書かれていなかった（監査 NO-GO 条件4）。**道具は archive/dsr_pbo にある。式は Bailey & López de Prado。実装を読んで確かめた条件を下に書く。

**(b) 試行数 N は「有効試行数」にする。** 生の試行回数ではない。全試行の日次収益系列をクラスタにまとめ、そのクラスタ数を N_eff とする（López de Prado & Lewis 2019 の ONC）。**さらに過去セッションの累積を足す。** 同じ値決め窓に対して過去に行った探索は全部 N に入る。累積カウンタのファイルを1本置き、engine_tuner が起動のたびに加算する。これが無いと DSR>0.95 は形式的な合格にしかならない。

**(c) 分散 V はランダムサーチの試行からだけ推定する。** DSR の SR0 は「試した全戦略の Sharpe の分散」を使う。Optuna の TPE は良い領域に試行を集めるので分散が縮み、**縮んだ分だけ DSR が過大に出る**。だから統計判定の土台になる分散は、独立にサンプリングした段（ランダムサーチ）からだけ取る。

**(d) PBO には全試行を渡さない。** 入力は (期間 T × 戦略 N) の行列で、C(10,5)=252 通り × N の Sharpe を内側のループで回す。N が数万だと数十分かかる。**重複を除いた候補集合（クラスタの代表）を渡す。**統計的にも N ≫ T は不健全で、T=122 に対し N が数万だと最良はほぼ確実にノイズになる。

**(e) 「最良を1つだけ選ばない」（④）を統計で裏づけるのは偽発見率の制御だけ。** DSR と PBO は「この1本が本物か」を見る道具で、「複数を残してよいか」には答えない。段の最後に BH 法かRomano-Wolf の段階的な検定を足す。
