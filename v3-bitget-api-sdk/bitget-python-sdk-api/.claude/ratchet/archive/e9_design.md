## 1. 目的・スコープ

### 1.1 目的
P23（下げトレンドの戻り売り SHORT）の手動ロジック（V9 Entry/Exit）を土台に、**入口の条件（どの指標値で入るか）と出口の条件（利確幅/損切り/保有時間の"値"をどう置くか）を一緒に動かして、往復の純益（net）が最大になる組合せを木に学習させる**。連続モード(cap0.12遵守)の NET が地面 **$925.73** を超えるか（伸びしろの存在証明）を検証する。

### 1.2 まこさんの定義（逐語・縮めない）
入口の条件（gap/ADX/ATR%/bb傾き/stoch/MTF の切れ目）と、出口の条件（利確幅/損切り/保有時間を**どう置くか＝値**）を、一緒に動かして、往復netが最大になる組合せを木に学習させる。

### 1.3 スコープ外（やらない・明記）
add のサイジング最適化（E9 の後）／ トレーリング・分割利確（gen._step 改造が要る＝import-only違反）／ 多 Priority 展開（P23 が最初の1つ）。

### 1.4 禁止（過去失敗の再演防止）
θ足切り（E8c）／ 出口を先に1つ固定（E8c StaleOff）／ **出口を離散プリセットから選ぶ**（E9旧§10.16の矮小化）／ 勝率・○×・「伸びるか」ラベル（E4/E6/E8a）／ net金額二値のボラ依存（E8b第1回）。

## 4. 特徴量 X ＝ 入口指標 ⊕ 出口値

### 4.1 入口指標（方向 regime 系・軸1/H15・E8b build_multiperiod + build_mtf 流用）
- 複数期間: stoch_k/d/gap[5,9,14]・adx[7,14,21]・bb_slope_pct/bb_pctb[10,20,40]・rsi/rsi_slope[7,14,21]・ret_5。
- MTF: 15m/30m/1h/4h（backward merge・leak-safe）。
- 時間: entry_hour / entry_weekday。
- **atr_pct（ATR%）は入れる**（まこさんの定義・学習後 vol_share で方向主役化を監視＝§4.3-e 確定 2026-06-08）。
- **bb_width_pct（バンド幅＝ボラ・エネルギーの溜まり/放出）も入れる**[10,20,40]（まこさん 2026-06-08・ATR%と同じ vol_share 監視・使い方は §4.3-g）。bb_slope_pct（傾き＝方向）も入れる。

### 4.2 出口値（★連続・プリセットでない・木に渡す）
`x_tp_pct`（利確幅）／ `x_sl_pct`（損切り%）／ `x_time_exit`（保有時間・分）。第1ラウンドの主軸はこの3連続値（失速/downF は V9既定で固定）。

### 4.3 Entry側で学習する内容（★詳細・誤魔化す余地をなくす）

**(a) 候補の型（残す・学習対象外）**: P23 の型＝stoch デッドクロス（k>d が2バー続いた後に k<d・クロス幅 d−k）＋陰線（close≤open）。出典 `cat_v9_decider.py` L469-484。`gen._p23_type_fires` が判定。**V9の固定閾値（gap0.3 / ADX30-50 / ATR150 / bb傾き−10）は外して候補を広げる**（型だけで発火＝61,111本）。型そのものは ML で変えない。

**(b) 学習する入口の閾値（V9手書き値 → 木が net最大の split で置換）**: V9 が人手で決めた固定閾値を、木の分岐が net 最大になるよう学習する：

| V9手書き閾値 | V9値 | 木が学習に使う特徴量（複数期間） |
|---|---|---|
| stoch クロス幅 | gap 0.3 | stoch_gap[5,9,14] |
| ADX 下限/上限 | 30 / 50 | adx[7,14,21] |
| bb傾き 上限 | −10 | bb_slope_pct[10,20,40] |
| stoch 位置（戻りの高さ） | — | stoch_k/d[5,9,14] / bb_pctb[10,20,40] |
| モメンタム | — | rsi/rsi_slope[7,14,21] / ret_5 |

→ 木は「ADX>X かつ bb傾き<Y かつ stoch_gap>Z … なら net 高い」という指標の切れ目（AND）を学習する。これが「入口の条件＝どの指標値で入るか」。

**(c) 学習する入口の指標期間（V9固定期間 → 木が有効期間を選ぶ）**: 各指標を複数期間で渡し、feature importance で有効な期間を木が選ぶ（stoch 5/9/14・adx 7/14/21・bb 10/20/40・rsi 7/14/21）。V9 の固定期間に縛らない。

**(d) MTF（V9に無い・足す）**: 15m/30m/1h/4h の上記 regime 系（上位足の下げ揃いを木が学ぶ・leak-safe backward merge）。

**(e) ★ATR%（ボラ）の扱い — 論点・誤魔化さず明記（要まこさん確定）**:
- **まこさんの定義は「入口の条件に ATR%」を含む**（gap/ADX/**ATR%**/bb傾き/stoch/MTF）。
- だが **H15（軸1ボラ逃げ）は「ボラ系を方向スコアの主役にしない」**（E8b第1回で atr が支配してボラ逃げ→破棄。E8c は atr を完全除外して vol_share=0）。
- ＝**まこさんの定義（ATR%入口）と H15（ボラ除外）が衝突している**。CC が勝手にどちらか（除外 or 採用）に決めると、また矮小化 or ボラ逃げになる。
- **確定（2026-06-08 まこさん「入れてチェックでいい」）＝「入れて監視」**: ATR%（atr_pct）を入口特徴量に**入れる**（まこさんの定義通り）。学習後に vol_share（＝AIが入口を決める時、荒さ系をどれくらい頼りにしたかの割合）で「ATR% が方向判断の主役になっていないか」を確認（H15①）。主役なら設計見直し（ボラ逃げ再演）、脇役なら採用。
- **bb_width_pct（バンド幅）も ATR%と同じく入れて監視**（まこさん 2026-06-08・使い方は §4.3-g）。bb_slope_pct（傾き＝方向）は入れる。

**(f) 入口条件＝予測往復net>0（θ足切りでない）**: 木が (入口指標 ⊕ 出口値) → net を学習。各入口で最適出口値での予測 net が >0 になる指標値の組合せが「入る条件」＝木が学習した指標の切れ目。確率θで上位N%を選ぶ（足切り）のではない。

**(g) bb_width_pct（バンド幅）の使い方 ＝ エネルギーの溜まり/放出（方向は示さない・まこさん共有資料 2026-06-08）**:
- bb_width は「上か下か（方向）」でなく「エネルギーが溜まっている（スクイーズ＝低水準）か、放出されている（拡大）か」を示す。
- ショートの王道＝**スクイーズ（低水準）→拡大に転じる＋ローソクが−2σを下抜け → 強い下落（バンドウォーク）の入口**。もう1つ＝bb_width がピークから収縮＋上バンド反転 → 過熱反転のショート。
- bb_width 単独は方向を示さないので、**木が bb_pctb（バンド内位置＝−2σ付近か）・bb_slope_pct（方向）・stoch と組み合わせて「エネルギー拡大 × 下抜け」を AND で学習**する（E9 は指標の組合せを net最大で学ぶ設計なので、この使い方がそのまま学習対象になる）。複数期間 [10,20,40] で渡し、木が有効期間を選ぶ。
- vol_share 監視（bb_width 単独がボラ逃げで方向の主役にならないか・H15）。

## 8. 推論 ＝ 各入口に最適な出口値を選ぶ（足切りなし）
```
出口値グリッド G = {利確の N1点} × {損切りの N2点} × {保有時間の N3点}   # §5範囲を細かく離散化
for 型バー i:
    x_in = 入口特徴量(i)
    for g in G: pred_net[i,g] = model.predict(x_in ⊕ g)   # sim でなく predict（軽い）
    g*(i)        = argmax_g pred_net[i,g]                   # この入口に最適な出口値
    pred_best[i] = max_g pred_net[i,g]
入る集合 = { i : pred_best[i] > 0 }     # 予測往復net>0（コスト勝ち・θ確率でない・木が学習した指標の切れ目）
出口値 by bar = { i : g*(i) }
```
グリッド解像度 N1×N2×N3 は実装時に決定（predict は軽いので密にできる）。

### 8.1 結果の出し方（★AI が何を学習したかをまこさんが確認できる形）

**Entry側＝学習した「指標 × 閾値」の組み合わせ**:
- 木の分岐（split）を集計し、「**どの指標を、どの値で切ると net が高いか**」を出力（例：`adx_14 > 28` / `bb_slope_pct_20 < −15` / `stoch_gap_5 > 3`）。
- **V9 手書き閾値（ADX 30-50 / bb傾き −10 / gap 0.3）と対比表で出す**（AI が V9 の値をどう書き換えたか一目で分かる）。

**出口側＝選んだ「保有時間・TP幅・SL幅」**:
- 入った玉ごとに AI が選んだ出口値（保有時間 分 / TP % / SL %）を出力。
- **入口条件帯別（bb傾き帯・ADX帯 等）に、選んだ出口値の中央値・範囲を集計**（例：強い下げの入口＝TP1.5%/SL2%/240分、弱い入口＝TP0.5%/SL1%/60分、のように「入口によって出口がどう変わったか」を見せる）。

→ これで「入口の条件（指標×閾値）」と「その入口に対して選んだ出口（保有時間/TP/SL）」が結果として読め、まこさんが学習の中身を確認できる。report.py / p23_learned_params_E09.json に出す。

## 15. リスク・未解決点
1. **net回帰のボラ依存（軸1の影）**: 金額ターゲットは高ボラほど大→ボラ逃げ回帰の恐れ。入口Xボラ除外＋vol_share監視で抑えるが完全には消えない（まこさんが vol_share・月別分散で判断）。
2. **案B（建玉別出口値）の正しさ**: add 中に出口値が建玉の g* に従うか。自己検査（V9既定固定で gen 一致）＋独立sim照合で担保。
3. **入口 pred_net>0 で件数が減るリスク**: 件数と avg net を毎周 report で確認（§11逆算＝月$1,900は件数×avg）。
4. **計算量が重い可能性**: §10 の通り実測後に分割等で対応・勝手に削らない。
5. **地面超え不可の可能性**: 超えなければ捨てず原因3分類で ledger 記録→次の一手。
