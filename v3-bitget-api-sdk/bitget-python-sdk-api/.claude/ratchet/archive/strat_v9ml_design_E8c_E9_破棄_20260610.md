### 10.15 E8c 確定設計（2026-06-08・まこさん承認・これが実装の正本／前の §10.6-10.8 と食い違う所は本節が優先）

**学習する要素（2つ）**
1. Entry：指標の閾値（gap / ADX / ATR / bb傾き）と期間。V9 手書き値を置換。
2. Exit：数値（TP幅 / 時間切れ / 失速カット 等）。V9 値を起点に最適化。

**学習方法**
- 候補＝P23 の型（stoch デッドクロス＋陰線・閾値は外して広く＝gen の typeonly）。
- ラベル＝「伸びるか」二値（実出口が利益方向に T% 以上動いたか）。T＝学習期間の勝ち玉(net>0)の MFE価格% 中央値 × 0.65（trade_analysis_methods_kb §3 の TP較正基準・データ由来・勘でない・実測 約0.9%）。MFEピークそのものは教師に使わない（H2）。
- 機械（LightGBM）が (Entry閾値 × Exit数値) の組合せを学習期間で探索し、連続モード net が最大になる組を見つける。**Entry/Exit はセット**（Exit を変えると勝敗＝学習の正解が変わるため・§8.5）。
- 特徴量＝方向 regime 系（stoch_k/d/gap・adx・bb_slope_pct・bb_pctb・rsi・rsi_slope・ret_5 の複数期間 ＋ MTF 15m/30m/1h/4h）。**ATR / bb_width は方向 X から除外**（軸1）。
- hyperparam＝Optuna × purged k-fold（§10.8）。期間分割は §10.5（H8）。
- ⚠️ k×σ 方向バリア（§10.7 の B 案）は**採らない**（E8b第2回 AUC0.52・無エッジ・ledger E8b第2回）。

**★ 数分スモークテスト（本格学習の前に必ず・前回入れ忘れた・10時間暴走の再発防止）**
- 小サンプル（例：1ヶ月分 or 数百候補）で end-to-end を数分だけ実行し、下記を確認してから本番（全期間の重い学習・採点）に進む：
  1. 最後までクラッシュせず走る（前回の KeyError 型を防ぐ）
  2. 自己検査（連続モード ＝ `replay_csv.run()` 一致）が小サンプルで通る
  3. ボラ逃げ番人（feature importance で ATR 等が非支配）が機能する
  4. ラベル分布・特徴量列数・小サンプル AUC が常識的な範囲
- 1 つでも異常 → 本番学習に進まず停止して報告。これで「10 時間走らせて間違いでした」を物理的に防ぐ。

**判定（PDCA・捨てない）**
- 連続モード(cap遵守) `score.py` の NET（採点 2025-04〜12）vs 地面 925.73。
- 超えれば残す。**超えなければ「捨てる」でなく、原因を3分類（戦略/執行/regime）で究明し、改善を ledger に記録 → 次の1手**（analysis_playbook §2.4）。

**番人（自動中断・CC の正直さに依存しない）**
- **勘値ストップ**：戦略コードの数値定数は「データ由来 or 出典コメント(# src:)」必須。出典なしのリテラル（勘の値）を入れたら停止。
- leak（.shift(-)/center grep＋学習末<採点始 assert）／ cap 0.12 連続モードゲート ／ コスト eval_engine ／ ボラ逃げ（feature importance）／ 自己検査（連続モード＝replay 一致）。

## §10.16 E9 設計（2026-06-08改訂・出口の「値」を連続学習／前の §10.6-10.15 と食い違う所は本節が優先）

> 経緯・分析は session_log_20260608 §7。**⚠️ 旧 §10.16（出口を16プリセットから選ぶ）は CC の矮小化＝「出口の値を学習」になっていなかった（CC が計算量を口実に勝手に16固定リストへ削った）。本節で出口の値の連続学習に是正。**

**まこさんの定義（逐語・これを実装・縮めない）**: 入口の条件（どの指標値で入るか＝gap/ADX/ATR%/bb傾き/stoch/MTFの切れ目）と、出口の条件（TP幅/損切り/時間を**どう置くか＝値**）を、一緒に動かして、往復の純益（net）が最大になる組合せを木に学習させる。

**WEB検索裏取り（出口の「値」を学習する手法・2026-06-08）**:
- ML-for-exit＝entry features から最適な **stop-loss / take-profit / holding period の値**を予測（ScienceDirect S1544612323006578「risk-aware constraints: stop-loss levels, target profit thresholds, holding periods」／ quantstrategy ML-for-exit）。
- 出口の値を利益最大になるよう探索（「identifying **values** that maximize the trade's gain … model explore possible outcomes」）。
- 入口の質に応じて出口の値を変える（arxiv 2102.04160「予測が確かなら大TP・小SL／確かでないなら小TP・大SL」）＝入口×出口の連動。
- ＝**16プリセットから選ぶのは誤り。出口の値（TP/SL/時間）そのものを連続的に net最大化する。**

**設計（出口の値を連続学習・プリセット廃止）**:
1. **出口の値は連続範囲**（TP幅・損切り%・保有時間を連続レンジで扱う・離散固定リストにしない）。
2. **学習データ**：各型バー i に、出口の値を**連続範囲からランダムに K 組サンプリング**して gen.simulate_independent（params に上書き）で前向きsim → (入口指標 ⊕ 連続な出口値 TP/SL/time) → 往復net（実出口・MFEピーク不使用＝H2）。
3. **木**：(入口指標 ⊕ 出口値) → 往復net を回帰（regression_l1）。木が「入口×出口値」の連続な net 地形を学ぶ。入口Xは方向regime系（stoch/adx/bb_slope_pct/bb_pctb/rsi/ret_5 複数期間＋MTF）・**ボラ系(atr/bb_width)はXから物理除外＝H15**。
4. **推論**：各入口で、出口値の細かいグリッド（TP×SL×time）を木に predict（sim不要で軽い）→ **net最大の出口値 (TP*,SL*,time*) を選ぶ**。入口＝予測net>0 の指標域で入る（θ足切りでない＝予測net金額の符号）。
5. **採点**：選んだ出口値で実sim（連続モード・gen._step import・建玉別出口）cap0.12遵守 → score.py → 地面$925.73 を超えるか。自己検査＝出口V9base固定で gen.run_continuous と件数/net一致。

**計算量（★実測前は断定しない・見積もりを事実として書かない）**: sim数 ＝ 学習サンプル本数 × 出口値サンプル数 K。**本番規模は、実装後に小サンプルで「1 sim あたりの実時間」を計測してから決める**（過去に CC が 88時間/35分/70分 等の未実測見積もりを断定し、削る口実に使った＝嘘。今後は実測値のみ報告）。重ければ分割・中間CSV保存で段階実行（勝手に削らず、規模はまこさんと決める）。

**禁止（E8c/旧§10.16の再演防止）**: 出口先固定（StaleOff）／prob≥θ足切り／**出口を離散プリセットから選ぶ**／勝率・○×・伸びるかラベル。すべて出口の値の連続学習に反する。

**実装・検証（cat_requirements §8.4-2.9 不正防止3点）**: train_p23_entry_E9.py（V9・gen import のみ）。判定は score.py の数字だけ／実装後に Web Claude（独立）レビュー／番人は「わざと壊して落ちるか」メタ確認。**リスク（監視継続）**: net金額ターゲットはボラ依存しうる（軸1の影）→入口Xボラ除外＋vol_share監視。
