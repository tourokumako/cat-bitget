## やること（1変更＝★8 の節に「④ 名前ごとの判定の列」の表を足す）

gen_materials.py の _regime_decl_view と _render_regime に、次の表を足します。

1. **宣言を機械で集める**＝e38＝e38_logics.json の global.regime から／e37＝tuner_adapters/e37.py の REGIME から。どの名前に何が宣言されているかを、名前4つに振り分けます。
