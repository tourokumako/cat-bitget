## やること（1変更＝gen_materials.py に節を1つ足す）

materials.md（と materials.json）に「★相場の宣言（M2-1-1）」の節を新設します。中身は3つで、全部 実物から機械で引きます。

1. **相場の名前の一覧**＝tuner_adapters.REGIME_NAMES から引く（いまは range・uptrend・downtrend・spike の4つ）。
2. **要る列2つ**＝entry_col（このバーだけ玉を建ててよい）・block_col（新規の発注を止める・要らなければ null）。宣言の鍵から引きます。
3. **止める検査の件数**＝check_regime（実行前・接続ファイル側）と _check_regime_meta（レシピの読み込み時・G5）と _regime_series（実行時・列が無ければ止める）の検査の数を、関数の実物から数えて出します。
