**root を直します。**

**それでは足りません。私が書き替えられる限り、次に逆へ書けるからです。**

**root の直し方**＝答えの欄そのものを、私が書けない場所（プログラムの出力）へ移す。**この設計はこちらです。**

### 3.2 答えの決め方（★これが「私が書ける欄」を消す本体）

**返す文字列は、下の4つだけです。プログラムの中に固定します。**
**★4つ**＝`当たりません` ／ `当たっています` ／ `当たっている疑いあり` ／ `測り方が未定`。**下の表は条件が6行ありますが、返る文字列は重なるので4つです。**

| 番号 | 条件 | 返す文字列 |
|---|---|---|
| 1 | 乱数の呼び出しが **0件** | `当たりません` |
| 1 | 乱数が1件以上・**法則の表を読む所が 0件** | `当たっています` |
| 1 | 乱数が1件以上・法則の表を読む所が 1件以上 | `当たっている疑いあり` |
| 2 | 数の並びが1件以上、**または** 範囲を通さずに作っている所が1件以上 | `当たっています` |
| 2 | 上のどちらでもない | `当たりません` |
| 3以降 | ルールが無い（まこさんが足した番号） | `測り方が未定` |

**★1番に「当たっています」へ倒す道を作ったのが、57回目からの変更点です。**
**57回目のルールでは、1番は永久に「疑いあり」しか出ませんでした。それでは検査になりません。**

**★1番で白黒が付かない場合が残ります。**乱数が「案の骨格を決めている」のか「同じ点数のときの並び順を決めている」のかは、構文木では分けられません。
**だからプログラムは「疑いあり」と出し、関数ごとの内訳を並べます。白黒は まこさんが付けます。**
**★`当たりません` に倒せるのは 0件のときだけです。「疑いなし」に倒すルールは入れません。**

### 3.3 `engine_tuner_gen` が読み込めなかったときの扱い

**読み込みに失敗したら、`lint_provenance` の欄に「測れませんでした（理由）」と出します。**
**そのとき 2番の答えは、数の並びの件数だけで決めます。**＝安全側（0件でない限り `当たっています`）に倒れます。
**★止めません。**この設計は見えるようにするだけです。
