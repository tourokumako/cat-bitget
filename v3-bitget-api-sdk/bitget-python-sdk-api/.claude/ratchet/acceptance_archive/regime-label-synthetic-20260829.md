## 2｜なぜ作るか（深掘り4点）

### ① 真因

**正解データを作るプログラムを、答えの分かっているデータで試したことが一度も無い。**
実物＝`_regime_labels`（`observe_diag.py`:5436-5453）。これを呼ぶ検査は、**実データでの集計しか無い**（検査15・順位づけ）。
**＝計算式を1文字 間違えても、出てくる数字が変わるだけで、誰も気づかない。**

### ② 期待値分解（勝率／平均利益／敗率／平均損失）

**非該当。この検査は売買を1本も出さない。**
**net への効き方は間接**＝正解データ → 材料の順位 → 組み立てる判定 → 入口の絞り → net。

### ③ root か symptom か

**root。**症状（出た数字がおかしい）に気づいてから調べるのではなく、**数字を出す道具そのものが壊れていないか**を、毎回の自己検査で確かめる。
