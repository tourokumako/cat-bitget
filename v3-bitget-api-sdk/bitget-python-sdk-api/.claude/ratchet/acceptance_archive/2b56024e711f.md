## 束の組み方（技術のやり方＝私が決めた・報告）

レンジの束＝`{"form": "hysteresis", "on": ON, "off": OFF, "value": {"n": 続く長さ}}` を1つ持つ `{"all": [...]}`。中身は次の4部品で、**決まり1件に部品1つを対応させる**（足りない部品が出ない作り）。

| 部品 | 決まり・法則 | 組み方 |
|---|---|---|
| A 帯の幅 | K-6・R7 | `level` ／材料 `{"geo": "W%"}`／`side: above`／閾値＝分位の範囲から引く（下限の値は探す値） |
| B 構造・位置 | K-4・R1 | `location` 役割の材料を順位 `rank_top_cols("location", ラベル, 先読み, K)` の上位 K から1本 引き、`level` か `band` で書く（帯内位置% の geo も候補＝型の表の geo_ok） |
| C 非トレンド | K-5・R8・R5 | `{"not": 条件}`。条件＝`env` 役割の材料を順位 `rank_top_cols("env", "強さ", 先読み, K)` の上位 K から1本 引き、`level`／`side: above`／分位の範囲＝「トレンドの強さが強い」の否定 |
| D 上位足 | K-2・R3・C4 | C の材料の時間足は、型の表の `tfs` のうち 5m より上からだけ引く（`_role_tfs` の結果を 5m より上に絞る）。これで K-2 を必ず満たす |
