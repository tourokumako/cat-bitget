## 深掘り4点
- ① 真因: 入口が帯の下端（h>=res_lo）で発火し、帯の上端（本当のレジスタンス）まで上がる逆行を丸ごと抱えて損切り・時間切れに当たる（analysis_block ④/⑥）。
- ② 期待値分解: 平均負けを下げる（逆行余地が帯の高さ から ほぼ0 に縮む）∩ 平均勝ちを上げる（入口から中央の利益余地が増える）＝R:R 改善。数値は両窓 score.py で確定。
- ③ root か symptom か: root（入口の位置）。守り（SL深く）／攻め（TP伸ばす）は symptom（improvement_plan STEP4）。
- ④ ベースアップ: range_scalping_kb §3（レジスタンス拒否で SHORT）・§4（SL はゾーンのすぐ外＝上端で入れば自然に浅くて足りる）・まこさんの「ショートは上端で入る」・WebResearch 2026-07-12（LuxAlgo Scalping S/R＝「confirmed rejection at resistance で入り SL は resistance の上」「帯手前の早期エントリーは確認不足で高リスク・overtrading」／ arxiv 1411.5062＝「stop-loss に近すぎる位置で入ると損切りされやすい＝入口の位置が損切りとの距離を決める」＝上端で拒否確認して入る本手を裏付け）。
