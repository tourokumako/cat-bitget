### 7.3 止める型（2つだけ）

**型A｜同じ名前について、反対の判定が2つ在る**

- **名前**＝行の中の次の3つ。①`T` に続く数字（`T24`・`T24②` など）②`--` で始まる旗（`--selftest` など）③バッククォートで囲まれた識別子。
- **判定の対**＝下の5組だけ。

| 組 | 片方 | もう片方 |
|---|---|---|
| 1 | 落ちる | 落ちない |
| 2 | 止まる | 止まらない |
| 3 | 在る | 無い |
| 4 | 一致 | 食い違い |
| 5 | pass | fail |

- **同じ名前を含む2行が、同じ組の反対側の語を持っていたら止めます。**

**型B｜全部を否定する文と、同じ動詞の個別の肯定文**

- **全部を否定する文**＝「〜が無い」「1件も〜ない」「0件」「すべて〜ない」＋ 上の表の動詞。
- **個別の肯定文**＝名前つきで、同じ動詞の肯定。
- **例**＝「新しく**落ちる**ものが**無い**」＋「T24② が**落ちる**」→ 止めます（実例1）。

### 7.4 止めないもの（誤報を出さないため）

| # | 何 | なぜ |
|---|---|---|
| 1 | 引用の行（`>` で始まる） | まこさんの逐語や外の資料の写しで、設計の主張ではない |
| 2 | 囲みの中（``` で囲んだ所） | コードや画面の出力の写し |
| 3 | 取り消し線（`~~` で囲んだ所） | 直す前の文を残してあるもの |
| 4 | 履歴の行（「直す前」「旧」「★2026-…に直した」を含む） | 前と後を並べて書くのは、食い違いではない |
| 5 | 表の見出しと区切りの行 | 中身ではない |
| 6 | **動詞をまたぐ組**（「在る」なのに「止まらない」＝実例2の型） | **止めずに画面に出すだけ。**意味の判断が要るため（下の §10 の限界） |
