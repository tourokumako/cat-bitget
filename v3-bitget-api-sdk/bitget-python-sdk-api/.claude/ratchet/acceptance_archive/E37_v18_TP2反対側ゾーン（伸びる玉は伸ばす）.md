## B 深掘り4点
- **① 真因**: E37 は状態機械の「利益最大化（伸びる玉は伸ばす）」半分が欠落＝伸びる玉をレンジ中央（TP2=mid）で頭打ちにしている。実測＝TP 決済後60分でさらに W 比 0.32〜0.39（中央値）下落・採点窓 取り逃し合計 $4,311（TP_FILLED 875件 $2,227＋PARTIAL_TP 835件 $2,084）・玉の 59〜63% が決済後 0.25W 以上伸びた（**両窓再現**・e37_v17_be_dd_replay_probe 補助集計）。
- **② 期待値分解**: 動かすのは**平均勝ち**（現状 $3.07・必要勝率 71.2%=実際 71.2% の分岐点ちょうど＝N7）。TP2 到達玉の1件単価を伸ばす（学習窓 TP_FILLED 平均 gross $1.23・be14.63＝手数料余地は大きい）。勝率は下がる方向（到達率低下）＝net での判定。
- **③ root か symptom か**: root（Y）＝状態機械の利益最大化枝の欠落そのもの。守り側の各枝は probe 7変種で中立と実測済み＝触らない。
- **④ ベースアップ**: (a) range_scalping_kb §4「TP はレンジの反対側（ショートならサポート側）または中央」 (b) WebSearch 2026-07-11＝レンジトレードの主要利確目標は反対側境界（LuxAlgo/Babypips）・平均回帰のターゲットは中央線 or 反対側バンドの両方が標準（QuantifiedStrategies） (c) 学術の逆向き知見も明記＝OU 過程では「SL が遠いほど最適 TP は近い」（arxiv 1411.5062・WebFetch）＝**深置きが逆効果の可能性は理論側にもある→ だから a-priori 1点で置き、採否は実エンジン両窓 score.py**（スイープしない）。
