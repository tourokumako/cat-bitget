## 何を作るのか

**作るものは、5つの枠を、段ごとに絞りながら埋める仕組みです。**枠は §2.2 が決めたもので、帯（段1）・強さの否定（段2a）・向きの否定（段2b）・3枠目（段2c）・持続（段3）の5つです。
