## 3｜何を作るか

### 3.1 ★読む形（まこさんの決定4・5）｜一覧をコードに焼かせない

**設計書に一覧を機械可読で書き、承認のときに設定ファイルへ機械で書き出し、実装はそれを読みます。**

```json
"spec_lists": {
  "law_expand_kinds": ["family", "系統", "性質", "geo"]
}
```

| 段 | 誰が | 何を |
|---|---|---|
| 1 | 私（手で） | 設計書の `spec_lists` に一覧を書く |
| 2 | **機械**（`approve_impl.sh`） | 承認の瞬間に `.claude/ratchet/spec_lists.json` へ書き出す |
| 3 | 私（手で） | 実装は、その一覧を**読むだけ**にする（コードに一覧を書かない） |
| 4 | **機械**（照合D） | 実装が その一覧を実際に読んでいるかを確かめる |

**★これで今日の型は「起きなく」なります。**一覧がコードに無いので、私が2通りに減らせません。

**★一覧は2か所に書きません**（まこさんの決定6）。設計書が唯一の出どころで、設定ファイルは機械が作ります。

### 3.2 設計書に足す欄（3つ）

| 欄 | 意味 |
|---|---|
| `spec_lists` | **実装がコードに焼かずに読む一覧**（§3.1） |
| `impl_functions` | この実装で作る・変える関数を、ファイルごとに全部 書く |
| `must_use` | そのうち、関数の中で必ず使う名前 |

### 3.3 照合（4つ・全部 実行の前）

| # | 何を照らすか | 落ちる条件 |
|---|---|---|
| **A** | git の差分で触った関数 ⊆ `impl_functions` | **設計書に書いていない関数を触った**ら止まる |
| **B** | `impl_functions` ⊆ git の差分で触った関数 | **設計書に書いたのに実装していない**なら止まる |
| **C** | `must_use` の名前が、その関数の中に在るか（AST） | 中身が設計と違うなら止まる |
| **D** | `spec_lists` の各一覧が、実装のどこかで読まれているか | **一覧を読まずにコードに焼いた**ら止まる |

**★今日の間違いは C と D の両方で止まります。**

### 3.4 抜け道を1件ずつ塞ぐ（6件・監査 cp8 が NO-GO の根拠にした型）

| # | 抜け道 | 塞ぎ方 |
|---|---|---|
| 1 | `must_use` に1件だけ書いて通す | **照合A・B で塞ぐ。**触った関数は git が知っているので、書かずに済ませられない |
| 2 | 自明な名前だけ書く | 1で「書かない」が塞がる。**中身の甘さは残る**＝§9 |
| 3 | 設計書を書き換えて再承認を頼む | **承認のとき、承認済みの控えとの差分を機械が必ず画面に出す**（`approve_impl.sh` に足す） |
| 4 | **Write/Edit を使わず Bash で .py を書く** | **hook の対象に Bash を足す**（監査 cp8 が実測で再現した穴） |
| 5 | 照合の道具を書き換える | **道具のハッシュ値を印にして、変わったら止める**（H2・G2 と同じ形） |
| 6 | hook を無効にする | 既存の `hook_health_check`（SessionStart）が毎回 数えて画面に出す |

### 3.5 分岐を直す（`verify_design_contract.py`）

**いま**＝`self_check_calls` が在ると `must_combine` が走りません。**直した後**＝書いてあるものを**全部 走らせます**。

### 3.6 ★読む形にできる範囲・できない範囲（正直に）

| 種類 | 例 | 読む形にできるか |
|---|---|---|
| 一覧を全部 展開する | 「4通りを展開する」 | **できる。今日の型はここ** |
| 決まった値 | 閾値・件数・期間 | **できる**（既に `search_limits.json` でやっている） |
| 順番・条件の分岐 | 「A なら B、でなければ C」 | **半分**。条件は外に出せるが、分岐の形はコード |
| 計算の中身 | 指標の計算式・売買の判定 | **できない。**コードでしか書けない |

**★できない部分が残るので、照合（§3.3）も要ります。片方だけでは足りません。**
