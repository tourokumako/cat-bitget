## 決めていただきたいこと：設計書を1本にするか、分けるか
- 前回の工事の案を読みました。設計書の「実装の指示」（【4-20】）には、直す1か所ごとに「直す前の文字」と「直した後の文字」を、コードのまま書きます。案を作る道具は、それを本物に書かずに写しへ当て、自己テストまで走らせて確かめます。
- 前回の工事は、1つのファイルの直しで実装の指示が13件、案が400行ありました。
- 今回の工事は18項目あり、触るファイルは観察の道具・参照表・設定2本・法則のコードなど10本を超えます。特に重いのは次の3つです。
  - P-1：材料の一覧の作り方を、指標ごとの一覧に作り替える
  - K-3：教科書の版を25種足す
  - B-1：帯の部品を新しく作る
- 1本の設計書にすると、実装の指示は数百件になる見込みです（数えてはいません）。監査も1回で全部を見ることになります。

**私の案：やることの表の順番どおりに、4本に分けます。**
| 回 | 中身 | 項目 |
|---|---|---|
| 1 | 作りの直し（監査の修正を当てる） | K-1・K-2・K-4・K-6・K-8 |
| 2 | パラメータ | P-5・P-1・P-2・P-3・P-4 |
| 3 | 新しい材料 | K-3・B-1・S-1・K-7 |
| 4 | 役割と閾値 | R-1・T-1 |

- 各回の最後に、G-1（表の作り直しと再承認）と G-2（自己テスト・G2・H2）を入れます。
- 分けたときの手間は2つあります。読むもの宣言・承認・監査が、回ごとに要ります。型の表の再承認も4回になります。
- 分けたときの良い点も2つあります。1回の設計書が小さくなり、私の誤りが監査で見つかりやすくなります。また、1回目の終わりで、壊れた7種と監査の作りの直しが先に本物に入ります。

「4本に分ける」か「1本にする」か、どちらかで答えてください。
