## 工事ごとの問い
### Q8 — K-1 の直しは、7種を修正13 の前と同じ材料に戻したか（優先度 A）
理由：戻し方が違えば、COPC・FISHER ほかが、修正13 の前とも今とも違う値で作られ、成績表の名前とも合わなくなる
当てた後の observe_diag.py の build_catalog を、修正13 の前の版（git show 4656de3 の observe_diag.py）と比べてください。7種（COPC・FISHER・FISHERシグナル・KSTシグナル・KDJ%K・KDJ%D・KDJ%J）が、同じ for の中で、同じ引数の並びで作られているか。材料の一覧に COPC(9,12,26)・FISHER(12,9)・FISHERシグナル(12,9) が在り、COPC(9,5,34)・FISHER(5,9)・FISHERシグナル(5,9) が無いか。KSTシグナル と KDJ の列の名前と値が、修正13 の前と同じか。AO% の2組（macd の組と ao_params の組）が、両方 作られているかも見てください。

### Q9 — K-8 の上位足の切り替え（bar_close）は未来を使わないか。検査は、未来を使う壊し方を見つけるか（優先度 A）
理由：未来を使う形が入ると、H2（未来参照なし）に反する材料で成績表と判定が作られる
build_features の式（上位足の値を、足の始まり＋足の長さ から、5分足1本ぶん早める）が、5分足の行 R で「R が閉じた時刻までに閉じた上位足」だけを使うかを、15分足と2時間足で確かめてください。軽い口（observe_diag.py --selftest-catalog）の K-8 の検査が、壊すプログラム b129（2本ぶん早める）を落とすか。設定の既定が now で、当てる前と後で、既定の設定の列が1つも変わっていないかも見てください（H2 は既定の now だけを測っています）。
