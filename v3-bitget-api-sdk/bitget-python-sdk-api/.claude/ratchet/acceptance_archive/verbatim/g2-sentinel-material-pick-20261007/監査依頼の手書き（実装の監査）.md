## 工事ごとの問い
### Q8 — 元の構造を選び直しても、既知答え11件はどれも狙った分岐を試しているか（優先度 A）
理由：元の構造が変わると、差し替えの見本が狙いと違う理由で弾かれ、判定のその分岐を1度も試していない状態になりうる
番人は、表に沿った構造のうち、指標の材料を持つ最初の構造（with_col[0]）を元に使う形になりました。既知答えは、元の構造を通すもの（本物の構造）、材料を1つ差し替えるもの（禁止3 の組・偽の指標・レンジ幾何の2種・時間帯）、表の写しを痩せさせるもの4件（指標の種類・時間足・時間帯の許可・材料が無い）、材料を読めることの1件です。足した4件は、出た違反の文まで照らしています。元の6件は、通るか弾かれるかだけを見ています。新しい元の構造で、元の6件が狙いどおりの理由で弾かれているか（例＝禁止3 の見本が、禁止3 の文で弾かれているか）を見てください。

### Q9 — 選び方は決まった並びで、乱数を足していないか。止まり方は正しいか（優先度 A）
理由：乱数は禁止（恒久67番）。止まり方を誤ると、既知答えが黙って減る
構造は今も、種を固定した乱数で30本 作ります（_real_structures）。直したのは、残った構造を前から順に見て、指標の材料を持つ最初の1本を選ぶ所だけです。この絞り込みが決まった並び（作った順）で、新しい乱数を使っていないかを見てください。表に沿っていて指標の材料を持つ構造が1本も無いときは、「[番人エラー] 表に沿っていて指標の材料を持つ構造が1本も作れない」で止まり、検査済みの印は書かれません。この止まり方で、既知答えを減らして通る道が無いかを見てください。

### Q10 — 壊すプログラム b144 は、直しを外したときだけ落ちるか。前からの壊すプログラムに影響は無いか（優先度 B）
理由：落ちない壊し方が在ると、選び方が黙って1本目に戻る
b144 を写しの作業場で走らせ、宣言した文で落ちるか、壊す対象がちょうど1か所かを見てください。★CC の自己申告＝b144 が落ちるのは、いまの材料の一覧で、表に沿った1本目の構造に指標の材料が無いからです。材料の一覧が変わると、直しを戻しても落ちなくなることがあります（設計書の 7-4・6-2 の2）。この限界を、ほかの形の壊し方で補うべきかを見てください。★CC の自己申告（2つ目）＝この工事の1回目の案の返信は、先頭に【】で始まる行を4つ付けたので、設計書を作る道具が読めない形でした。案だけを載せ直し、まこさんに2回目の OK をいただきました（worklog §16）。★CC の自己申告（3つ目）＝案を作る最初の道具（r6_build.py）は engine の部品を読み込むので、G2 の印が古い間は G2 の守りが走らせませんでした。守りはくぐらず、読み込まない道具（r6b_build.py）を作り直し、古い方は消しました。
