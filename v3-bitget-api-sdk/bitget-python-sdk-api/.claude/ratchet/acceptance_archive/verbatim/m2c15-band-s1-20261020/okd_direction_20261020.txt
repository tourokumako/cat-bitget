## この工事で直すこと（6つ）

いま、材料（指標一覧）には、法則 R1（レンジの帯）と法則 S1（急な値動き）を測る部品がありません。そこで、次の6つを足したり直したりします。

1. **スイングの帯**：上の線と下の線のそれぞれで、跳ね返された回数（3〜4回以上）を数えます。終値が2本の線の間に在れば 1 を出す部品を足します。
2. **pivot の帯**：上の線を前の日の R1、下の線を前の日の S1 にして、1と同じ数え方をする部品を足します。
3. **VAH/VAL の帯**：上の線を前の日の VAH、下の線を前の日の VAL にして、1と同じ数え方をする部品を足します。
4. **1時間足の区切り**：いまは 10:05〜11:05 で区切っています。これを、正時（10:00〜11:00）と切り替えられる形にします。既定は今のままです。
5. **効いていない設定の直し**：S-Rタッチ1時間ATR の倍率と ATR の期間は、値を変えても結果が変わりません。原因を調べて直します。
6. **S1 の部品**：E36 の中にだけ在る「急な値動きを見つける式」を、材料に入れます。

最後に、表を作り直して、検査を通します。
