**気をつけていただきたい点が2つあります。**
- 1の TradingView のページは、Lee-Mykland の検定ではなく、近い別の統計（Barndorff-Nielsen and Shephard）のスクリプトです。ただし、同じページに Lee-Mykland の説明もあります。窓の本数の文は、論文の推奨と同じです。これを2つ目のサイトとして数えてよいかは、まこさんのご判断です。
- 2の日数の書き方から、論文の推奨値は、米国株の取引時間（1日6.5時間）で数えた本数だと読めます。BTC は24時間動くので、5分足270本は約22.5時間です。教科書の値はそのまま使います。ただし、この違いは、M2-F-10f で一致率を比べるときの材料として、記録に残しておきます。

**この先の見込み**：表のプログラムの決まりでは、スキャルの代表の値は 270 になる見込みです。デイトレは、156・110・78 の3つが候補になるので、決まった規則で1つになります。規則の最後は「小さい値」なので、78 になる見込みです。実際の値は、写しでプログラムを走らせて確かめます。

1の TradingView を2つ目のサイトとして使ってよいですか。
