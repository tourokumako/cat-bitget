4. **G-1 → G-2 が最後**：表は全部の直しが終わってから1回だけ作り直します（全体の表の順番の5）。

### §1 概要

★向きを見る所。
レンジの法則 R1（価格が何回も跳ね返された線が上下に在るか）と、スパイクの法則 S1（今の1本の値動きが統計的にありえないほど大きいか）を測る部品が材料（指標一覧）に無いので、法則どおりの帯の部品と S1 の部品を材料に足します。

いまの材料の一覧（materials.json の349行）には、Lee-Mykland の部品が1行もありません。帯に関わる行は、RG-v5 の帯から作るレンジ幾何の列（帯内位置% ほか）と、今の終値の近くに在る確定したスイングを数える S-Rタッチ確定数（observe_diag.py:657〜675）です。上の線と下の線のそれぞれで確定したスイングを数え、終値がその間に在るかを出す部品はありません。法則ファイルの R1 の「書けるか」の欄は「✕ 帯を作る形が無い」で、S1 が使う指標の一覧は空です。法則どおりの帯は RG-v5 の中にしか無く、その数字は固定です（worklog 20261003 §35 の4番）。S1 の式は E36 の急騰Exit の中にだけ在ります（同 12番）。

この工事でやることは、次の6つです。①確定したスイングを束ねた帯の部品 ②教科書の pivot（前の日の R1・S1 と、前の週の R1・S1）を線にした帯の部品 ③教科書の VAH/VAL（前の UTC の日）を線にした帯の部品 ④帯の1時間足の区切りを、今の区切りと正時で切り替えられる形（監査 CP60 の修正69）⑤S-Rタッチ1時間ATR の倍率と ATR の期間が列に効かない件（§6 の252番）の原因を確かめる（原因は照らしの道具の側に在ったので、材料は直さず、照らしの道具を直した＝設計書の外）⑥S1 の部品（Lee-Mykland の論文の版と、E36 の版）。帯の部品の値（回数・手数料の倍数・許容幅）は設定ファイルに書き、コードを直さずに変えて試せる形にします。新しい部品を判定に使うのは工事2（段1 の土台の差し替え・法則の判定の直し）で、この工事は材料に足すまでです。
