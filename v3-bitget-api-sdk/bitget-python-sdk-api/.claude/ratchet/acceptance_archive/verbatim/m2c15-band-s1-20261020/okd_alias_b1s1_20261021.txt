逐語のファイルを7本作りました（今日の決定の案と OK）。次に、資料の表に新しい種類の行を足す「別名の表」を作ります。ところが、表を作るプログラムの決まりを読むと、前にお見せした別名の割り当てのままでは、表が壊れる所が見つかりました。作る前に伺います。

## 何が壊れるか

- 表のプログラムは、調べた結果のパラメータの数と、名前のパラメータの数が合う前提で、範囲を作ります（apply_param_rule.py:208・:302〜312）。
- 帯の部品のパラメータ（窓・許容幅・タッチ・倍率）は、元にする指標（pivot・VAH・S-Rタッチ）のパラメータではありません。そのまま写すと、軸の違う値が混ざります。
- 調べた結果に行が在る種類は、別名の表に同時に載せられません（make_param_table.py:91 が止めます）。

## 直した割り当て（私の案）

| 新しい部品 | 使う今の行 | パラメータ |
|---|---|---|
| 帯スイング・帯スイング1時間ATR | S-Rタッチ確定数 | **写さない**。窓・許容幅・タッチは、元の行のパラメータと違うためです |
| 帯pivot・帯pivot1時間ATR | 前期間pivotR1 | 写さない。許容幅は、pivot のパラメータではないためです |
| 帯pivot前週・帯pivot前週1時間ATR | 前週pivotR1 | 写さない（同じ理由） |
| 帯VA・帯VA1時間ATR | 前日VAH | 写さない（同じ理由） |

- 「写さない」は、先例（K-3b の SMC_SWEEP確定・まこさん「よい」2026-10-09）と同じ扱いです。役割と閾値は、元の行のまま使います。
