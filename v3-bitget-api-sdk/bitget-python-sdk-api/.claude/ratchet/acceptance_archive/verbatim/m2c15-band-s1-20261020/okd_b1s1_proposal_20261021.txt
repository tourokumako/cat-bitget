【4-0 この仕組みは何か】
材料（指標一覧＝observe_diag.py の材料の表とカタログ）に、法則 R1（価格が何回も跳ね返された線が上下に在るか）・R7（取れる距離が往復の手数料を超えるか）の部品と、法則 S1（今の1本の値動きが統計的にありえないほど大きいか）の部品を足します。帯の部品は4種類です。①帯スイング＝確定したスイングを許容幅で束ねた上と下の帯（上の帯の山と下の帯の谷がそれぞれ 2・3・4 回以上・取れる距離が手数料の床以上・終値がその間なら 1）②帯pivot＝前の日で固定の R1・S1 の間に終値が在り、取れる距離が床以上なら 1 ③帯pivot前週＝前の週で固定の R1・S1 で②と同じ（監査 CP83 の修正12・まこさん「ウ」）④帯VA＝前の UTC の日で固定の VAH・VAL で②と同じ。②③④は線に触れた回数を数えません（pivot の役割＝前の期間から前もって推定する支持線・抵抗線・StockCharts の逐語「Pivot Points use the prior period's high, low, and close to estimate future support and resistance levels.」・まこさん「Aでいい」）。どの種類にも、固定の許容幅の版と、1時間足の ATR% × 倍率を 0.15%〜0.6% に収める版を付けます（まこさん「１は案ア」・3つの決定の2）。S1 の部品は2つです。論文の版（LeeMykland＝Lee-Mykland 2008 の式(8)どおり、ふだんの揺れに今の1本を入れない）と、E36 の版（LeeMykland_E36版＝E36 の式を1文字も変えずに材料の表へ移した物・E36 はそこから呼ぶ）です（監査 CP83 の修正1・まこさん「案A」）。K は論文の推奨値の5つ（16・78・110・156・270）です（修正7・まこさん「案B」「甲」）。あわせて、帯の1時間足の区切り（今は 10:05〜11:05）を、正時（10:00〜11:00）に切り替えられる設定を足し（既定は今のまま）、prepare_df を呼ぶ4か所（E38 の接続・E38 の本体・H2 の検査・E37 の接続）と観察の道具の帯の列に届く形にします（監査 CP60 の修正69・CP83 の修正5・まこさん「案A」）。完成すると、カタログの新しい列は 118 本（帯スイング 18・帯pivot 3・帯VA 3・帯スイング1時間ATR 54・帯pivot1時間ATR 9・帯VA1時間ATR 9・帯pivot前週 3・帯pivot前週1時間ATR 9・LeeMykland 5・LeeMykland_E36版 5）になり、engine_tuner と M2 の段は、法則 R1・R7・S1 を材料の列として選べるようになります（選んで組むのは工事2）。なぜこの形か＝帯pivot・帯VA に触れた回数を求めた最初の形は、実物の5分足6000本で 帯pivot 0.0%・帯VA 1.2% しか 1 にならなかった（前の日の線に過去のスイングがそろわない）。触れた回数を外した形では 帯pivot 72.1%・帯VA 45.3%・帯pivot前週 49.8%・帯スイング（タッチ2回）11.6%（同じ6000本・写しの確かめ b1s1_check.json）。

【4-4 処理の流れ】
1. 材料の関数が5分足（または各時間足）を受け取る → 帯スイングは確定したスイング（_fractal_marks）を窓 n の中で束ね、上と下の帯を選ぶ → 回数・距離・終値の位置で 1・0 を出す。
2. 帯pivot・帯VA は、前の日の線（_pivot_prev_period・_vp_by_day の前日）と許容幅から、終値の位置と距離で 1・0 を出す。帯pivot前週は、前の週の線（_pivot_prev_period(d, "W")＝先例 K-7 の前週pivot と同じ線）で同じ。
3. 1時間足 ATR の版は、_atr_pct_1h_on（閉じた1時間足の ATR%）から許容幅の並びを作って渡す。
4. LeeMykland は、終値の対数の値動きと、直前の K−1 本の bipower（今の1本の項を入れない）から L を出す。LeeMykland_E36版は、今の1本の項を入れた K−1 項の bipower から L を出す（E36 の式）。
5. 区切り＝e38_logics.json の global.regime.h1_edge → prepare_df を呼ぶ4か所（tuner_adapters/e38.load_windows・e38_priority_stack.py・leak_causality_diag.py・tuner_adapters/e37.py）→ e38_logic_parts.prepare_df → e37_scalp._apply_rg5_to_5m → _rg5_frames → build_range_gate_dashboard._resample(edge)。
6. 床＝build_catalog が、渡された設定の band_fee_mult から1回作り（_band_fee_floor(cfg)）、帯の部品の1組ずつに結び付ける（_band_material）。
- 条件のつなぎ方に触るとき：非該当＝この工事は材料を足すだけで、条件のつなぎ方（型の表・場面の決まり）を直さない（直すのは工事2）。
