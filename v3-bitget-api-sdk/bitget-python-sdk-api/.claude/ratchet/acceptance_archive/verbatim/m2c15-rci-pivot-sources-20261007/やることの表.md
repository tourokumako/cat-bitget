### 4-19 通しの例

例＝RCI。いま RCI の列は、設定の rci_periods の組から作られ、探す範囲の設定にも RCI がありません。そのため engine_tuner は、カタログの数字の最小〜最大を範囲として使い、RCI は値を埋めない種類の並びに「資料に行が無い」として載っています。資料には、調べる係が集めた RCI の値（スキャル用・デイトレ用・範囲）が入りました。この工事の後は、RCI の列が資料の最初の値と残す名前（V9 の RCI の3本）の組で作られ、新しく RCI5 の列が増えます。探す範囲は資料の範囲（見つかった値と今の値の最小〜最大）になり、値を埋めない種類の並びから RCI が外れます。前期間pivot の3種は、パラメータを持たないので、並びから外れるだけで列は変わりません。照らしの道具の②は、食い違い0件になります。
