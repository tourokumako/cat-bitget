【4-0 この仕組みは何か】
依頼書の道具 gen_audit_docs.py が、依頼書を書く前に節どうしの食い違いを自分で見つけ、1件でも在れば書かない。
見るのは、結論の問いが照らす Q が問いの一覧と監査対象に在るか、2つ目以降の結論の問いがスコープに在るか、自己申告に出どころの無い番号が無いか。
自己申告に写すとき、設計書の門が書かせる監査 cp14 の Q5 の5件は、番号を外さず出どころを書いて写す。
直す前は、道具に節どうしを照らす仕組みが無く、私が道具を手で直したときの抜けが依頼書に出た。前の工事では、5件の番号を出どころを確かめずに外した。
