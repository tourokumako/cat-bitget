## 手書きの項目

［手書き］この工事の設計書の、手書きの項目です。プログラムは、ここから そのまま写します。

### §1 概要

★向きを見る所。
1つの指標の情報が何か所にも分かれているため、誤りを1か所で直しても、それを使う全部のロジックに届かない。設計書1は、そのための「1か所」になる indicators.json を作る。

#### 目的
- CAT の目標は、本番で全月 net ≥ $1,900 を達成することです（core_requirements_full.md:13）。engine_tuner の目的は、「net利益を最大化させる条件（指標、閾値、時間、パラメータ）の組み合わせを、見つけることができる機械を作ること」です（:19）。
