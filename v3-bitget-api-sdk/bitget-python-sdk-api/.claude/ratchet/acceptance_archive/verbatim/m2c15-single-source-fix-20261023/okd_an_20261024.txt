これは「①集める」の作業です。設計書の監査の依頼書を作るには、案に【外部検索】の表（監査人が外で何を調べるか）が要ります。前に OK をいただいた案に、この表だけを足しました（下の【外部検索】）。外部検索は依頼書にだけ写す項目で、設計書1と見直し表は変わりません。

- 2件目は、1つのデータに集めて写すプログラムで元と照らす作りが、外の一般の作り方（single source of truth）と合うかを調べる物です。
