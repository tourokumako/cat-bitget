3つ目：閾値の代表の値は、写してくる置き場が在りません
あとで閾値の修正をするので、その後は対応できるようになるのか？



<pasted_content id="6151">
私の案
読む場所を、パラメータと同じ形に決めておきます。つまり、指標ごとに「最初の値（スキャル）」「最初の値（デイトレ）」「範囲」「出どころ」を持つ形です。設計書を作るプログラムは、その欄が在れば写し、無ければ「未決」と出します。

こうしておけば、閾値の修正の工事は、決めた形で置き場に値を書くだけで済みます。設計書を作るプログラムは直さずに、そのまま閾値が出るようになります。

ただし、閾値を数字で取り出す決まりは、まだ決まっていません。閾値の修正の工事で、この形では持てないと分かる可能性は残ります。そのときは、読む所を直す必要が出ます。

この案で進めてよいでしょうか。
