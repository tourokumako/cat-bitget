### Q9 — 古い形の元から作る設計書は、この工事を当てた後も、1行も変わらないか。新しい形の見分け方（やることの表の手書きの項目に「### 目標」が在るか）は、取り違えを生まないか（優先度 A）

### Q10 — CC が「合っている」と判定を書く表をやめ、プログラムが作る索引に替える形（実装の _index_lines と INDEX_MAP）は、要件定義の9番を弱めないか。要件の番号と節の対応は正しいか（優先度 A）
