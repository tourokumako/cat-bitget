### Q8 — 要素の定義表の40行で、構造に要ることの30件を、作り直さずに受けられるか（優先度 A）
理由：要素が足りないと、記録を写し直す工事（161番）で置き場が無く、要素の定義表を作り直すことになる。要素が多すぎると、使われない欄が残る
対象の問い：2
要素の定義表には、40行の要素が在ります。内訳は、指標の記録11行・使い方の記録11行・部品の記録8行・法則の記録10行です。「構造に要ること」は、3つの使い方を書き出して見つけた、データの構造に要る物の30件です（指標の構造の要件定義書 第5章）。要素の1行ずつには、受ける「構造に要ること」の番号を書いてあります（要素の「根拠」の欄）。30件のうち5件（9・13・14・21の後半・30）は、この表では受けません。この5件は、型と出口の枝などの記録（構造の案の E）と、機械学習のモデルの記録（構造の案の F）が、後から受けます。完成の条件2は、30件のどれもが、要素の根拠か「この表で受けない要ること」に在るかだけを見ます。受け方が正しいかは見ません。

### Q9 — 代表の固定値と範囲の置き場が、要件定義の4番・5番に合っているか（優先度 A）
理由：範囲を使い方ごとに持つと、要件の「範囲は指標ごとに1つ」に反する。代表の固定値の置き場を誤ると、最初の段階で engine_tuner が読む値が決まらない
対象の問い：2
範囲は、次の3か所に置きます。パラメータの範囲は、指標の記録の要素「パラメータの軸」（番号 ②-4）に、軸ごとに置きます。閾値の範囲は、指標の記録の要素「閾値の範囲」（番号 ②-11）に、閾値の形ごとに1つ置きます。閾値の形は、値・分位・回数・倍率・前提つきの5つです。部品の範囲は、部品の記録の要素「パラメータの軸」と「閾値」（番号 ④-4・④-5）に、部品ごとに1つ置きます。
代表の固定値は、使い方の記録の要素「閾値」（番号 ③-5）と「パラメータの代表の値」（番号 ③-6）に、使い方ごとに置きます。使い方の記録に代表の値が無いときは、指標の記録の「パラメータの軸」の代表の値を使います。代表の固定値を使い方ごとに持ってよいことは、2026-10-30 に まこさんが決めました（指標の構造の要件定義書 第4章）。閾値の範囲を使い方ごとに持たず、指標の記録に指標ごとに1つ置くことは、2026-10-31 に まこさんが決めました。
使い方の記録の要素「合図の形のパラメータ」（番号 ③-9）は、使い方ごとに範囲を持ちます。合図の形のパラメータは、クロスの前に続く本数・クロスの開き・タッチの許容幅などです。CC は、これらは指標を計算するときの設定ではないので、要件定義の「範囲は指標ごとに1つ」（core_requirements_full.md:60）の「パラメータ」に当たらないと読みました。
次の3つに答えてください。
1つ目に、範囲を指標の記録に指標ごとに1つ（閾値は形ごとに1つ）置く形が、要件定義の :60 に合っているかを答えてください。
2つ目に、合図の形のパラメータに使い方ごとの範囲を持たせる読みが、要件定義に合っているかを答えてください。
3つ目に、部品の範囲を部品ごとに1つ置く形が、要件定義の「指標ごとに1つ」と食い違わないかを答えてください。

### Q10 — 法則の記録の要素と「法則が指せる物」の決まりで、今の法則のデータを受けられるか（優先度 A）
理由：法則の記録には、法則が指標を名前で指さない決まりを置く。今のレンジの法則 R5・R6・R7 は、指標を名前で並べている。受けられないと、法則のデータを新しい形へ移す工事（ToDo の195番）を進められない
対象の問い：2
法則の記録には、10行の要素が在ります。番号・法則の種類・場面・文・級と出どころ・使う段・判定・指せる物の決まり・条件どうしの関係・オン/オフと注意の10行です。「判定」の要素は、判定の型を、選べる値の8つから選びます。8つのうち3つ（部品を数える・系統を重ねない・形を持つ）は、今の法則のデータ（regime_laws.json）が使っている型です。残りの5つは、組み合わせの法則（indicator_combination_kb.md の §3・§4）から足した型です。「指せる物の決まり」の要素（番号 ⑤-8）は、法則が指標を名前で指すことを止めます。法則が指せるのは、教科書の役割・値の読み方・使い方の種類・場面・時間足・部品の名前の6つです。
次の3つに答えてください。
1つ目に、regime_laws.json の今の判定13件を、法則の記録の要素と選べる値で、全部書けるかを答えてください。

### Q11 — 読むプログラムが守る決まり3つで、要素を足す・止めるときに、データの1か所を直すだけで済むか（優先度 B）

2つ目に、使い方の記録に値が無いときに指標の記録の値を使う作りが、使い方ごとに値を変えたい場面を損なわないかを答えてください。
