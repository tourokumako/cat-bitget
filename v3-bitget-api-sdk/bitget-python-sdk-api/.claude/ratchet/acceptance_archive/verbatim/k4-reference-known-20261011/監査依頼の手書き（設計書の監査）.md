## 工事ごとの問い
### Q8 — 定義から導いた既知答え（写しの9登録と、下げ続ける足の7列）は、定義から正しく導かれているか（優先度 A）
理由：導きが違えば、ライブラリと同じ誤りを「正しい答え」として固定し、修正59・60 の目的（誤りを捕まえる）が逆向きになる
設計書の 4-0 の②③の表と、実装 3・10・19〜30 の既知答えの式を、登録の定義・流儀の欄の文と、監査 CP60 の §5 が引いた原典の逐語、ライブラリの実物（必読の7本）から、監査が自分で導き直してください。特に＝ALMA の遅れ（重みの向き・i は古い側から）、HILO の「終値 − 11」（13本の高値の平均・21本の安値の平均）、DPO% の (n/2+1)＋(n−1)/2、VWAP の出来高 9 の足の式、PSAR の g←0.8×(g＋1) の収束＝4、CKSP の c＋17 と c＋1（TradingView の形 p=10・x=1・q=9）、PMAX の EMA10 の遅れ 4.5。★CC の自己申告＝答えの数字は定義から導いた式で書き、ライブラリの値は写していません。写しで走らせて7つとも 1e-6 以内で合いました（k4_check_run.log）。合ったことは「導きがライブラリと同じ」の証拠で、「導きが定義どおり」の証拠ではありません。定義の読みは監査とまこさんの目です。

### Q9 — 写しの印16登録の選び方は、修正59 が名指しした10件の独立実装を使う登録と一致するか。印の外に写しが残っていないか（優先度 A）
理由：印の付け忘れが在れば、その登録は独立実装だけで「一致検証済み」に数えられ続ける
修正59 の原文が名指しした10件（_tb_vs_pivot・_vp_ref・_tb_vs_vwap・_tb_wpat・_tb_sr_touch・_alma・_stc_parts・_tb_pos_hilo・_tb_thermo_pct・_tb_dpo）を使う登録を、参照表の実物から監査が数え直し、設計書の 4-0 の①の16登録（W字・close vs VWAP・pivotPP・pivotR1・pivotS1・POC・VAH・VAL・S-Rタッチ数・STC・STCstoch・close vs ALMA%・ALMA傾き%・close vs HILO%・DPO%・THERMO%）と合うかを見てください。名指しの10件を使う登録で印が付いていない物、名指しの外で同じ型（カタログかライブラリの変形の写し）の独立実装が在る物が在れば所見に書いてください。★CC の自己申告＝名指しの10件の外の登録（272件）は未判定（None）のままにしました（設計書の 3-1 の2・5 の5番）。

### Q10 — 検査3 の直し（独立(写し)✓）・番人2つ・軽い口 selftest_match は、修正59 の文の意図を満たすか。軽い口が検査3 を絞ることで守りが減らないか（優先度 A）
