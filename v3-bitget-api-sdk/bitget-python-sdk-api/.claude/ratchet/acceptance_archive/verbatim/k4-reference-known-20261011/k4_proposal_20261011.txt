| 決めたこと | 理由 | 捨てた案 |
|---|---|---|
| 写しの既知答えは、原典の数字でなく定義から導いた式にする | 修正59 の補足の例（ALMA の重み）のように原典に数字が在る物は無い。定義から合成の足で1つに決まる値なら、写しが写した誤り（向き・列・未来・重み）で値が変わる（読むもの宣言のとおり） | 既知答えを足さず印だけ付ける（検証済みが減る） |
| 下げ続ける足は終値 1000 から1本ごとに 1 下げる600本 | 前から在る部品 _dn で作れる。600本で漸化式が収束し、終値が負にならない | 200 から下げる（既存の _dn の既定＝600本で負になる） |
| 写しの独立実装が合っただけでは検証済みに数えない | 修正59 の文「照合は自分と同じかしか確かめていない」。検証済みにするのは既知答え | 写しの独立実装を照合から外す（独立✗ の検出まで失う） |
| 3種の独立の実装は別の書き方にし、式の出どころは変えない | 監査 CP73 の Q8 の (c)＝同じ文字の写しどうしでは、両方に同じ誤りが入ると見つからない | 説明の文だけ（CP73 の修正2 で済）のまま |
