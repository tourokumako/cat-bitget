### §1 概要

M2-F-10 の3つ目で、まこさんは「案B」（段2a を、閾値の分位の格子 quantile_grid の9点 q10〜q90 で測る）を選びました。設定 search_limits.json の stage_limits.stage2a.quantiles に9点を書くと、engine_tuner_gen.py の自己テストが落ちました。原因は、候補を作る関数 build_stage_candidates が、同じ材料の9本の候補に同じ順位を付けることです（T40②）。あわせて、9点と関係なく落ちていた3件（T23②・T42・T44）も、まこさんの「全部OK」で同じ工事で直します。3件の原因は、10/02〜03 に成績表を版3 の札で作り直して並びが変わったのに、自己テストの見本と測り方が前の並びに頼っていたことです。この工事は、候補の順位の付け方と自己テストを直すだけで、成績表・札・法則・測る道具の測り方は変えません。
