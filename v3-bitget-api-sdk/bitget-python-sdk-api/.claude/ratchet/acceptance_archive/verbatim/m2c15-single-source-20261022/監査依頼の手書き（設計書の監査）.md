## 工事ごとの問い
### Q8 — 役割の区分から札を決める対応は、教科書と R-1 の決定に合うか（優先度 A）
理由：対応を誤ると、全部の札が一度に誤る。札が役割と違うと、engine_tuner は指標を本来の役割と違う所で使う
対象の問い：2
この工事は、役割の区分から札を1対1で決めます（gen_indicator_table.py の CAT2LIN）。対応は、向き→トレンド・強さ→強さ・勢い→勢い・行き過ぎ→オシレーター・値動きの幅→ボラ・出来高→出来高・位置→構造・位置です。役割の区分が2つ以上の種類は、今の札に合う区分を選びます。
写しで数えた結果、札が変わる種類は 0 でした。
次の2つに答えてください。
1つ目に、この対応が、資料の表（indicator_roles_thresholds.json）と R-1 の札の正本（r1_role_map.json）の区分の使い方に合うかを答えてください。
2つ目に、区分が2つ以上の種類で「今の札に合う区分を選ぶ」決め方が、今の札の誤りを表の中に残してしまう恐れが在るかを答えてください。
