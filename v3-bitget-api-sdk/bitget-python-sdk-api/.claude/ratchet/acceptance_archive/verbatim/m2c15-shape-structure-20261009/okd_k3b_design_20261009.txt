**結論：道具の作りに効く点が3つあります。私の案で進めてよいかを教えてください。**

**1. 「山と谷を確定させる本数」は、名前に出さない引数にします**
- 教科書の版の3種（W字・S-Rタッチ・SMC_SWEEP）は、前後何本で山と谷を確定させるかの数（k）を新しく持ちます。
- k を名前に入れると、資料の行と軸の数が合わなくなります。それに、まこさんの「名前に値を入れて指標を増やさない」にも反します。
- ですから、名前に出さない引数にします。最初の値は 2 です。これは資料の fractal の既定 2 で、4つの出どころで ✅ になっている値です。
- 範囲で探すのは、工事2（M2-F-10b）の仕組みで行います。

**2. SMC_SWEEP の教科書の版は、ライブラリの数字（15本・ヒゲ1.5倍）を使いません**
- 教科書の形は「確定した山か谷をヒゲで抜けて、終値で戻した足」です（監査 CP60 の修正46・LuxAlgo の逐語）。ヒゲの倍率の条件はありません。
- K-3a と同じように元の行を写すと、使わない 15・1.5 が資料と設定に書かれてしまいます。
- ですから、資料の対応表（alias_map.json）に「パラメータは写さない」印を足します。印を読む資料の道具も直します。直す道具は .claude/state にあり、BOT の中身ではありません。

**3. 下半分位置を「使う」にするため、印を作る道具を直します**
- レンジ幾何の列の定義表（RANGE_GEO_REF）に、まこさんの決定を書く欄を足します。
- 印を作る gen_indicator_switch.py が、その欄を読んで「使う」に入れるようにします。
