### §1 概要

まこさんの要望「監査結果から直接自動生成で実装を修正できるようにしろ」に対し、当てる道具の --report の道の穴を塞ぐ。前の案（R-1〜R-3・commit 827bcbd）＝①使わなくなった元データの件で全件が止まる ②確かめのコマンドの多くを走らせない ③印の取り直しを走らせない。次の案（R-4〜R-7・監査 cp54 の C-1〜C-4）＝④gen_regime_kb.py --write を走らせない ⑤pre_audit_check.py --run を走らせない ⑥results の結果ファイルの rm を行わない ⑦新しいファイルの件が在ると全件が止まる。承認のプログラムは まこさんだけが打つので入れない。
