【4-0 この仕組みは何か】
当てる道具 apply_audit_fix.py の --design（設計書の実装の指示を実物に当てる口）を直し、設計書に書いた実装を、CC が Edit で書かずに道具が当てられる範囲を広げる。

2つ目＝hook と壊すプログラムにも、承認と TARGET／NEW_FILE がそろったときだけ当てられるようにする。

【4-1 システムの境界】

【4-4 処理の流れ】
