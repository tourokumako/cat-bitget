はい。計算できる形にします。1つの役割について、保有時間の下限と上限（本数）を入れると決まる定義です。5分足1本ごとに付けます。

見る過去の長さ。そのバーの前の、保有時間の上限の4倍から6倍の本数を見ます。4倍から6倍は法則 C4（上位足の比）から取ります。どの倍率にするかは範囲で試します。

山と谷の取り方。あるバーの高値が、その前後 m 本の中で最も高ければ、山とします。谷も同じです。m は、その役割の保有時間の下限から上限までの範囲で試します。

帯の上と下。上の線は、高さの差が手数料の床 0.08 パーセント以内にある山を1つにまとめた所です。下の線は谷で同じことをします。まとめた山が2つ以上あれば上の線が在るとし、谷も同じです。2か3かは範囲で試します。これが法則 R1 の跳ね返しの帯です。

幅。上の線と下の線の差を、そのバーの終値で割ります。これが 0.08 パーセント以上なら合格です。法則 R7 です。

続くこと。そのバーの次から、保有時間の上限の本数まで、全部の終値が上の線と下の線の間に在れば合格です。ヒゲではなく終値で見るのは、法則 R4 の注意（だましのヒゲ抜け）に従います。

3と4と5が全部 合格なら、そのバーは、その役割にとって「レンジだった」です。1つでも外れれば「レンジではなかった」です。

役割ごとの値は、スキャルが1本から12本、デイトレが12本から120本です。試す範囲は、倍率が4から6、m が下限から上限、山谷の数が2か3です。この3つの中でどれを使うかは、⑪タブで まこさんが見ることと、検査15 の片道の度合いで決めます。私は選びません。

出どころが無く、私が導いた所は2つです。山をまとめる幅に手数料の床を使うこと。続く長さを保有時間の上限と同じにすること。

受け取り方＝指示。範囲＝上の定義に出てくる数字（倍率・山谷の尺 m・山谷の数 c・手数料の床・保有時間の範囲）の全部。

守り方はこうします。

数字は全部、設定ファイルに置きます。コードには1つも書きません。役割ごとに、保有時間の下限と上限、倍率、m、c を持たせます。手数料の床は既存の定数を読みます。

札を作る道具は、その設定ファイルを読んで動きます。値を書き替えて走らせ直せば、札と⑪タブの版が作り直されます。

⑪タブの版の名前に、使った値を入れます。例として、役割がスキャルで倍率が4、m が6、c が2なら、その4つが名前に入ります。どの値で作った絵かが、名前だけで分かります。

設定ファイルの中身は、道具が画面の「仕様」にそのまま出します。手で書き写しません。

実際に売買した結果をみて、答え合わせに使う正解ラベルが不適切である場合に、修正しやすい状態にしておいたほうがいいよね。
はい。そのとおりです。理由も同じ見方です。正解ラベルが正しいかは、最後は M2-L で入口と出口を固定して売買し、net で見るまで分かりません。そこで外れていたら、札を直して段1から並べ直す必要があります。

直しやすい状態にするために、数字の設定ファイルだけでは足りない点が3つあります。

1つ目は、札の式そのものも差し替えられることです。数字を変えるだけでなく、定義の形（山谷の取り方や続くの見方）を変えても、同じ道具で作り直せるようにします。そのために、札の定義を版として持ちます。

2つ目は、札を作る場所を1つにすることです。いまは観察の道具の中にある式（先 n本の ER）を、⑪タブの道具と成績表の道具の両方が別々に呼んでいます。札を直したときに片方だけ変わる形は危ないので、6d で1か所にまとめます。これは観察の式に触るので、設計書と監査を通す仕事です。

3つ目は、どの版の札で作った成績表かを、成績表の側に残すことです。順位表と落ちた候補のファイルに、札の版の名前を書きます。売買結果を見て札を疑うときに、どの札で選んだ束かをたどれます。

いま作ってよいかを聞いていた道具は、この1つ目と3つ目を最初から入れた形にします。2つ目は 6d の設計書に書きます。
