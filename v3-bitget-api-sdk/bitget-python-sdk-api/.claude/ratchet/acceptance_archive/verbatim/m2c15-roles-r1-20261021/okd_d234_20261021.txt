**結論：20種全部に出どころの原文が見つかりました。逐語は22件とも、ページの本文と「一致」です。4つの条件で残った「怪しい」物は3種だけです。**

## 調べ方
- StockCharts の指標の一覧から、各指標の正しいページの住所を取りました。Gemini が書いた住所には、誤りがありました（Keltner・フィボナッチ）。
- ページを curl で直に取り出し、本文の中から役割の文を探しました。
- StockCharts に無い物は、TradingView のヘルプ（順位2）と Capital.com（順位4）で探しました。
- 最後に、照らしの道具と、4つの条件のプログラムにかけました。

## まだ残る3種（4つの条件に当たった物）
- TRIXヒスト・TRIX_EMAヒスト：出どころが Capital.com（順位4）だけです。原文は「プラスで広がっているときは、勢いが加速している」です。
- PSAR反転：原文は「値段のトレンドが反転したときに、SAR も反転する」です。向きの語（uptrend など）が文に無いので、条件4 に当たりました。

## 決めていただくこと（3つ）
1. **close vs 〜% の26種の札**：私の勧めはア（オシレーター＝行き過ぎ）です。理由は前の返信に書いたとおりです。
2. **「その他」になった6種の札**：シグナル線4種の原文は、「元の指標の反転や交差を見つける線」です。経過バー2種の原文は、「トレンドが出ているか、横ばいかを見分ける」です。どちらも、7つの区分のどれにも当たりません。私の勧めは、シグナル線は元の指標と同じ札にすることです（MACD・TRIX・TSI のシグナル線は「勢い」になります）。経過バーは、「トレンドが出ているか」を見るので「強さ」にすることです。ただし、どちらの勧めも、原文から推し量った物です。
3. **残る3種**：Capital.com（順位4）だけの2種と、PSAR反転を、この原文のまま採ってよいですか。
