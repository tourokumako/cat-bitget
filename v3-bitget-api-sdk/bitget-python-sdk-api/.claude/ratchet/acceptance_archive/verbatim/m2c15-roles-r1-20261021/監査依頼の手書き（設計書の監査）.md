## 工事ごとの問い
### Q8 — 食い違う疑いの64種と、D6 で札を変える22種の札は、出どころの原文に合うか（優先度 A）
理由：札が教科書の役割と違うと、engine_tuner が指標を本来の役割と違う所で使う。これは、要件定義の3番の5（4つが、それぞれの役割に沿って使われている）に反する
対象の問い：2
この工事は、88種の札を、r1_role_map.md の「新しい系統」のとおりに直します。88種は、食い違う疑いの64種と、決定 D6 で足した24種です。変える札は76種で、変えない札は12種です。
64種は、変える54種と、変えない10種に分かれます。24種は、変える22種と、変えない2種に分かれます。
この問いでは、64種の全部と、D6 で札を変える22種を確かめてください。合わせて86種です。
変える札は、次の4つの群に分かれます。
- 1つ目の群は、終値と線の離れ（close vs 〜%）の47種と、Keltner上・下です。この群は、オシレーター（行き過ぎ）の札になります。出どころは、StockCharts の Distance From MA のページです。
- 2つ目の群は、ADX・CHOP・ER・VHF・MMI と、高値と安値からの経過バーの2種です。この群は、強さの札になります。
- 3つ目の群は、MACD の3種・PPO の3種・KST の2種・TRIX の5種・AO%・STCstoch・TSIヒストです。この群は、勢いの札になります。
- 4つ目の群は、ABER の3種（ボラ）と、PSAR反転（トレンド）です。
64種のうち札を変えない10種は、5つ目の群です。
- 5つ目の群は、DI差・TSI・TSIシグナル（トレンドのまま）と、Donchian幅（ボラのまま）と、n本高値・n本安値・fib位置・S-Rタッチ1時間ATR・S-Rタッチ確定1時間ATR（構造・位置のまま）と、HT_DCPHASE（構造・位置のまま）です。HT_DCPHASE は、調べた役割が7つの区分のどれにも当たらないため、決定 D5 で今の札のままにしました（やらないことの Y-4）。
出どころの原文は、r1_role_map.md の出どころの欄ごとに、次のファイルに在ります。「CC の調べ」は cc_ans04.json、「D6」は cc_ans05.json、「Gemini」は ans03_b.json、「D2」は chrome_ans02_a1.json、「係の調べ」は research/out_w1〜4.json です。
1つ目〜4つ目の群では、出どころの原文が、新しい札を支えるかを答えてください。
5つ目の群では、出どころの原文が、今の札のままにすることを支えるかを答えてください。
支えない札があれば、種類の名前と理由を書いてください。

### Q9 — 型の表と出口の枝に強さ・勢いを足す形は、法則に合うか（優先度 A）
理由：足し方を誤ると、engine_tuner が同じことを見る指標を重ねて使うか、使えるはずの指標を使えなくなる。どちらも、net 利益を最大にするロジックを見つける力を下げる
対象の問い：2
この工事は、型の表の環境（env）に強さと勢いを足し、十分さ（sufficiency）に強さを足します（実装28〜31）。出口の枝 REVERSE_IND と BREAKOUT の使える系統には、強さと勢いを足します（実装32〜35）。合図（trigger）と場所（location）には足しません。
直す前は、ADX と MACD線% は、どちらもトレンドの札でした。そのため、決まり G3 は、この2つを同じ環境の役割に置かせませんでした。直した後は、この2つは強さと勢いの別の札になります。そのため、環境の役割に、ADX と MACD線% と EMA傾き（トレンド）を一緒に置けるようになります。
次の2つに答えてください。
1つ目に、この変化が、法則 C2（同じ問いに答える指標を重ねて使わない）と R2（補助は違う系統から選ぶ）に合うかを答えてください。
2つ目に、足す役割と足さない役割の分け方が、型の表の役割ごとの出典の文（gen_signal_families.py の 229〜265 行）に合うかを答えてください。

### Q10 — 終値と線の離れをオシレーターにしたときの使われ方は、正しいか（優先度 A）
理由：使われ方が教科書と違うと、engine_tuner が誤った向きで閾値を引く。また、§2.2 の段1 の候補が減り、レンジの判定が弱くなるおそれがある
対象の問い：2
