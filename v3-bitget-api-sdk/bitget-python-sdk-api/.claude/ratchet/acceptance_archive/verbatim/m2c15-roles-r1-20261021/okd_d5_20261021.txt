**一覧を作るときに直した誤り（1件）**
最初の一覧では、名前の頭が「close vs」の物を全部オシレーターにしていました。そのため、決めていただいた26種の外にある close vs ABER_ZG% まで、オシレーターになっていました。この指標は、係の調べで「値動きの幅」と確かめられていた物です。決定の26種だけに当てるように直し、26種であることも確かめました。close vs ABER_ZG% は、係の調べのとおり「ボラ」にしました。

## 決めていただくこと：未決の3種

**1. Keltner上・Keltner下**（今は構造・位置）
- この2種は、「終値がケルトナーの帯から何%離れているか」を測ります。
- StockCharts の原文は2つあります。1つは「横ばいのとき、帯で行き過ぎを見る」（行き過ぎ）です。もう1つは「帯を抜けたら、トレンドの始まりかもしれない」（向き）です。
- 私の勧めは、オシレーター（行き過ぎ）です。これは、close vs 〜% と同じ「線からの離れ」を測る値なので、先の決定とそろえるためです。

**2. HT_DCPHASE**（今は構造・位置）
- 係の調べの原文は、「支配的な相場のサイクルの、今の位相（角度）」です（TA-Lib の説明）。7つの区分のどれにも当たりません。
- 私の勧めは、今の構造・位置のまま変えないことです。新しい区分を足すと、私が自分で決まりを作ることになるためです。

この2つも、私の勧めでよろしいですか。
