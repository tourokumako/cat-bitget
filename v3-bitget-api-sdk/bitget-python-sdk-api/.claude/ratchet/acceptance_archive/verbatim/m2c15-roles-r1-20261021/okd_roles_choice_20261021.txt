## 前提：R-1 は何をする工事か

- 指標には、1つずつ「系統」という札が付いています。札の種類は8つです。例えば、RSI には「オシレーター」、ADX には「トレンド」の札が付いています。
- engine_tuner は、この札を見て条件を組みます。例えば、「入る合図には、オシレーターの札の指標を使う」という決まりがあります。「同じ札の指標を2本重ねない」という決まりもあります。
- 教科書で調べた役割と、この札が合わない指標が、64種あります。
- R-1 は、この札を教科書どおりに直す工事です。

直し方を決めようとしたところ、私だけでは決められない所が3つ見つかりました。

## 1つ目：教科書の役割の名前に、合う札が無い

- 例は CHOP です。教科書は CHOP について、「トレンドがあるかどうか（強さ）を測る。向きは見ない」と書いています。
- ところが、札の8種類の中に「強さ」がありません。そのため今は、「ボラ（値動きの大きさ）」の札が付いています。
- 同じように、教科書が「勢い」と書く KST や PPO にも、合う札がありません。
- 選べる道は2つです。
  - ア：札の種類に「強さ」と「勢い」を足す。
  - イ：札は8種類のままにして、近い札に寄せる。
- 私の勧めはアです。法則 R2 の原文が、「トレンドの強さ」と「値動きの大きさ」を別の物として書いているからです。

## 2つ目：教科書を調べた相手が、うちの指標と違う

- 例は close vs RMA% です。この指標は、「終値が、移動平均の線からどれだけ離れているか」を測ります。
- ところが、教科書を調べた係は、移動平均の線そのものを調べていました。線そのものは「向き」を見る物です。そのため、一覧は「向き」の札にせよと言っています。
- つまり、一覧の答えは、うちの指標の答えではない恐れがあります。このような指標が16種あります。
- 選べる道は2つです。
  - ア：一覧のとおりに、16種を「トレンド」の札に直す。
  - イ：「終値が線からどれだけ離れているか」の役割として、係に調べ直させてから直す。
- 私の勧めはイです。

## 3つ目：「疑い」の34種は、調べ方が粗い

- 一覧の「疑い」は、教科書のページに出てくる単語の数を数えただけの印です。
- 例は DI差 です。DI差 は、トレンドの向きを見る指標です。ところが、ADX のページの単語を数えたので、一覧は「強さ」と言っています。
- 選べる道は2つです。
  - ア：単語の数のとおりに直す。
  - イ：係に役割を調べ直させてから直す。
- 私の勧めはイです。2つ目のイと合わせて、50種を1回で調べます。費用は多くて約37万トークンの見込みです。前回は70種を約52万トークンで調べました。
