23種と MMI の役割を、指定いただいた方法で調べ直しました。逐語53件は、ページを開き直して照らした結果、全部「一致」でした。調べた結果、さきほどの勧めのうち、加速バンドの2種だけを変えます。

## 調べ方
- StockCharts の指標の一覧から住所を取り、関わる12ページを curl で取り出しました（全部取れました）。
- 加速バンドは StockCharts に無いので、前回の調べで使った5つのページを curl で取り出しました（全部取れました）。
- MMI の開発者のページは、curl では30秒で切れ、Chrome でも開けませんでした。そのため、web.archive.org にある 2024-11-02 の写しを curl で取りました。
- 結果のファイルは [cc_ans05.json](.claude/state/indicator_review/gemini_r1/cc_ans05.json) です。照らしの道具（verify_quotes_w.py）は、53件とも「一致」と判定しました。

## 分かったこと

**1. 移動平均との離れ（21種）**
- 共通の原文は、前回と同じ StockCharts の Distance From MA のページです。原文は「ゼロの線の上下の extreme values を探す」と「式は移動平均の種類を問わない」です。D2 と同じく、行き過ぎにあたります。
- 線ごとのページがあったのは3種だけです。
  - SMA・EMA のページは、移動平均を「トレンドの向き」と「支持線・抵抗線」に使う、と書いています。
  - HMA のページは、「終値が線を上に抜けたら買い」と書いています（向き）。
- ほかの18種には、StockCharts のページがありません。

**2. 加速バンドとの離れ（2種）**：勧めを変えます
- 開発者 Headley の説明は、「帯の外への抜けを見る」（向き）と「短い時間足では、帯が支持線・抵抗線になる」（位置）です。
- LuxAlgo は、加速バンドを、行き過ぎと読むボリンジャーバンドと比べています。そのうえで、加速バンドは「抜けた向きに乗るために作られた」と書いています。
- つまり、加速バンドは行き過ぎの指標ではありません。今の札（構造・位置）は出どころに入っているので、**変えない**を勧めます。

**3. MMI**：調べた結果、強さです
- 開発者は、MMI を「値動きの幅（volatility）やトレンドから作った物ではない」と書いています。
- また、「MMI が下がると、トレンドが近い」と書いています。
- つまり、MMI が見ているのはトレンドの局面かどうかで、CHOP・ER と同じ「強さ」です。**強さに変える**を勧めます。

**4. 決まった D2 に関わる事実（お伝えだけです）**
- D2 の26種に入っている KAMA のページは、「終値が KAMA より上なら上げのトレンド」と書いています（向き）。
- 一方、線形回帰のページは、「上下への行き過ぎを見る」と書いています（行き過ぎ）。
- つまり、離れの値の符号は向きを表し、大きさは行き過ぎを表す、と読める原文が両方あります。D2 を変えるお願いではありません。

**機械の判定について**
- 4つの条件の道具（r1_gemini_check.py）は、24種とも「怪しい」と判定しました。
- 理由の1つ目は④です。行き過ぎの語の決まりは overbought と oversold だけで、Distance From MA の原文の語は extreme だからです。これは D2 のときと同じです。
- 理由の2つ目は③です。加速バンドと MMI の出どころが、順位4のページだけだからです。

## 決めていただくこと（勧めを直した版）
1. 移動平均との離れの21種：ア（D2 と同じオシレーター）を勧めます。
2. 加速バンドとの離れの2種：今の構造・位置のまま、変えないことを勧めます。
3. MMI：強さに変えることを勧めます。

この勧めでよろしければ、札を変える指標は54種から76種になります（54＋21＋MMI の1）。経緯は [worklog 20261022 §1](.claude/state/session_worklog_20261022.md) に書きました。
