## A. これは何か（1行）
v5 の検出器ゲート（結果ベース教師・2603特徴・purged CV・OOF 測定系）はそのまま、**①一次イベントを5型（異手法）に拡大して検出器に「稼げる場面か」を判定させ、②θ 選定規則を「be≥1.0 を満たす分位のうち頻度最大」に反転**して、手数料超え帯の絶対頻度をスキャル床（≥3件/日）以上に育てる。

## B. 深掘り4点
### ① 真因
v5 の θ 選定規則「頻度床5イベント/日の中で be 最大」が赤字帯（q0.8・OOF be0.569）を強制選択した。検出器の較正は正（OOF 分位で be 単調増・逆較正なし）＝分離は本物。手数料超え帯（top10% be1.01/3.7イベント日）は実在するが、現行イベント定義（dev_z±1.0σ∩反転バー・41候補/日）の母数では頻度と両立しない。＝**頻度と手数料超えの両立は θ では解けず、イベント母数側で解く**（ledger ARC18 問4）。

### ② 期待値分解
- be（平均gross÷往復コスト）: 学習窓 0.55 から **≥1.0 へ**（θ が be≥1.0 帯に立つ＝定義上の黒字分岐超え）。
- 件数/日: 採点窓 2.25 から **≥3（スキャル床）かつ v5 超えへ**。母数拡大（41候補/日 から 複数型で2〜3倍へ）× be≥1.0 帯の分位選定で、be≥1.0 帯の絶対イベント頻度を床以上に。
- 勝率: 必要 57.5% に対し実 53.7%（不足 3.8pt）。be≥1.0 帯は OOF win_rate 0.613（q0.9）＝帯選定で不足を埋める構図。

### ③ root か symptom か
**root**。SL 出血（−$2,136）・手数料負け（$463）・低ATR薄利帯（−$387）の3系統は「赤字帯 θ が薄利イベントを通した」に収束（analysis_block STEP3）。θ 規則の向きとイベント供給を直すのが根。個別帯の手動カット（symptom 患い）はしない＝線引きは検出器（木）に判定させる。

### ④ ベースアップ（2026-07-03 実施・検索3本/種別3/精読2本）
- **イベントベースサンプリング（Hudson&Thames・AFML Ch.2）**: 「全時点をラベルするのでなく、イベントを ML の入力にする」が業界標準。イベント抽出閾値は「高い＝情報価値高いが訓練データ減／低い＝イベント増だが予測力低下」のトレードオフ＝**イベントは広めに取り、検出器（メタ層）に判定させる**のが本設計と整合。https://hudsonthames.org/machine-learning-trading-essentials-part-2-fractionally-differentiated-features-filtering-and-labelling/
- **メタラベリング（Hudson&Thames・Joubert SSRN 4032018）**: プライマリ（向き・イベント）は多様なルール系でよく、セカンダリ（検出器）が「取るか取らないか」を判定して precision を上げる二層構造。プライマリを複数の発生源（異手法イベント型）にしても、セカンダリの特徴にシグナル文脈（event_type・RSI・ボラ・モメンタム）を渡せば1本のセカンダリで扱える。https://hudsonthames.org/does-meta-labeling-add-to-signal-efficacy-triple-barrier-method/
- **スキャルの頻度とコスト（QuantifiedStrategies）**: 「期待値が取引コストを超える時だけ執行」の向きで入る条件を置くのが定石＝be≥1.0 優先の規則反転と整合。https://www.quantifiedstrategies.com/scalping-trading-strategies/
