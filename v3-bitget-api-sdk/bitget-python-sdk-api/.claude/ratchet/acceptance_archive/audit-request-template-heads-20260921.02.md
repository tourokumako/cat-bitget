## 1｜概要

監査の依頼書を作る古い方の道具（`scripts/priority_rebuild/gen_audit_request.py`）が、いまのテンプレ（`_template.md`）を読めるようにします。この道具は、テンプレの見出しを一覧（`SECTION_KIND`）で持ち、一覧に無い見出しがテンプレに在ると止まる作りです。2026-09-15 に、テンプレへ見出しを2つ足しました（「この監査で答えてほしいこと」「依頼を出した CC の自己申告」）。そのとき この道具を直さなかったので、自己テストが1件 落ちたままです。監査に出す前のチェック（`pre_audit_check.py`）はこの自己テストを必ず走らせるので、チェックが通らず、監査の依頼書を置き場（inputs）に1本も作れない状態が続いています。直すことは3つです。1つ目は、一覧に見出しを2つ足すことです。2つ目は、その2つの節の埋め方を決めることです。どちらの節も、依頼を出す側が書く文なので、この道具の決まり（依頼を出す側が文を書けるのは凍結ファイルの中だけ）に合わせて、凍結ファイルから写す形にします。凍結ファイルにその節が無いときは、依頼書を作らずに、足りない節の名前を出して止まります。3つ目は、自己テストを、この形を測れるように直すことです。本物の凍結ファイル（`_frozen_question_regime.md`）は、まこさんが承認した文なので触りません。
