## やること（4つのまとまり）

### A｜否定（not）を足す — 法則 R8

**足すもの**＝条件の木の節に `{"not": <ノード>}` を1つ。入口の木と、場面の判定（build）の木の両方で使えるようにします。

**★禁止を2つ、同時に入れます**（これを入れないと、いまの決まりの意味が壊れます）。

| # | 禁止 | なぜ |
|---|---|---|
| 1 | **`not` の中に「建てる合図（trigger）の役割の条件」を置けない** | 合図は「縁で発火する」ものです。反転すると「発火していない全部のバー」が真になり、**経路ごとに合図はちょうど1本（G1）**の意味が壊れます |
| 2 | **`not` の入れ子は1段まで**（`not` の中に `not` を置けない） | 二重の否定は元の条件と同じ＝形を1つに決めます（入れ子の本数 1 を禁じている既存の決まりと同じ考え方） |

**★欠損の扱いを、設計で決めます。**`not` は真偽の反転です。**内側の条件が「値が無いので不成立」としたバーは、反転すると成立になります。**
これを避けるため、**案を作るプログラムは `not` の内側の条件に「値が無いバーは成立とみなす」（`na: "pass"`）を必ず付けます。**＝反転したあとは不成立になります。
**この決まりが効いていることを、わざと外した入力で確かめます。**

### B｜状態を保つ形を足す — 法則 U10・C6・C7

**足すもの**＝形を1つ。名前は `hysteresis`（日本語＝**入る線と出る線を別にして、状態を保つ形**）。
**★名前の出どころ**＝知識の正本の逐語「Use hysteresis. Entry threshold: P(Bear) > 0.6. Exit threshold: P(Bear) < 0.4.」。私が作った造語ではありません。

```json
{"form": "hysteresis",
 "on":  { …条件または木… },
 "off": { …条件または木… },
 "value": {"n": 288}}
```

| 欄 | 意味 |
|---|---|
| `on` | この条件が成立したバーから、真になります |
| `off` | この条件が成立したバーで、偽に戻ります |
| （どちらも成立しないバー） | **前のバーの値を保ちます**（＝状態を保つ） |
| `value.n` | 真を保つ最大の本数。ここを超えたら自動で偽に戻ります |

**★これが「入る線と出る線を別にする」です。**`on` と `off` に別の閾値を書けます（例＝ADX が上から70%の所を超えたら入り、下から40%の所を割るまで出ない）。
**★`value.n` が「状態が続く長さ」です。範囲で探します**（C7）。過去に14版を凍結した理由の3つ目＝「判定は16〜28時間 続くのに、取引は中央値15分」は、この長さを調整する仕組みが無かったことでした。

**★既存の `streak`（何本 続いたら成立）とは別物です。混ぜません**（C6＝安定させる仕組みは2つ・別のもの）。

**★未来を見ません。**前から1バーずつ、その時点までの値だけで決めます。

**★形を足すときに触る所（46回目に分かった決まり）**

### B-2｜状態に入って以降を見る前処理を足す — 実例の9番・11番

| 名前 | 中身 |

### C｜帯を作れるようにする — 法則 R1・C10 の②

**3つに分けます。**

**C-1｜山と谷を確定させる部品を足す**（`observe_config.json`・`observe_diag.py`・`indicator_reference_diag.py`）

| 部品の名前 | 中身 |
|---|---|
| `fractal高値距離%(k)` | 中央のバーが前後 k本 より高いとき、そこを山とします。**k本 遅らせて確定します。**列の値＝いまの終値と、直近で確定した山との差（%） |
| `fractal安値距離%(k)` | 同じく谷 |

**★k本 遅らせて確定するのが、未来を見ないための作りです**（C10 の②）。実例の「j+2 確定」がこの形です。
**★列は%で持ちます**（値段そのものを持ちません＝H6）。
**★k は範囲で探します。**

**C-2｜帯の窓と幅を、決まった数字から範囲に変える**

`S-Rタッチ数(窓,幅)` は、参照表では**数字2つを受ける型**です。いま設定に入っているのは窓 288・幅 0.003 の1組だけです。

**C-3｜他の材料に連動する閾値を足す**（値の書き方に1区分）

```json
{"ref": {"family": "ATR%", "param": 14, "tf": "1h"},
 "mult": {"threshold_q": 50},
 "clip_lo": {"const": "…"}, "clip_hi": {"const": "…"}}
```

**意味**＝閾値を、別の材料の列に係数を掛けたものにします。下限と上限で挟みます。
**＝1バーごとに動く閾値です。**実例の「価格帯 clamp(0.5×ATR%_1h, 0.15%, 0.6%)」がこの形です。
