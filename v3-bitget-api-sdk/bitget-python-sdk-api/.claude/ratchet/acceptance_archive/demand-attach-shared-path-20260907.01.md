## 2. なぜ作るか（実測）

**実測（2026-09-07・H2 の印を取り直したときの出力）**＝種を固定した生成の案3本のうち、**2本が突き合わせの対象外**になりました。逐語は「両方 走れない（同じ理由）＝突き合わせ対象外: 走れない（RecipeError: [実行器] 需給の列が実行データに無い: L-S比）」です。**＝H2 の生成の道の見張りが 3本 → 1本 に薄くなりました。**その数字を出したコマンドは `python3 scripts/priority_rebuild/leak_causality_diag.py` です。

**原因**＝需給の列を載せる関数 `_attach_demand` を呼んでいるのは、`engine_tuner_gen.py`:3434（`run_generation` の中）の1か所だけです。実行器の共通の道 `engine_tuner_exec.attach_recipe_columns`（:3089）には入っていません。

**共通の道を呼んでいる所は5か所です**（`grep -rn "attach_recipe_columns"` で数えた実測）。`engine_tuner_exec.py` の2か所（:3190・:3462）、`leak_causality_diag.py` の2か所（:347・:442）、`tuner_adapters/e37.py` の1か所（:289）です。**共通の道に入れれば、5か所ぜんぶが同じように動きます。**

**なぜ私が作った穴か**＝2026-09-06 の cp24 の直し（需給の部品を足す）で、本走が落ちないことだけを確かめ、**本走の外の道を1つも確かめませんでした。**
