| # | 理由 |
|---|---|
| 1 | **`--approve` が最初に `verify()` を呼びます。**＝まこさんが型の表を承認する操作の中で、必ず通る道です（「型の表を触る前に効かせる」の実体） |

**中身**

1. `verify()` の最後（`✅` を印字する直前）で `g2_selftest()` を呼びます。
2. **ただし、表が未承認のときは走らせません。**`_table_status()` が False を返したら、G2 を飛ばして「表が未承認なので G2 は走らせていない（承認のあと `--verify` で走ります）」と印字します。
3. G2 が落ちたら（`SystemExit`）、`--verify` は ✅ を出さずに落ちます。理由の文をそのまま出します。

**★2番（未承認のときは飛ばす）を入れる理由＝入れないと行き止まりになります。**
G2 は本物の案を作って試します。案を作るには承認済みの表が要ります（`engine_tuner_gen.py`:576 が fail-closed で止める）。
**表を作り直した直後は必ず未承認です。**そこで `--approve` を打つと、その中の `verify()` が G2 を呼び、G2 は「表が未承認」で落ちます。
**＝まこさんが二度と承認できなくなります。**だから、未承認のときは飛ばします。
