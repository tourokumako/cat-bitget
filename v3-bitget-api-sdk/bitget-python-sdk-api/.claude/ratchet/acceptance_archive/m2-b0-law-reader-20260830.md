## 1｜何を作るか（1つだけ）

**場面の審査（G7＝`_check_scene_rules`）を、法則の正本 `.claude/ratchet/regime_laws.json` を読み込んで審査する形に直す。**

### （a）法則7件に「機械が読む判定」を足す

対象＝いまの審査と同じ7件（承認済みの対応表 milestones2 0-6 のとおり）。**法則の一文・説明・出どころは1文字も変えない。鍵を1つ足すだけ。**

| 法則 | 掛かる場面 | 型 | 中身 |
|---|---|---|---|
| C1（旧 K-1） | uptrend・downtrend | 部品を数える | 向きを持つ部品を1本以上（向きを持たない一覧＝型の表 signal_families.json の bans を引く） |
| C4（旧 K-2） | range・uptrend・downtrend | 部品を数える | 執行足（5m）より上の時間足の部品を1本以上 |
| C6（旧 K-3） | range・uptrend・downtrend | 形を持つ | hysteresis（成立と解除を別々に持つ形）を1つ以上 |
| R1（旧 K-4） | range | 部品を数える | 系統「構造・位置」の部品 か geo の部品を1本以上 |
| R8（旧 K-5） | range | 形を持つ | not（否定）を1つ以上 |
| R7（旧 K-6） | range | 部品を数える | 幅の部品を1本以上（geo＝W% ／ family＝BB幅・Donchian幅・HWC幅%） |
| S1（旧 K-7） | spike | 部品を数える | 「いまの値動き ÷ ふだんの揺れ」の比の family を1本以上（★一覧は空＝いまは満たせない・部品は M2-C で足す） |

**判定の型は2つだけ**＝「部品を数える」（束の中に、条件に合う部品が n本以上あるか）／「形を持つ」（束の中に hysteresis や not の形があるか）。**新しい型（系統の重複・弱い側・続く長さなど）は M2-B で法則を足すときに増やす**（増やせる作りにしておく）。

### （b）語彙（何がその部品に当たるか）の置き場所

- **幅・比の一覧**＝法則の側（R7・S1 の「機械が読む判定」の中）へ移す。**理由**＝「何を幅と数えるか」はその法則の意味そのものだから。いまはコードの定数（`_WIDTH_GEO`・`_WIDTH_FAMILIES`・`_SPIKE_RATIO_FAMILIES`）。
- **向きを持たない部品の一覧**＝いまのまま型の表（signal_families.json の bans）から引く。**理由**＝部品そのものの性質で、法則ごとに変わらないから。

## 2｜なぜ作るか（深掘り4点）

### ① 真因

**法則の判定が実行するプログラムに直書きで、法則のファイルは「開けるか」しか確かめられていない**（`engine_tuner_gen.py`:2188 が返り値を捨てている・判定の実体は `engine_tuner_exec.py`:1094-1119）。だから法則を足しても書き替えても、動きが変わらない。**「設定に書いてあるのに効いていない」（違反の記録 #25 の型）がまた起きる素地でもある。**

### ② 期待値分解（勝率／平均利益／敗率／平均損失）

**非該当。この直しは売買を1本も出さない。**net への効き方は間接＝法則 → 審査 → 場面の判定の質 → 入口の選別 → net。

### ③ root か symptom か

**root。**M2-B（法則を読み込ませる）・M2-C（部品）・M2-E（法則から組ませる）の全部が、この読み込みの上に乗る。ここを直さずに先へ進むと、足した法則が全部 飾りになる。

### ④ ベースアップ（この設計の前に開いたもの）

**外の新しい検索は使っていない。この設計の材料は全部 実物**＝`engine_tuner_exec.py`（1031-1119・4183-4208・語彙の定数 1003-1028）／`engine_tuner_gen.py`（1179-1198・2179-2216）／`regime_laws.json`（法則50件の形・R1 の実物）／`regime_detection_kb.md` の 11-2（R1〜R10）／`leak_causality_diag.py`（238-252）／`gen_composition_rules.py`（139・166-201・306-371）。法則の意味の出どころ＝composition_rules_src.json の出典の欄（StockCharts・LuxAlgo・range_scalping_kb の逐語）。
