## 1｜概要

［手書き］やることの表の「§1 概要」
指標の系統の札が教科書の役割と合っていない指標が64種と、同じ作りなのに役割を調べていなかった指標が24種あるので、出どころの役割を調べ直し、その役割のとおりに札を直します。

系統の札は、engine_tuner が「この役割の条件には、この系統の指標を使う」と材料を選ぶときに読みます（型の表の役割ごとの系統・出口の枝の使える系統・G3・法則 R2）。札が誤っていると、engine_tuner は教科書の役割と違う使い方で条件を組みます。これは、機能要件の5番「4つが、それぞれの役割に沿って使われている」に反します。

いまの札は8つの区分で、教科書の役割の「強さ」と「勢い」に当たる区分がありません。また、64種のうち50種は、前の調べが別の物を調べていた（close vs 移動平均の16種）か、ページの語を数えただけ（疑いの34種）でした。そこで、50種を Gemini と CC で調べ直し、逐語をページと照らしました。さらに、64種の外で同じ作りの24種（印が付かなかった、移動平均との離れ21種・加速バンドとの離れ2種と、注記が CHOP・ER と同じ物差しと書く MMI）を、StockCharts ほかのページを curl で取り出して調べ直しました（D6）。設計書の監査 CP85 で、同じ量なのに札が割れる2種（AROONU・AROOND）と、札を直すとオン・オフの印から落ちる34種が見つかりました。まこさんの決定 D7 と決定アを足しました（D7＝ABER の3種はオシレーター・止める線との離れ7種は今の構造・位置のまま・AROONU・AROOND は強さ・TSI は勢い）。
