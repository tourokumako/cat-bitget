## 2｜何を作るか

### 2.1 `.claude/tools/pre_audit_check.py`（新設・部品1）

| 口 | 何をするか |
|---|---|
| `--run` | 上の1〜6を**その順番で**走らせ、続けて全部の `--verify` と `--selftest` を走らせて、結果を `.claude/state/pre_audit_check.json` に書く。★**`--approve` が要るもの（1・2）は打たない**＝「まこさんの承認が要る」と画面に出して止める |

**json に書くもの**＝走らせたコマンド／その rc／走らせた時刻／**そのとき見ていたコードの指紋**（H2 の印と同じ作り方＝対象ファイルの内容から作る）。

### 2.2 `.claude/hooks/require_acceptance_before_impl.sh`（部品2）

**474-486行の依頼書ゲートに、判定を1つ足す。**いまの判定（設計書の指紋と承認の照合）はそのまま残す。

足す判定＝`.claude/audits/inputs/*.md` を Write するとき、`pre_audit_check.py --verify` が rc=0 でなければ止める。

**止めるときに画面へ出すもの**＝どの検査が rc≠0 か／`--run` の打ち方。
