## 1｜何を作るか（1つだけ）

**observe_diag.py に「検査15」を1つ足す。読むだけ。売買記録も採点も出さない。**

いまの正解の印が「レンジだった」と札を付けた区間について、**別の物差しで測り直して、食い違いの量を数える。**

| | 中身 |
|---|---|
| **分子** | 区間の始まりと終わりの価格差の絶対値＝`abs(close[i+n] - close[i])` |
| **分母** | その区間の値幅＝`max(high[i..i+n]) - min(low[i..i+n])`（★**始まりのバー i を含める**。分子が i から i+n の n+1本ぶんを見ているので、分母も同じ範囲にしないと比が 1 を超える＝一直線の区間で 1.333 になる。**2026-08-29 に実装と設計書の食い違いとして見つけ、まこさん指示「書き直していい」で直した**） |
| **比** | 0 〜 1。0 に近いほど行って戻った／1 に近いほど片道 |

**いまの印との違いは分母だけ。**いまの印の分母は「歩いた距離の合計」（observe_diag.py:5447）で、細かく揺れるほど分母が増えて値が下がる。＝荒れているだけの区間も「レンジ」に入る。
