## 7｜付録（hook が求める項目）

### 7-1 深掘り4点

**① 真因（root cause）**＝2つです。①前処理 abs を足したとき（2026-09-11）、前処理を使う全部の関数（名前を作る・値を計算する・解決表の鍵を作る）を洗い出さず、鍵を作る関数を直し忘れました。自己テストが解決表の鍵を作らない形だったので、98回目に実際の束へ abs が付くまで表に出ませんでした。さらに 98回目の私は、完成の条件 #7（`--build 3`）を誰も走らせていないのに「走らせた」と書きました。②Major 7件の多くは「設定・法則・宣言を書く場所は作ったが、読む側・照らす側を作っていない」型です（stage_limits を読まない／C4 を読まない／EXPECT_MSG を正常な出力と照らさない）。書く場所と読む場所が別々に作られ、つながっていることを測る自己テストがありませんでした。

**② 期待値分解**＝売買のロジックには触れません。勝率・平均利益・敗率・平均損失は、この工事だけでは動きません。動くのは5つです。①R9 の診断が走る種の数（0 → 全部）②設定の欄と法則を書き替えたときに候補と束が変わることを、機械で測っているか（C4・R3・stage_limits＝測っていない → T24⑤・T43 が測る）③壊すプログラムの照合が、落ちた行だけを見るか（12本 → 0本の弱い宣言）④段2c の候補に5分足が入る ⑤測れない束を rc=0 で通すか（通す → rc=1）。
