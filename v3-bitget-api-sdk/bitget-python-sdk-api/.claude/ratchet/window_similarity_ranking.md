## 抽出方法（再現可能・スクリプト＝scripts/priority_rebuild/window_similarity.py）

- 基準＝採点窓（periods.py 正本・SCORE_START〜SCORE_END）の5分足から構造特徴15個を計算し、全期間を採点窓と同じ4ヶ月幅×1ヶ月刻みの候補窓（採点窓と非重複）でスライドして同じ15個を計算。候補窓分布で z-score 標準化したユークリッド距離の昇順。
- 特徴15個＝E38/E37 のツマミが参照する次元に対応: ボラ（ATR%14中央/裾q90・実現ボラ20中央・日次値幅%中央）／レンジ性（RG-v6 レンジ滞在率・uptrend率・ADX14_1h中央・1hリターン自己相関）／レンジ幅（帯対幅W%中央）／急騰性（DI差14裾q90・基準線乖離26裾q95・+0.5%足/日・5分リターン尖度）／方向（月次リターン%・陽線日比率）。
- レンジ判定は採用構成と同じ RG-v6（adaptive_k=V25_K）を import 再利用。全て確定バーのみ（H2）・**戦略の成績（net）は一切使わない**・金額不使用。
- ⚠️ 限界: 構造の近さもツマミ移転の保証ではない（あたり付け）。窓の決定はまこさんのみ。最終確認は選んだ窓の前半探索→後半確認の実測。
- 再生成: `cd scripts/priority_rebuild && python3 window_similarity.py`（全期間ロード込み 数分・採点窓が変われば periods.py に自動追従・窓幅は GRID_MONTHS）。
