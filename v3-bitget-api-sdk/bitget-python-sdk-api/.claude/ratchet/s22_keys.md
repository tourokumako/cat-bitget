# 束が使う「分位の鍵」は、どれだけ重なるか

**★この表はプログラムが作ります（手で書き換えない）。**出どころ＝`gen_s22_fidelity.py --keys N` の実測。

**なぜ在るか**＝束1本を測る時間の**99%**は、「その分位が実際にいくつか」を計算する所に行っています（`s22_breakdown.md`）。**その計算は鍵ごとに1回で済みます。**いまは束を1本ずつ渡しているので、同じ鍵を何度も計算し直しています。

**測った束＝50 本**（頼んだ 50 本・種 7・組めなかった案 13 件）

| 何 | 数 |
|---|---|
| 束1本が使う鍵（平均） | **7.6** |
| 1本ずつ渡したときの合計（いまの形） | **382** |
| まとめて渡したときの種類（重複を除く） | **251** |
| **減る割合** | **34.3%** |

## 時間に直すと

**★1つの鍵を計算する時間**＝`s22_breakdown.md` の実測（束1本 2.77秒）を、束1本が使う鍵の数（7.6）で割って **約 0.36 秒**。

| | 鍵の数 | 時間 |
|---|---|---|
| いまの形（1本ずつ） | 382 | **138 秒** |
| まとめて渡す形 | 251 | **91 秒** |

**★これは測った束の数での話です。**束を増やすと、鍵の重なりは変わります（同じ材料を使う束が増えるほど、重なりも増える見込み）。
