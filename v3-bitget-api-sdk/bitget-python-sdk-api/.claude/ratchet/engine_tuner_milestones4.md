## 1 前提

## 2 流れの骨（決まっている手順だけを使う）

- 先に、玉の状態ごとの分岐表を書きます（entry_exit_matrix.md:42）。

- 値の出発点は、V9 の実証値か教科書の標準値です。採点窓で選びません（同 :62・:102）。

  - 入口の合図と出口の反転の関係（同じ指標を逆向きに使う・期間をそろえるか）を、法則の記録にします。

### 手順5 前提が崩れた玉（損切り・レンジ破れ・急騰）

- **V9**：
  - 損切りは固定の % の災害 SL です（ショートは 5%、P21 は 2%）。

- **E37・E38 の実データ**：

  - v59 の急騰の早切りは、down 型と flat_up 型で別の指標を使います（adopted_strategies.md:79）。

  - 上げトレンドの判定で全部の玉を成行で閉じると、856件で −$3,574 でした（entry_exit_matrix.md:184）。この形をやめると、その損は0になりました（同 :188）。

- **指標の使われ方**：
  1. 帯の線（位置）、出来高の比、続く本数（1時間）
  2. トレンドの強さと向きの指標（DI差・基準線との乖離）を、値の閾値つきで「急騰の印」として使う
  3. 場面の判定の列（上げトレンド）を、出口の引き金に使う
  4. 型ごと（down・flat_up）に、別の指標と閾値を使う
- **いまの実物**：
  - レンジ破れの枝は、系統の中から乱数で選びます。損切りの3つの型も乱数で選び、15% は損切りを置きません（engine_tuner_gen.py:2069〜2085）。

- **構造に要ること**：
  - 出口の引き金として、場面の判定の束と、破れの判定の部品（帯・出来高・続く本数）を指せるようにします。
  - 型ごとに、使う指標と閾値を分けられるようにします。

## 4 漏れの照らしとまとめ

**網羅の正本（出口の軸 X-a〜X-k・79の選択肢）との照らし**（exit_families.json の counts）
- 組める物は31、一部だけの物は7、組めない物は14です。そのほか、この段の外が19、ほかで受ける物が7、市場に無い物が1です。
- **組めない物**：
  - σ 幅の水準（X-a5・X-d9）
  - ATR に連動する水準（X-c2・X-c5・X-d5）
  - Parabolic SAR（X-c3）
  - 加速度の損切り（X-d8）
  - 指標の発表（X-f6）
  - ローソクの反転（X-g11）
  - X-g9
  - 発注の方式（X-k5・X-k8〜10）
- **一部だけの物**：VWAP の水準・損切りと利確の比の確認・Donchian・出来高のダイバージェンス・積み増しの合図・発注の方式。
- Parabolic SAR が組めない理由の文は「型の表の部品に無い」です。ところが、いまの型の表（signal_families.json）には、PSAR加速と PSAR反転があります（grep で4件ずつ）。理由の文が古い可能性があります。

**指標の構造に要ること（15〜23 に足す物）**

24. 指標を「出口の水準を作る材料」として使えるようにする（ATR の倍数・BB の σ 幅・VWAP・帯の線）。
25. 出口用の閾値（反転の水準など）を、入口とは別に、代表の値と範囲つきで持たせる（いまは4指標の定数だけ）。
26. 入口の合図と出口の反転の関係（同じ指標を逆向きに使う・期間をそろえるか）を、法則の記録として持たせる。
27. 出口の引き金として、場面の判定の束と、破れの判定の部品（帯・出来高・続く本数）を指せるようにする。
28. 型ごと（down・flat_up）に、使う指標と閾値を分けられるようにする。
29. 値の単位（ドル・%・手数料の床の倍数・ATR の倍数）を持たせる。
30. 枝の記録に、優先の順と、どの入口の型用かを持たせる。

**マイルストーンとフローの問題**
1. engine_tuner_gen が作るレシピには、レンジ破れと上げトレンドの畳みがありません。そのため、E38 の S1 のレンジ破れと v59 の急騰の早切りを、作る側で組めません。
2. 出口の型の表は「閾値は分位」と書いています。しかし、売買を回すプログラムは、出口の条件で分位を使えません。
3. engine_tuner_gen は、時間切れの後の建値待ちを30% の乱数で付けています。E38 の宣言は、これを 0 に固定しています。広げるかは、まこさんが決めることです（恒久の決まり §5-12）。
4. 出口の枝の値を、最後の段階で一度も詰めていません。
5. 入口を固定して、出口だけを磨く口がありません（M3 の問題と同じです）。
6. 守りの枝だけを置いても、実測では効きませんでした（L-334）。出口を早めると入口がすぐ建て直す問題（L-330）を扱う段も、ありません。
7. 出口の型の表の、PSAR が組めない理由の文が古い可能性があります。
