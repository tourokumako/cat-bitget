# 材料A — engine_tuner がいま何をできるか

出どころは [engine_tuner_manual.md](engine_tuner_manual.md)。実体から機械生成されたものです。

## できること

- 戦略を2つ扱える。e37 と e38。接続ファイルを1枚足せば戦略を増やせる
- 登録12本のロジックのうち、8本を回せる
- 入口の型を7種から1つ選べる。戻り売り、上抜け失敗、統計的回帰、急落反発、下抜け失敗、統計的回帰ロング、下端タッチ
- 入口の確認を、9個の部品から最大2つ足せる。上位足から1つ、ボラと出来高から1つ
- 出口の値を7つ動かせる。利確1段目の位置、2段目の位置、損切りの離し方、保有上限、建値待ちの有無、利確の型、利確の幅
- 値決め窓で値を選び、確認窓で1回だけ表示する
- 審判 score.py をそのまま呼んで採点する
- 件数の下限を割った試行を捨てる
- DSR と PBO を出す
- 判定を1枚の表で出す

## できないこと

- **登録12本のうち4本が回せない。** S1 と L1 は実装が e37_scalp の一枚岩で共通の売買ループで動かない。S5 と L5 は入口の型が未実装
- **入口に足せる部品は9個だけ。** 指標も時間足も、この一覧の外は試せない
- **指標カタログ768列のうち、いちばん広いロジックでも触れているのは9本。1.17%**
- **局面の判定がレンジに固定。** 共通の売買ループが range_ok_rg5 を前提にしている
- **保有の上限が分単位に固定。** デイトレの時間単位を試せない
- **調整の単位はロジック1本。** 戦略まるごと、つまり複数ロジックと優先度と枠の配分を一度に扱えない

## 実測の時間

| 戦略とロジック | データ読み込み | 1試行 |
|---|---|---|
| e37 の v59 | 98.2秒 | 2.62秒 |
| e38 の S2 | 103.3秒 | 0.38秒 |

読み込みは試行の回数によらず毎回かかります。

## ロジックの並べ方

| V9 の構造 | engine_tuner のいま | そこから出る要件 |
|---|---|---|
| 9本を優先順位で上から見て、最初に当たった1本だけ発火 | 1本ずつしか扱わない | この道具では扱わない。調整の単位はロジック1本、とまこさんが決めています。統合の段の話です |

## この照らし合わせから出る設計の形

**条件1つの形。** 形・材料・側・値 の4つで表します。

- 形 — 上の表の左列にある書き方のどれか
- 材料 — 列1本、または列2本
- 側 — 上か下か
- 値 — 閾値、遡る本数、許容幅

**入口。** 条件のリスト ＋ つなぎ方 です。つなぎ方は 全部満たす／どれか満たす／入れ子 の3つです。

**出口。** 枝のリスト です。枝1つは 発火の条件 ＋ 決済のしかた ＋ 効く玉の範囲 で表します。効く玉の範囲は、積み増しの回数と保有時間です。

**探索が決めるもの。** 条件の本数。各条件の 形・材料・側・値。つなぎ方。枝の有無と順番と値。積み増しの上限。

## ⚠️ この照らし合わせの使い方を間違えないこと

**「V9 の20種のうち、いくつ書けるか」を進捗の数字にしません。** それは V9 を到達目標にすることで、コピーを作るのと同じです。2026-07-27 に CC が一度この形を出して、まこさんの指摘で取り消しました。

**数えるなら「この道具が組み立てられる条件の形が何種類あるか」です。** 基準は材料B の軸カタログであって、V9 との一致率ではありません。

# 材料E — 過去の実験でわかっていること

出どころは entry_exit_matrix の E37 グリッド。#1 から #32 まで実験済みです。

## 実測で筋が閉じたと結論されたもの

- **出口だけを直すレバー。** 早く撤退すると入口がすぐ建て直し、救った損を新しい玉の負けが食う。スロット再回転による相殺。L-330
- **守りの枝を単独で足すこと。** 建値撤退、ピーク反転、失速切り、V9型3枝分業の7変種を試して、全部が両方の期間で中立からマイナス。L-334
- **浅い損切り。** 平均回帰には逆効果。L-323
- **トレーリング。** 両方の期間で符号が反転する

## まだ残っている軸

- **クールダウン。** 機械が退出した後 N 本は再エントリーしない。入口と出口の結合部の新しい軸。ARC29 が「次に筋のある組」と名指し
- **入口の期待値の側。** 高ボラに限定する、stoch_k を除外でなく特徴量として渡す
- **伸ばす側の時間整合。** 利確後60分でさらに伸びる分が両方の期間で実在。$4,311
- **入口の情報。** 需給、CVD、上位足整合

## E38 の状態

S1 と L1 は恒等移植が済んでいます。**S2 から S5、L2 から L5 は全部未試行です。**

# この材料から見える事実

**engine_tuner がいま触れている範囲は、扱うべき範囲の正本である軸カタログに対して、ごく一部です。**

入口の8軸のうち、実質的に動かせるのは E-e の確認だけです。それも9個の部品からの選択に限られます。出口の11軸のうち、動かせるのは X-a と X-b と X-d と X-f の値だけです。

**そして、その狭い範囲の中で E37 は32回の実験を回し、実測で「出口だけを直す道は閉じた」と結論しています。**
