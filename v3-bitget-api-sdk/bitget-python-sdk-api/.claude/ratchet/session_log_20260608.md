## 1. ★ ボラ逃げを起こさない学習設計の知見（KB＋Web・本セッションの核心）

### 1.1 正体（なぜ「ボラ逃げ」が起きるか）
- 前回 E8b 第1回のラベルは「**稼いだ net 金額が大きいか**」。相場が荒れる（高ボラ）ほど勝っても負けても金額が大きくなる → モデルは「方向（下げ）」でなく「**荒れているか（揺れ幅）**」を当てれば金額ラベルに当てはまる → 揺れ幅指標（ATR）に逃げる。実際 feature importance を atr_pct が支配し地面 $925.73 に負けた（$655・ledger E8b）。
- Web 確認（私の推測でなく業界既知問題）:
  - 「スケール（揺れ幅）が局面ごとに変わる目標を学ばせると、モデルは方向でなくボラを学ぶ」（[quantreo](https://www.newsletter.quantreo.com/p/how-to-build-targets-that-make-sense)）
  - 「金額の大小を取り除くと**方向成分だけが残り**、ボラの代理になっていないかのクリーンな検査になる」（[arXiv 2508.20108 ReVol](https://arxiv.org/html/2508.20108v2)）
  - 「ボラと方向は別物。ATR は方向に中立 → 方向指標の**相棒**として使う」（[ATR guide](https://changelly.com/blog/average-true-range-atr-in-crypto/)）
- KB 整合: cc_entry_logic_self_study §18.5 軸1原因＝**regime 不在 ＋ LONG/SHORT 並列 ＋ ボラ依存ラベル**（§13.1+§14.6）。entry_fix_6axis_gate §軸1。

### 1.2 直す4点（Web＋KB で裏取り）
| # | 手 | なぜ効く | 出典 |
|---|---|---|---|
| ① ラベルから金額の大小を消す | 「方向が当たったか（+1/−1/0）」or「ボラ正規化リターン（return÷σ・クリップ）」 | 金額を消すと方向成分だけ残る | arXiv 2508.20108 / quantreo / KB§14.1 |
| ② ラベルを決める TP/SL バリアをボラ基準に | `entry×(1±k×σ)`（σ=ATR/EWMA・k=1〜3）。固定%にしない | 固定%だと高ボラ時ノイズで簡単に到達し**ラベルがボラを写し込む**。ボラ基準で全局面同難易度 | quantinsti Triple Barrier / KB§9 |
| ③ ATR を方向当てから外し相棒へ＋regime を入力 | ATR=サイズ/バリア幅の相棒。局面(regime)は別途入力 | ATR は方向中立。効く指標は局面で変わる（低ボラ=モメンタム/高ボラ=ボラ系） | ATR guide / KB§14.6 |
| ④ 学習後に feature importance 検証 | 揺れ幅(ATR/bb_width)が方向スコア上位を支配しないか実測 | 「ボラの代理になっていないかのクリーンな検査」 | arXiv 2508.20108 / H15条件① |

### 1.3 ReVol（arXiv 2508.20108）のラベル正規化式（参考・代替候補）
`ε_t = (1/σ̂) × [ log(S_t / S_{t-1}) − (μ̂ − σ̂²/2) ]` … ドリフト除去＋σ で割る → 標準正規に近い残差＝方向成分のみ。σ̂ は attention 加重推定（ノイズ down-weight）。実証=IC +0.03 / Sharpe +0.7（米中英韓）。クリップは本文明記なし（一般には極値抑制で付与）。

### 5.2 E8c（軸1準拠の正攻法）— ボラ逃げは消えたが地面に負けた

### 5.3 ★ E8c レポート（report_trades_p23_E08b_ai.txt・149件）の正しい分析
まこさん「結果レポートを見て分析しろ」を受け、全項目を読んだ結果（次セッションの起点）:

**出血源（はっきり2つ）**
- **C. 時間切れ 70件 −$1,441**（最大の出血・全月マイナス）。
- **I. MFE帯 〜5(37件)−$822 ＋ 5〜15(33件)−$681 ＝ MFE<15 の70件で −$1,503**。＝**含み益がそもそも伸びなかった玉が、時間切れまで抱えられて死ぬ**（時間切れ70件 ≒ MFE<15の70件・同じ集団）。

**稼ぎ（はっきり）**
- **C. 利確TP +$1,659 / ストキャス反転 +$619**。
- **D. add別が右肩上がり**: 0.024(102件)−$132 / 0.048(29)−$166 / 0.072(10)+$241 / 0.096(5)+$258 / 0.120(3)+$371 ＝**単発・add1/2が出血、add3-5の継続玉が本体**。
- **I. MFE>15 の79件で +$2,074**（15〜30 +$541 / 30〜60 +$717 / 60〜 +$816・勝率75〜100%）。
- **G. 稼ぐ場面**: bb傾き≤−30（急な下げ）80件+$563 / ADX≥25 / ATR%≥0.4 / stochギャップ3〜6。下げてない(bb≥0)・低ADX(0-20)・低ボラは負け。

**診断（3分類＝① 戦略の選択／執行）**
1. モデルは伸びる入口を選べている（AUC0.67・bb≤−30が稼ぎ頭・ボラ逃げ無し）。
2. **自動選定したExit='StaleOff'（含み益失速カットを実質オフ）が致命**。伸びない玉(MFE<15)を切れず時間切れまで抱えて −$1,441。V9フルExit（失速/stoch反転で損切り）なら早く切れた。
3. 入口選別(θcut)は **P23の fat-tail では地面（全部取る265件$925）に勝てない**（E8a-2「取るほど稼ぐ」の再確認）。

**効くレバー2つ（次の一手・PDCAで捨てない）**
- **(A) Exit を損切り保持で最適化**: StaleOffを選ばせず、失速カット/stoch反転を残し、時間切れになる前に伸びない玉を切る。
- **(B) サイジング(E9)**: AUC0.67の伸びる確率を「選別(cut)」でなく「サイズ配分」に使う（add3-5が稼ぐ＝伸びる玉に厚く・de Prado）。

**★ 目標逆算（件数・net が全く足りない・playbook §2.5 MRP ＋ §11逆算）**
- **目標 月$1,900（全月）＝9ヶ月で$17,100**。
- **E8c**: 月$61（9ヶ月$553）＝**目標の約1/31**。トレード数 149/9ヶ月＝**16.6件/月**・1件あたりnet **$3.71**。
- **地面V9**: 月$102.86（9ヶ月$925.73）＝**目標の約1/18**。トレード数 265/9ヶ月＝**29.4件/月**・1件あたりnet **$3.49**。
- **逆算で必要な1件単価**: 月16.6件なら**$114/件（現状の31倍）**・月150件なら$12.7/件（3.4倍）・月300件なら$6.3/件（1.7倍）。
- **F 月別の最悪月（MRP robust下限）**: E8c=2025-04 **−$118**（黒字は11月+684・12月+164のみ・残り7ヶ月マイナス基調）。全月$1,900には全月が桁で足りない。
- **結論（逃げでなく事実）**: P23単独は**件数も1件単価も全く足りない**。$1,900は全Priority合算（§6.2）の目標で、**P23の当面の到達目標は地面$925.73超え**。ただし地面自体が月$1,900の1/18なので、全Priorityを足して届かせるには **件数（regime条件付けで取れる下げ場面を増やす）＋ 1件単価（Exit/サイジングで伸ばす）の両方**を上げる必要がある。E8cはθ足切りで件数を149に削り（地面265から−116件）、削った分が06/09/10月の大勝ち玉（10月 地面+608→AI+1）で、fat-tailの土俵を崩して総netを落とした＝**件数を増やす方向に動くべき**を裏づける。
