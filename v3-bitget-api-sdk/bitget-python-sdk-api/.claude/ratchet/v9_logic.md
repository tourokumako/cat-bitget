作成: 2026-07-27。まこさん指示「V9の構造を詳細に記録しろ」。

## この文書は何か

**V9 は、このプロジェクトで唯一 net が黒字になっている実物です。** 月 $354、採点期間で月 $172。ほかの戦略はまだ地面を作れていません。だから V9 は参考資料ではなく**資産**です。

この文書は、その V9 が **どういう構造で組まれているか** を、実コードから読み取って書いたものです。

**目的は2つです。**

1. 新しいセッションの CC が、V9 を読み直さずに構造を掴めるようにすること
2. 新しいロジックを設計するとき、**どういう形の条件が書けないと話にならないか** を思い出すこと

**⛔ この文書は V9 をコピーするためのものではありません。** V9 の値も、枝の構成も、そのまま持ってきません。担当する相場が違います。V9 は下げトレンドの SHORT が中心で、E37 と E38 はレンジのスキャルです。実測で結論が逆になった例もあります。**借りるのは条件の組み立て方だけです。**

# 1. 全体の形

## 1.1 9本のロジックを、優先順位をつけて上から評価する

1つのバーで発火するのは **1本だけ**です。上から順に条件を見て、**最初に当たった1本を採用して、そこで打ち切ります**。同じバーで2本が発火することはありません。

判定の順番です。cat_v9_decider.py の 336行目から 584行目までを上から読んだ順です。

| 順 | ロジック | 方向 | 中心の指標 |
|---|---|---|---|
| 1 | P3 | LONG | Stoch のゴールデンクロス ＋ BB 中央の上昇 |
| 2 | P4 | LONG | 押し目 ＋ 順張り |
| 3 | P2 | LONG | Stoch のゴールデンクロス |
| 4 | P23 | SHORT | Stoch のデッドクロス ＋ BB 中央の下降 |
| 5 | P22 通常 | SHORT | RCI のデッドクロス ＋ BB 上限タッチ |
| 6 | P22 緩和 | SHORT | 上と同じだが条件が緩い |
| 7 | P24 | SHORT | RSI 高位 ＋ Stoch 高位 |
| 8 | P1 | LONG | MACD のゴールデンクロス |
| 9 | P21 | SHORT | MACD のデッドクロス |
| 10 | P25 | SHORT | ADX の急上昇 |

**順番の意味は、確度の高いものから、です。** 強いシグナル、標準のシグナル、スキャルのシグナル、の順に並んでいます。

## 1.2 使っている指標は10種

cat_v9_decider.py の preprocess、52行目から 159行目で作っています。

| 指標 | 設定 | 何を見るか |
|---|---|---|
| RCI | 7・9・52 | 価格の並びの規則性 |
| ボリンジャーバンド | 20本 | 中央線、上下の2σ、幅、中央線の傾き |
| ADX | 14 | トレンドの強さ |
| ATR | 14の単純平均 | 値動きの幅 |
| EMA | 20 | 短期のトレンド |
| RSI | 21、傾きは3本差分 | 買われすぎ売られすぎ |
| MACD | 12・26・9 | 方向の転換 |
| ストキャスティクス | 14、平滑3 | 短期の勢い |

| entry_risk_score | 20本の標準偏差 ÷ close | ボラが過大か過小か |

**location_prev だけ 1本ずらしています。** 未来を見ないための処理です。

## 1.3 LONG だけに共通の事前フィルタがある

131行目から 153行目です。**LONG のロジック全部が、この3つの AND を通ってから判定されます。**

- location_prev ≤ 0.9 — 直近20本の高値圏では買わない
- entry_risk_score ≤ 0.3398 — ボラが大きすぎるときは入らない
- entry_risk_score ≥ 0.0007 — ボラが小さすぎるときも入らない

SHORT 側にも同じ列は作られていますが、**AND にまとめた入口フィルタは LONG だけです。** SHORT は P22 が個別に risk のフィルタを使っています。

# 2. Entry の条件（9本ぜんぶ）

## 2.1 P3 — LONG・Stoch ゴールデンクロス・強い版

cat_v9_decider.py 336行目から 348行目。**全部 AND です。**

1. 2本前で Stoch の K が D より下
2. 1本前でも K が D より下
3. 今の足で K が D より上 — **ここでクロス**
4. K と D の差が 0.3 より大きい
5. 今の足が陽線。close ≥ open
6. BB 中央線の傾きが 10 より大きい
7. ADX が 30 以上
8. ADX が 50 未満
9. ATR が 250 以上

## 2.2 P4 — LONG・押し目からの順張り

351行目から 438行目。

1. **過去10本のどこかで**、安値が EMA20 か BB 中央線まで届いた。届いたかの判定に許容幅 0.0005 を掛ける
2. 今の足の close が EMA20 以上 — 押し目から戻ってきた
3. BB 中央線の傾きが 20 以上
4. **BB 中央線の傾きの直近5本平均が 15 以上** — 一時的でなく続いている
5. 陽線
6. LONG 共通の事前フィルタを通っている
7. RSI が 60 以下
8. ATR が 200 以上
9. **ADX が 20 以上 25 未満なら不成立** — この帯だけ抜く

## 2.3 P2 — LONG・Stoch ゴールデンクロス・標準

443行目から 464行目。P3 とクロスの形は同じで、周りの条件が違います。

1. 2本前と1本前で K が D より下、今の足で上 — クロス
2. K と D の差が 0.3 より大きい
3. 陽線
4. ADX が 30 以上 50 以下
5. **ADX が 40 以上 50 未満なら不成立** — 抜き帯
6. RSI が 45 以上
7. ATR が 100 以上 300 以下

## 2.4 P23 — SHORT・Stoch デッドクロス

469行目から 484行目。P3 の裏返しです。**実測で一番稼いでいるのがこれです。**

1. 2本前と1本前で K が D より上、今の足で下 — デッドクロス
2. D と K の差が 0.3 より大きい
3. 陰線。close ≤ open
4. BB 中央線の傾きが −10 より小さい
5. ADX が 30 以上 50 未満
6. ATR が 150 以上
7. **ADX が 40 以上のときだけ、ATR 200 以上を追加で要求する** — 入れ子の条件

## 2.5 P22 — SHORT・RCI クロス ＋ BB 天井

487行目から 510行目。**この1本だけ、2系統の OR で組まれています。**

まず部品を4つ作ります。165行目から 234行目です。

- RCI7 が RCI9 を下抜けたか
- **直近2本のどちらかで**高値が BB 上限に届いたか。許容幅 0.0012
- BB 中央線の傾きが 0.02 以下。**傾きが欠損なら通す**
- RCI52 が 55 より大きいか

そして組み合わせます。

- 核の条件 ＝ 「RCI クロス かつ BB 上限タッチ かつ 中央線が下向き」**または**「RCI52 が過熱」
- 通常系統 ＝ 核 かつ ADX 22 以上 かつ risk フィルタ かつ BB 中央の傾きが −20 以下 かつ BB 幅の上限
- 緩和系統 ＝ 核 かつ BB 中央の傾き かつ BB 幅 かつ ADX の緩い下限。**risk フィルタを外す**

**通常で当たらなければ緩和で見る、という二段構えです。**

## 2.6 P24 — SHORT・RSI 高位からの反転

515行目から 533行目。

1. RSI が 65 より大きい
2. **RSI の3本差分がマイナス** — 高いところから下を向いた
3. BB 中央線の傾きが 50 より小さい
4. Stoch の K が 60 より大きい
5. 陰線
6. ATR が 30 以上

## 2.7 P1 — LONG・MACD ゴールデンクロス・スキャル

538行目から 551行目。

1. 1本前で MACD が Signal 以下
2. 今の足で MACD が Signal より上 — **1本前と今の足を比べるクロス**
3. ADX が 30 以上
4. ATR が 60 以上 9999 以下

## 2.8 P21 — SHORT・MACD デッドクロス・スキャル

556行目から 569行目。P1 の裏返しです。

1. 1本前で MACD が Signal 以上、今の足で下 — デッドクロス
2. ADX の下限。設定は 0
3. ATR が 150 以上

## 2.9 P25 — SHORT・ADX の急上昇に乗る

574行目から 584行目。**反転を狙う他の SHORT と違い、これだけ順張りです。**

1. **いまの ADX と3本前の ADX の差が 5 以上** — 急に強まった
2. ADX が 25 以上
3. BB 中央線の傾きがマイナス
4. 陰線

# 3. Exit の構造

## 3.1 上から順に見て、最初に当たった枝で決済する

replay_csv.py の 180行目から 334行目です。Entry と同じ先勝ちです。**枝の順番そのものが設計です。**

| 順 | 枝 | 誰に効くか | 発火の条件 |
|---|---|---|---|
| 1 | BREAKOUT_CUT | P22・積み増し3回目 | BB 幅が 0.03 以上 かつ RSI 70 以上 |
| 2 | MFE_EXIT | P22 | 保有が制限時間の 0.6 倍以上 かつ 含み益のピークが $20 以上 |
| 3 | MFE_STALE_CUT | P22・積み増し5回以上 | 保有120分以上 かつ ピークが $12 未満 |
| 4 | MFE_STALE_CUT | P2 LONG・積み増し1回 | 保有90分以上 かつ ピークが $3 未満 |
| 5 | MFE_STALE_CUT | P23・積み増し1回 | 保有30分以上 かつ ピークが $4 未満 |
| 6 | MFE_DRAWDOWN_CUT | P23 | ピークが下限以上に達した後、いまの含み益がピークの X 倍を割った |
| 7 | STOCH_REVERSE_EXIT | P23 | **4条件の AND**。下に別記 |
| 8 | MFE_STALE_CUT | P3 LONG・積み増し1回 | 保有90分以上 かつ ピークが $4 未満 |
| 9 | MFE_STALE_CUT | P21・積み増し1回 | 保有90分以上 かつ ピークが $4 未満 |
| 10 | RSI_REVERSE_EXIT | SHORT 共通 | RSI が 50 未満 かつ RSI の傾きが上向き かつ ADX が 12 未満 |
| 11 | MAE_CUT | P2 LONG・積み増し4回以上 | 保有300分以上 かつ 含み損が $50 相当を超えた |
| 12 | PROFIT_LOCK | LONG / P22 / P23 | ピークが下限に達した後、いまの含み益が下限を割った |
| 13 | STAGNATION_CUT | 全部 | 保有が下限を超えても ピークが $1 以下 |
| 14 | TIME_EXIT | 全部 | 制限時間。**含み損なら短縮する** |

## 3.2 STOCH_REVERSE_EXIT の中身

249行目から 266行目。**V9 の出口で一番よく効いた枝です。**

次の4つを全部満たしたときだけ切ります。

1. Stoch が **ゴールデンクロスした**。1本前は K が D より下、いまは上
2. 含み益のピークが $15 以上ある
3. 保有が 30分以上たっている
4. いまの含み益がプラス

**指標の反転だけでは切りません。利が乗っていて、時間もたっていて、いまプラスであることを全部要求します。**

## 3.3 含み損なら時間切れを早める

328行目から 331行目。制限時間に係数を掛けます。**含み損なら 0.5 倍、含み益なら 1.0 倍**です。

## 3.4 利確の値の決め方

127行目から 160行目。**固定値ではありません。4段階で作ります。**

1. ロジックごとの基準の % を取る
2. P23 だけ、ATR に連動した値と比べて**広い方を採る**。上限あり
3. **手数料の往復に余裕を掛けた値を下限にする** — これを割る利確は作らない
4. ADX が高いときに広げる。上限で止める

## 3.5 損切りの値

166行目から 173行目。ロジックごとの % があればそれ、無ければ方向ごとの % です。**P23 と P2 は 5%、P21 は 2%、P3 は 1.5%。** 損切りはロジックごとに大きく違います。

## 3.6 積み増し

run_once_v9.py の 1203行目から 1208行目。**同じ方向でもう一度シグナルが出たら、新しい建玉を作らずに既存へ積み増します。建値は平均になります。** 上限はロジックごとに決まっていて、1回のものと5回のものがあります。

**積み増した回数によって、効く Exit の枝が変わります。** これが上の表の「誰に効くか」の列です。

# 5. 設計の考え方として読み取れること

**数字ではなく、組み方の話です。**

- **1本の指標で決めない。** どのロジックも5個から10個の条件の AND です。
- **クロスと水準を混ぜる。** クロスしただけでは入らず、そのとき ADX がいくつか、ATR がいくつかを一緒に見ます。
- **同じクロスでも周りの条件で別のロジックにする。** P2 と P3 は Stoch のクロスが全く同じで、周りの条件だけが違います。強い方を先に評価します。
- **除外する帯を持つ。** 以上と以下だけでなく、特定の帯を抜く形があります。
- **Exit の枝は1本ではない。** 14本の枝を順番に見ます。順番そのものが設計です。
- **Exit は積み増しの回数と保有時間で切り替わる。** 同じロジックでも、1回目の玉と5回目の玉では効く枝が違います。
- **利確は固定値ではない。** 手数料の床を必ず持ち、相場の状態で広げます。
