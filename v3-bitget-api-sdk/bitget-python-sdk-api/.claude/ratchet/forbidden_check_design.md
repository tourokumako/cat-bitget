### 5.2 判定のルール（★これが「私が書ける欄」を消す本体）

**返す文字列は、この4つだけです。プログラムの中に固定します。**

| 番号 | ルール | 返す文字列 |
|---|---|---|
| 1 | 乱数の呼び出しの合計が **0件** | `当たりません` |
| 1 | 乱数の呼び出しの合計が **1件以上** | `当たっている疑いあり` |
| 2 | 「数の並び」の合計が **1件以上**、**または** `sample_regime_build` の中の `draw_param` が **0件** | `当たっています` |
| 2 | 上のどちらでもない | `当たりません` |
| 3以降 | ルールが無い（まこさんが足した番号） | `測り方が未定` |

**★「当たっている疑いあり」を置く理由（正直に書きます）。**
**1番だけは、プログラムが白黒を付けられません。**乱数の呼び出しが在っても、「案の骨格を乱数で決めている」のか「同点のときの並び順を決めている」のかは、構文木では分けられません（値の流れを関数の外まで追い切れないためです）。
**だからプログラムは「1件でも在る＝疑いあり」と出し、関数ごとの内訳を並べます。白黒を付けるのは まこさんです。**
**★`当たりません` に倒せるのは、0件のときだけです。**「疑いなし」に倒すルールは入れません。
