# §2 いま engine_tuner が何をしているか

## 2.1 案の作り方は、いまサイコロです

**engine_tuner は、売買ルールの案を100本 作り、一番 net が良かった1本を選びます。**その100本の作り方が問題です。

**いまの手順です。**

1. 型をサイコロで1つ引く。
2. 役割の順番をサイコロで並べ替える。
3. 使う指標と時間足をサイコロで1つ引く。
4. 条件の形（クロスか、傾きか、帯か）をサイコロで1つ引く。
5. 向き（上か下か）をサイコロで引く。
6. 条件の本数・経路の数・入れ子の深さを、サイコロで引く。

**＝条件と条件のあいだに、理由がありません。**これが欠陥 D14 です。
