### 0.3.1 何が違うか

**出どころ＝Gemini の回答（まこさんが 2026-08-19 に貼ったもの）。**【外の AI】の見解であって、実測ではありません。

> 結論から言うと、はい、全く同じ要素（指標、閾値、パラメータ、時間足）の組み合わせで構成されます。構成パーツは完全に共通ですが、「それぞれの要素に割り当てる役割や数値（設定）」が大きく異なります。
>
> **同じパーツを使って、レジーム判定は「マクロな市場環境の把握」を行い、Entry/Exitは「ミクロな仕掛けのタイミング」を測ります。**

**★この2つの言い方が、いちばんの要点です。**同じパーツで、**大きく見る**か、**入る瞬間を測る**か。

| | レジーム判定 | Entry/Exit |
|---|---|---|
| **何をするか** | **マクロな市場環境の把握** | **ミクロな仕掛けのタイミングを測る** |
| 例え | 天気予報（雨か晴れか） | 傘を開くか、日傘を差すか |

| 結果 | トレンド、レンジ、ボラ大、ボラ小 | 買い注文、売り注文、ノーポジ、決済 |

### 0.3.2 4つの要素は、それぞれ扱いがこう変わります

| 要素 | **場面の判定** | **入口・出口** |
|---|---|---|
| **① 指標** | トレンドの有無・値動きの幅を測るもの（ADX・ATR・長期の移動平均・一目均衡表） | 売買の過熱・節目・抜けを測るもの（RSI・MACD・ボリンジャーバンド・水平線） |
| **② 閾値** | **相場の状態が切り替わる境目**（ADX が 25 以上・ATR が過去平均の2倍以上） | **注文を出す合図**（RSI が 30 以下・+2σ にタッチ） |
| **③ パラメータ** | ダマシを減らすため**大きめ・長め**（EMA 200・ATR 50） | 反応を早くするため**標準から小さめ**（RSI 14・MACD 12/26/9） |
| **④ 時間足** | **上位足**（日足・4時間足・1時間足） | **下位足**（15分足・5分足・1分足） |

**★例外＝同じ指標・同じパラメータ・同じ時間足で、閾値だけを変えて両方に使う形もあります。**

### 0.3.3 なぜ BTC で、この2つを分けるのか（Gemini の回答・逐語）

> BTCは「トレンドが始まると極端に長く続くが、レンジ期間は出来高が細ってダマシが多発する」という両極端な特性を持っています。

**分けずに「RSI が 30 以下でロング」だけで売買すると、こうなります（逐語）。**

> レンジレジームの時： RSIの逆張りがきれいに決まり、利益が出る。
> 大暴落トレンドレジームの時： RSIが30以下になっても価格が下がり続け（張り付き）、**無限に損切りさせられる**（または強制ロスカット）。

**正解の組み合わせ（逐語）**

> 「レジーム判定」がレンジと教えてくれている時だけ ➡️ RSIの逆張り「Entry/Exit」を起動する。
> 「レジーム判定」が下落トレンドに変わったら ➡️ **即座に**RSI逆張りを停止し、戻り売り（ショート）の「Entry/Exit」に切り替える。

**★これが M2 の目的そのものです。**E38 はレンジの平均回帰（逆張り）です。**場面の判定が無い、または当たらないと、下げトレンドで同じ「張り付き」が起きます。**
