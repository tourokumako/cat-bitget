## 3 手順ごとの使われ方

### 手順1 型を選ぶ

- **何をするか**：レンジの中の「どこで・何が起きたら売るか」で、型を決めます。レンジのショートには、次の5つの型があります（entry_exit_matrix.md:224〜229）。
  - 上端で売る逆張り（E38 の S1）
  - 中央より上に戻った所で売る戻り売り（S2）
  - 上端を抜けて戻った所で売る上抜け失敗（S3）
  - 帯の上側に行き過ぎた所で売る統計的回帰（S4）
  - 中央から上端に指値を並べるグリッド（S5）
- **指標の使われ方**：型を決めるのは「レンジの中の位置」の指標です。
  - 帯の線は4本です。上端（res_hi）、その下の縁（res_lo）、中央（mid）、下端（sup_lo）です。1時間足のスイングを束ねて作ります（束ね幅は 0.3%）。
  - S2 は「帯の中の位置が pos_min 以上」です。pos_min の範囲は 0.0〜0.9 です。
  - S3 は「高値が上端を抜け、終値が上端の内側」です。
  - S4 は、dev_z（終値と20本平均の差を、20本の標準偏差で割った値）の上側です。
  - 指値の置き場も型ごとに違います。S1 は天井、S2〜S4 は終値の少し上です（e38_logic_parts.py:370）。
  - 法則は「ショートはレジスタンスゾーンで確認された拒否」と「最低3回のタッチ」です（range_scalping_kb §3・§2）。
- **実データ**：S1 は、建値が帯の下の縁（真の抵抗より中央値で 0.69% 下）で決まります。そのため、帯の中を上へ轢かれる玉が50%ありました（entry_exit_matrix.md:212）。
- **いまの実物**：engine_tuner_gen は、型を名札にしか使いません（:3454）。型ごとの条件は、E38 の手書きの関数にしかありません（e38_logic_parts.py:95〜210）。
- **構造に要ること**：帯の線を、パラメータ（窓・束ね幅・時間足）つきの位置の指標として持たせます。型の記録には「位置の条件」と「指値の置き場」を持たせます。

### 手順2 機会の数を数える

- **何をするか**：型ごとに、入る機会が1日に何回来るかを observe_diag で数えます。順位は付けません。
- **実データ**（worklog 20260723:219〜226・機会のバーの数）：
  - 天井に届いたバーは、1日 18.5 本でした（上端 0.5・down 型の天井 18.0）。
  - 中央より上への戻り（S2）は、1日 81.2 本でした。
  - 下端に届いたバーは、1日 38.7 本でした。
  - S2 の観察では、場面のバーが1日 78.2 本、素の勝率は 48.9% でした。
- **いまの実物**：数える道具はあります。ただし、型の定義が E38 の関数の中にあり、型の記録はありません。
- **構造に要ること**：数える側と組む側が、同じ型の記録を読むようにします。

### 手順3 役割ごとに使える系統を絞る

- **型の表**（gen_signal_families.py:238〜272）：
  - 入る合図は、オシレーターとローソクで、時間足は 5m・10m・15m です。
  - 相場の向きは、トレンド・ボラ・時間帯・強さ・勢いです。
  - 値動きの大きさは、ボラ・出来高・需給・オシレーター・強さです。
  - レンジの中の位置は、構造・位置です。
- **実データ（オンの数）**：
  - オシレーター59・構造・位置62・ボラ18・勢い17・トレンド13・出来高10・強さ9・需給3・時間帯2 です。
  - **ローソクはオンが0です。** body比・pinbar・包み足・孕み足の4種は、全部オフです。
  - オシレーター59種のうち46種は、「終値と各移動平均の距離%」です。
- **見つかったこと**：
  - ストキャス %K と RSI の記録は、方向が「順張り値」になっています。
  - 型の表の決まり DC1 は、順張り値の指標を相場の向きと値動きの大きさに使うとき、ショートなら「下側」だけにします。
  - ところが、V9 の P24（ショート）は「%K が 60 より上」で使っています（cat_v9_decider.py:529）。
  - **つまり、同じ指標でも、使い方によって向きが逆になります。**
- **構造に要ること**：向きを、指標に1つではなく、使い方ごとに持たせます。ローソクの形の指標には、役目とオン/オフを持たせます。

### 手順4 入る合図を決める

- **実際に使われている合図**：
  - **ストキャスのデッドクロス**：
    - V9 P23 は、ストキャス(14,3) の5分足を使います。2本前と1本前は %K が %D より上、いまは下、かつ %D−%K が 0.3 より大きい、という条件です（:469〜476）。
    - E38 の S1 は、ストキャス(9,3) を使います。
    - 教科書のスキャルの値は、(9,3,3) か (5,3,3) です。
  - **RCI7 と RCI9 のデッドクロス**：V9 P22 が使います（:204〜208）。
  - **MACD(9,17,7) のデッドクロス**：V9 P21 が使います（:556〜569）。
  - **RSI の水準と傾き**：
    - V9 P24 は、RSI21 が 65 より上、かつ3本前より下がった、という条件です。
    - レンジでは RSI 70/30 が有効で、5分足は RSI9 を使います（range_scalping_kb.md:29）。
- **実データ**：
  - デッドクロスの「発生」だけを見て水準を見ないと、%K が高い側の負けが残りました（E37 #28）。
  - %K が高いほど負けました（相関 −0.12〜−0.17）。
  - **つまり、合図の指標は、クロスと水準の2つの形で同時に使います。**
- **使われ方のまとめ**：
  1. 同じ計算から出る2本のクロス
  2. 期間違いのクロス
  3. クロスの前の持続（2本前から上側）
  4. クロスの開き（0.3）
  5. 値の水準（65・70）
  6. 傾き（3本前との差）
- **記録の実物**：
  - ストキャスのスキャルの代表の値は空です。範囲は 5〜21 です。閾値は、定数の 80 と 20 だけです。
  - RSI のスキャルの代表の値は 7 です（要件の例は 9）。
  - 閾値の定数を持つのは、59種のうち RSI とストキャスの3種だけです。
- **いまの実物**：クロスの2本の組は、乱数で選びます（engine_tuner_gen.py:1627〜1659）。閾値は分位の q70〜q90 だけで、70 や 80 の値では持てません。
- **構造に要ること**：
  - 1つの指標が持つ複数の出力（%K と %D）と、出力どうしの組を持たせます。
  - 合図の型ごとのパラメータ（持続の本数・開き）を持たせます。
  - 閾値は、値と分位の両方の形で持たせます。

### 手順5 入ってはいけない場面を除く条件を決める

- **何をするか**：合図の弱点を見る条件を、必ず1本足します（indicator_combination_kb.md:144）。
- **実データ**：
  - S2 の観察では、両半期とも素の勝率を超えた組が9組ありました。9組とも「上位足のモメンタムが過熱していない」形です。例は、ROC24 の2時間足が q50 以下・DI差7 の4時間足が q50 以下・%D14 の2時間足が q50 以下です。
  - 上げトレンドでは、M2 の判定の列で新規の建玉を止めます（engine_tuner_exec.py:2781）。
  - V9 P23 の条件は、ADX 30〜50・BB 中央線の傾き −10 未満・ATR14 150 以上・ADX 40 以上なら ATR14 200 以上、です。これは下げトレンドの値です。
  - レンジでは ADX が低いことを見ます（法則 R5）。**つまり、同じ ADX でも、場面で閾値の向きと値が変わります。**
- **使われ方のまとめ**：
  1. 上位足（2h・4h・1d）で見る
  2. 既定でないパラメータ（ROC24・DI差7・BB幅(50,3.0)）を使う
  3. 閾値の形が、分位・値・前提つきの値の3通りある
  4. 場面で向きが変わる
- **いまの実物**：
  - 弱点を見る条件を足す決まりがありません。条件は乱数で選びます（:3493〜3502）。
  - V9 の ATR14 は値段の単位（ドル）です。engine_tuner の材料は ATR%（%）です。
- **構造に要ること**：
  - 「合図の型 → 足す除く条件の系統」を、法則の記録にします。
  - 閾値と向きを、場面と役目ごとに持たせます。
  - 閾値の単位を持たせます。
  - 前提つきの閾値を書ける形にします。

### 手順6 合図が本物かを確かめる条件と、値動きの大きさの条件を決める

- **実際に使われている物**：
  - 反転ローソクと出来高とモメンタム（range_scalping_kb.md:28〜29）です。V9 は陰線を使います。E38 の S2 は「デッドクロス・RSI9 下向き・陰線・なし」から選びます。
  - V9 P22 は、直近2本で高値が BB 上限の 0.12% 手前まで届いたかを見ます（:211〜220）。
  - S2 の9組の後ろ半分は、値動きの床です。volume_ratio50 の15分足が q70 以上、BB幅(50,3.0) の日足が q50 以上、などです。
  - E37 では、ATR が 0.2 未満の玉 494 玉で −$388 でした。値幅が手数料を超えなかったためです。
  - 需給の taker_ls は、E28（下げ相場のロング）で効きました。ショートでは確かめていません。データがあるのは 2026-01-01 までです。
- **いまの実物**：ローソクの形の指標は全部オフです。使えるのは、陰線か陽線かだけです。
- **構造に要ること**：
  - 指標の記録に「使える期間」を持たせます。
  - ローソクの形の指標に、パラメータと役目を持たせます。

### 手順7 法則で組む

- **何をするか**：次の決まりで条件をつなぎます（indicator_combination_kb.md:173〜179）。
  - 1つの経路に、合図は1本
  - 同じ問いに答える指標を2本入れない
  - 実データで動きが重なる列を入れない
  - 役目で時間足を決める
  - 上位足の向きと逆の入口を作らない
- **実際のつなぎ方**：
  - 全部満たす：V9 の全 Priority がこの形です。
  - どれか満たす：V9 P22 は「RCI のクロス・BB 上限タッチ・中央線が下向き」か「RCI52 が 55 より上」です（:491〜492）。
  - 前提つき：ADX 40 以上なら ATR 200 以上です。
  - 型で分ける：S1 は、down 型と flat_up 型で天井が違います。
- **いまの実物**：つなぎ方はあります。ただし、どの条件を足すかと本数は乱数です（:3485〜3512）。
- **構造に要ること**：法則の記録に、条件どうしの関係（合図と除く条件の対応・同じ問い・前提つき）を持たせます。

### 手順8 第一段階で組を絞る

- **何をするか**：スキャルの代表の値で組を作ります。例は、ストキャス(9,3,3) の5分足のデッドクロスや、RSI9 の 70 です。値決め窓を、実際の売買のエンジンで走らせて net を出します。1日5件を下回る組は捨て、落とした理由を全部出します。
- **いまの実物**：
  - 代表の値を読む口がありません。ストキャスのスキャルの代表の値は空で、閾値の代表の値は全部空です。
  - 1回の走行で、レシピを1本しか回せません。
- **構造に要ること**：代表の値を、出力ごと（%K の本数・平滑・%D の本数）と使い方ごとに持たせます。

### 手順9 最後の段階で範囲から探す

- **範囲の実物**：%K は 5〜21、RSI は 2〜21、ADX は 7〜21 です。閾値の範囲は、オンの193種のうち192種が空です。
- **構造に要ること**：閾値の範囲を、値と分位のどちらの形でも持てるようにします。

## 4 漏れの照らしとまとめ

**網羅の正本（入口の軸 E-a〜E-j）との照らし**
- E-a 型：S1・S2 は手書きです。S3〜S5 はまだ試していません。グリッドは、別の売買の関数が持っています。
- E-c 指標：ローソクのオンが0です。オシレーターの多くは、移動平均との距離です。
- E-e 確かめ：反転ローソク（#9）・上位足の整合（#11）・需給（#14）は、E37 の格子でまだ試していません。
- E-i 損切りと利確の比を、建てる前に確かめる条件：入口にまだありません。
- E-j 時間帯：オンは2種です。

**指標の構造に要ること（§9-1 の14件に足す物）**

15. 向きを、使い方（行き過ぎを見る・向きを見る）と場面（レンジ・下げ）ごとに持たせる。
16. 複数の出力（%K と %D など）と、出力どうしの組を持たせる。
17. 合図の型ごとのパラメータ（持続の本数・開き・タッチの許容幅・何本以内か）を持たせる。
18. 閾値の単位（値段・%・0〜100・分位）と形（値・分位・前提つき）を持たせ、それぞれに代表の値と範囲を持たせる。
19. 代表の値を、出力ごと・使い方ごとに持たせる。
20. 「合図の型 → 足す除く条件の系統」を、法則の記録として持たせる。
21. 帯の線を、パラメータつきの位置の指標として持たせる。型の記録に「位置の条件」と「指値の置き場」を持たせる。
22. 使える期間を持たせる。
23. ローソクの形の指標を、役目とパラメータつきで持たせる。

**マイルストーンとフローの問題**
1. 型の定義が E38 の手書きにしかなく、engine_tuner は型を区別しません。
2. ローソクの形の指標が全部オフで、確かめる条件の主な材料が使えません。
3. 向きを1つしか持てないため、DC1 が V9 P24 の使い方と逆になります。
4. 合図の弱点を見る除く条件を足す決まりがありません。
5. 閾値を値で持てません。V9 の値段の単位の閾値を移すための、単位の決まりもありません。
6. S2 の観察は、2026-03-01〜06-30 で測っています。この期間は、いまの採点窓に当たります。この結果を値決め窓の材料として使ってよいかは、まだ確かめていません。
