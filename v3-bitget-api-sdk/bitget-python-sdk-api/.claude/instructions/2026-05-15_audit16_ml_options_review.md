## 監査観点（5問）

### 問A: 選択肢列挙の網羅性（W1〜W4・X1〜X8 の抜け）

Web Claude が列挙した12選択肢（枠内 W1-W4 + 枠外 X1-X8）に**抜けはないか**を独立判定。

Web Claude 自身が §6 で以下3つを「思いつかなかった選択肢」として申告:
- データを買う・取引所を変える
- 予測対象を MFE/MAE 以外にする（終値方向・分位点・分散）
- 学習データを増やす・期間を変える（半減期跨ぎ問題）

**監査依頼**:
- 上記3つに加えて、ML/統計の標準観点から見て**抜けている選択肢を最大限提示**してほしい
- 「自己バイアスを認めて3つを挙げた」こと自体が**残りのより深い盲点を隠す機能**を果たしていないか
- 特に **「ML の使い方」というフレーム自体が狭くないか**（例: ML を「予測装置」として使うのではなく「**シグナル生成装置**」「**特徴量変換装置**」「**異常検知装置**」として使う案）

### 問B: 「最有力 X1・次点 X4+W3」判断のバイアス検証

Web Claude が §5 所感で示した推奨「最有力 X1（Exit を予測対象に追加）・次点 X4+W3」のバイアス検証。

Web Claude 自身が §6 で「LightGBM の枠を活かせる＝今までの作業を無駄にしない保身」が混じった可能性を申告。

**監査依頼**:
- 月次$1,900 達成の見込み・実装の正味コスト等から見て、X1 が**実際に最有力か**を独立判定
- 「最有力」判定の根拠が、Web Claude にとって**技術的にも心理的にも一番扱いやすい案**になっていないか
- まこさん発言「あらゆる Exit 方法を学習して最適化すればいい」に**直接対応する案として X1 が最適か**、それとも別案（例: X2 強化学習で Entry/Exit/Position 全体最適化）の方が直接対応か
- 「慎重に検討すべき X2（強化学習）」の評価が**実装回避バイアス**になっていないか

### 問C: 複数案の組合せの現実性

まこさんが本セッション中に提起した「**時間足×指標×閾値×Exit×サイズの全部組合せでエントリー予測・最適選択**」が、各案の組合せで現実的に実現可能か。

Web Claude はドキュメント §4 補足で組合せ例を3つ示すのみで、まこさんの「全部組合せ」イメージへの直接回答は出していない。

**監査依頼**:
- 「全部組合せ」を ML で実現する**最短経路の案組合せ**を独立判定（例: X1 + X4 + X6 の同時実装 / X2 強化学習で一括 / 段階的に W3 → X1 → X4）
- 「全部組合せ」が**理論的に実現可能か**（情報理論・学習データ量・leak混入リスクの観点から限界はあるか）
- まこさんの目標達成（月次$1,900）に「全部組合せ」が必要十分か

### 問D: 各案の月次$1,900達成見込みの独立判定

Web Claude の「期待効果（小/中/大）」評価は主観の3段階。月次$1,900達成見込みを定量的に独立判定。

参考データ:
- Phase 5 v3 現状: 合計-$985 / 月次最大$1,265 / 月次達成0/12
- 強い4 combo 合計: +$5,177（K12_SHORT_q90-q95 勝率72.6% 等）
- 月次$1,900達成には現状から約4.4倍の改善が必要

**監査依頼**:
- 各案について、月次$1,900達成見込みを**「絶望的(0-10%)/低(10-30%)/中(30-60%)/高(60-90%)/確実(90%+)」の5段階**で独立判定
- 達成見込みの判定根拠は数値で示してほしい（例: 「X1 で Exit 選定失敗が解消したと仮定すれば time_exit を採用していた combo の損失-$2,833 が改善余地。combo 別損益分布から逆算して月次最大+$2,000-$3,000 程度の改善が期待値」など）
- Web Claude の「期待効果」評価が**楽観/悲観どちらに偏っているか**を5段階判定と比較

### 問E: 分類軸のバイアス検証

Web Claude が選択肢を「枠内 W」と「枠外 X」で分類した。これが**唯一の適切な分類軸か**を独立判定。

Web Claude 自身が §6 バイアス2 で「変更幅が小さい順 = 安全」という暗黙の前提を含むことを申告。

**監査依頼**:
- 別の分類軸（例: 投資回収速度・leak混入リスク順・spec 改訂規模・期待リターン高低・実装失敗時のロールバック容易性）で並べ直すべきか
- 分類軸の選び方が、まこさんが**「どれを選ぶべきか」を判断する材料**として最適か
- 複数の分類軸を併記すべきか
