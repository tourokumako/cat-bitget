### §F-1. 学習対象未定で「最適化」と書く罠（最重要）

**症状:** L1 = 「ML 学習で Entry / Exit / Position を最適化する」と書いた。**学習対象が未定なのに**「最適化」という言葉が文として成立してしまう。

### §F-4. 過去失敗パターンの教訓を「読んだだけで適用しない」

**症状:** 本セッション中盤、選定アプローチ A/B/C を出したときに「(A) 既知問題からの逆算」を推奨案として出した。まこさんから「A は過去失敗のやり方そのもの・参考にならない」と指摘されて lessons_active.md を読んだ。**読んでいれば最初から A は除外できた。**

**対応:** §I-1 必読ゲートで lessons_active.md 全件読了を**着手前に**完了する。失敗パターンを「次の提案を出す前のフィルタ」として機能させる。

### §F-5. headroom_analysis を「23 軸全体の検証」と誤読しかけた

**症状:** headroom_analysis_summary.md を「ヘッドルーム分析」という名前から「23 軸の改善余地分析」と推測。まこさんから「23 軸のうち 1 軸の一部の項目でしか検証してない」と指摘されてようやく中身確認。

**対応:** ファイル名から内容を推測しない。**全文 view して中身を確認**してから議論に使う。

### §F-6. 手動ロジック「P23 のみ有効か」を質問した論外ミス

**症状:** 手動ロジック理解を確認する段で、「現状有効なのは P23 SHORT のみ・他は ENABLE=false」という運用状態の確認質問をした。

**まこさん指摘:** 「最低限の学習範囲の参考として手動ロジックを確認してほしいのであって、1 の質問は論外」

**原因:** 「手動ロジック = 学習範囲の参考」という目的を、運用状態の話と取り違えた。

**対応:** 手動ロジックは「**学習範囲の下限の参考**」として扱う。どの Priority が現在有効か / replay で何を使ったかは**学習範囲議論には関係ない**。

### §F-7. 質問が多すぎる癖

**症状:** 1 メッセージで複数の確認質問を並べる癖。対話ルール 3（選択肢並べて投げ返さない）違反。

**対応:** 1 メッセージに確認 1 つだけ。複数浮かんだら一番重要な 1 つに絞る。

### §F-8. 「私の試案」を出して結局まこさんに判断回す癖

**症状:** 「3 段階フィルタの選定方法」のような試案を出して「合っていますか?」と聞く。対話ルール 3 違反。

**対応:** 試案を出すなら結論まで出す。「合っていますか?」で逃げない。

### §F-9. memory ルール違反した時に自覚せず進む癖

**症状:** memory に書いてある対話ルールに違反した時、まこさん指摘で初めて気付く。事前 self-check で防げる類。

**対応:** メッセージを出す前に「対話ルール 1〜22 のどれかに違反していないか」を機械的にチェックする。特にルール 3（選択肢投げ返し）・ルール 6（翻訳禁止）・ルール 22（ゴール認識固定）。
