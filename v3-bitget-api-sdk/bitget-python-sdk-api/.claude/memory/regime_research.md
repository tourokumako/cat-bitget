## §1 regime 判定ゴール（合格基準）

| 項目 | 基準 |
|------|------|
| 出力粒度 | 1 時間程度（5 分足ボット運用要件・WORKFLOW §A） |
| 切替頻度 | 1 日複数回〜数日に 1 回 |
| 持続時間 | 2-3 時間以上（取引平均保有 60-130 分より長い） |
| 視認一致 | 1h chart 上の局面切替と判定切替が目視で揃う |
| 補助一致 | 1826 日肉眼ラベルとの日単位一致率 |

不採用基準:
- ❌ 月単位/週単位で固定される判定
- ❌ 5 分や 1 分で頻繁切替する判定
- ❌ 人間ラベルそのものを入力に使う仕組み（look-ahead）
- ❌ 「月単位人間判定との一致率」だけで採否判定

## §3 現行試作版（v3 仮採用）

スクリプト: [`scripts/regime_classifier_prototype.py`](../../scripts/regime_classifier_prototype.py)
出力先: `dashboard/regime_prototype/`

| 要素 | v3 の値 |
|------|--------|
| 上位 TF | 4h MA50 傾き（5 バー≒20h・±0.3% flat）+ 4h ADX14 ≥ 25 |
| 中位 TF | 1h MA20 傾き（10 バー≒10h・±0.2% flat）|
| 下位 TF | 15m DI+/DI-（差 1.0 超で方向確定）|
| 統合 | **上位 4h trend (ADX≥25) AND (1h 一致 OR 15m 一致) で trend 確定・それ以外は range** |
| ヒステリシス | 1 時間連続で同判定なら切替 |
| 出力粒度 | 1 時間ごと |

- 一致率: 1d 39.41% / 1h 38.87%（v2 比でほぼ横ばい）
- 分布: range 66.0% / uptrend 17.8% / downtrend 16.2%（人間ラベル分布 rg37.8/up32.8/dn29.4 に近づいた）
- 視認所見: 「v2 よりだいぶ良くなった」（まこさん）
- 仮採用ステータス: 視認 OK / 一致率横ばいのため v4 で押し上げ試行中

## §6 試行禁止リスト（regime 研究関連・現行有効分のみ）

- ❌ 月単位/週単位で固定される判定（5 分足運用に意味を与えない）
- ❌ 5 分や 1 分で頻繁切替する判定（取引を殺す）
- ❌ 人間ラベルそのものを入力に使う仕組み（look-ahead 問題）
- ❌ 「月単位人間判定との一致率」だけで採否判定（2026-04-28 までこれで 3 日間迷走）
- ❌ 経緯未把握での退路提案（L-127）
- ❌ 設計判断を感覚で進める（feedback_quantitative_comparison）
- ❌ HMM 特徴量に Funding Rate / OI / L-S Ratio を直接追加（L-134・5 回試行で全失敗）
- ❌ HMM 特徴量にボラ系を方向系と混合（L-134）
- ❌ K=2 採択（候補 B 不合格・上昇バイアス問題）
- ❌ 教師あり学習で ground truth に完全フィット狙い（L-129・30-40% 天井）
- ❌ 過去却下方針への退路提案（L-127）
- ❌ 判定軸マトリクスの未試行を残したまま「もう手はない」と撤退（feedback_exhaustive_search）

## §8 ダッシュボード仕様

### パスとファイル構造

```
dashboard/regime_prototype/
├── index.json                       # 試作版インデックス（バージョン一覧 + 月一覧）
├── predictions_v{N}_1d.json         # 日次集約（1827 行）
├── predictions_v{N}_1h.json         # 1 時間粒度（43,814 行）
└── predictions_v{N}_5m/<YYYY-MM>.json  # 5 分粒度・月別 60 ファイル
```

### タブ ⑪ レジーム試作

- バージョンセレクタ: `index.json` から自動構築
- 粒度切替: 5 分 / 1 時間 / 4 時間 / 1 日
  - 4 時間は 1h JSON からクライアント側集約
  - 5 分は重いので月選択必須
- 月フィルタ: 5 年分 60 か月（1d/1h/4h は「全期間」可）
- チャート: 上半分 = 肉眼ラベル / 下半分 = 試作版予測 の背景塗り
- KPI: 1d 一致率 / 1h 一致率 / 分布
- 日別テーブル: 1826 行・hourly 内訳付き・フィルタ対応

### 自動拡張仕様

新しい試作版を実行 →
1. `predictions_v{N}_*.json` が生成される
2. `index.json` に新エントリが追記される（既存 v{N} は置換）
3. ブラウザリロードで UI に新バージョンが選択肢として出現
- → JS 側の変更不要

## §10 既知リスク（L-126〜L-137 要点・必読）

- **L-126**: 月単位視認は補助 lens であって運用粒度の指示ではない
- **L-127**: 過去却下方針への退路提案禁止
- **L-128**: replay_csv.py 3 関数すべてに look-ahead バグ・SAFE 値で再評価必要
- **L-129**: 教師あり完全フィット狙いは 30-40% 天井
- **L-130**: 閾値はデータ駆動・mean/std を必ず先に提示
- **L-131**: 単体検証は 5-7 回・最大 15-21 回（**設計探索フェーズには適用しない** by feedback_exhaustive_search）
- **L-132**: 特徴量設計は冗長確認後に拡張
- **L-133**: WORKFLOW 既定タスク盲従禁止・上流前提を毎回疑う
- **L-134**: 異種特徴混合は HMM を支配する・方向系のみが原則
- **L-135**: HMM 安定性 (ARI) と分離度はトレードオフ・K=2 は候補 B 不合格
- **L-137**: 試行単位 = 完全レシピ・部品単独評価は廃止
