## §1 スキャルとは（定義・執行様式）

- **保有時間: 数秒〜数分が典型（1〜5分）。長くても数十分。**「保有4時間」はスキャルではない。
- **利幅: 小さい**。1回の狙いは小さく、その代わり回数で積む（small profits done many times）。
- **R:R（リスクリワード）: 1:1.5〜1:2 ＝勝ち側を大きく・損切りを浅く**。損切りが利確より深い形（E37 v9 の SL 2×ATR vs TP 0.5σ）はスキャルの逆。
- **頻度: 高品質なセットアップに限定して1日数件〜**。「大量」の意味は乱発ではなく「1件を小さく短く、確認の取れた場面だけで、毎日コンスタントに回す」こと。
- 常時監視前提の手法＝機械化（BOT）と相性が良い。ただし高コスト（手数料）がリターンを蝕むのが最大の敵（§6）。

## §2 レンジの正しい認識（何をもってレンジと言うか）

- **レンジ＝「価格がサポートとレジスタンスの間で繰り返し反応している状態」**。統計量（横ばい度・ADX 等）ではなく、**機能しているレベルの実績**で認識する。
- **レベルは1本の線でなくゾーン**（例: BTC $39,800〜$40,200 のような帯）。
- **機能実績の基準: 最低3回のタッチ**。タッチ（テスト）回数が多いほど強い。**近いピボット（スイング高値・安値）は1つのゾーンに束ねてタッチ回数を合算**する（孤立した1本ずつのピボット線を引かない）。
- **上位足で主要ゾーンを構築 → 下位足（5分）で執行**（多時間軸の黄金律）。ゾーンの信頼性は複数時間軸の整合と出来高で裏取りする。
- ⚠️ 「直近スイング高値・安値の間にいる」だけの判定（E35/E36 のフラクタル箱）は、タッチ実績の概念が無いためレンジ判定にならない＝上昇トレンド中でも常に直近高安の間にいる。

## §3 入口（レンジスキャルのエントリー）

- 手順: **①ゾーンに到達 → ②拒否（跳ね返し）の確認 → ③エントリー**。到達だけで入らない（確認なしの逆張りはダマシに轢かれる＝E37 v2 の型）。
- **拒否の確認材料**: 反転ローソク足パターン（ピンバー・エンガルフィング・ハンマー・シューティングスター）＋出来高＋モメンタム（レンジ相場の RSI は 70/30 が有効・5分足は RSI9）。
- **ショート＝レジスタンスゾーンで確認された拒否**。ロング＝サポートゾーンでの確認された反発（E37 はショートのみ＝上限ゾーンだけ使う）。
- 指値（maker）で入る場合もゾーン＋確認が前提（受け身の指値を全場面に置くのではない）。

## §4 出口

- **TP: レンジの反対側（ショートならサポート側）または中央**。手数料を超える幅が最低条件（§6）。
- **SL: ゾーンのすぐ外（浅い）**。「サポート/レジスタンスレベルの直下/直上」に置く＝レンジが破れたら即撤退する位置。スイングポイント超過に ATR 1〜2倍を目安にする流儀もあるが、核は「レベル基準で浅く」。
- **time-stop**: 勝ちセットアップが通常 X 分で最大収益に達するなら、それを大幅に超えて持たない（entry_exit_relationship_kb §time-stop と同旨・スキャルは分単位）。

## §5 レンジの終わり（破れの判定・いつ黙るか）

- 破れの判定3点: **①20期間平均を上回る出来高 ②境界を明確に超えた終値 ③複数時間軸での確認**。
- 破れたらレンジ戦略は**黙る**（トレンドの担当に譲る＝cat-bitget では下げトレンドは E32b の領分）。

## §6 失敗パターン（スキャルが負ける型）

- **高コスト**: 手数料・スプレッドがリターンを蝕む＝スキャル最大の敵。maker 前提・「幅 > 往復コスト」を建てる前に確認（TP 目標が往復手数料+滑りを超えない場面では建てない）。
- **リスク管理の欠如**: 損切りなし・深すぎる損切り（1発で数十回分の小勝ちを吐き出す）。
- **確認なしの逆張り**: 到達だけで入る・伸び切りを fade して継続に轢かれる。
- **レンジ判定なしの発火**: トレンド中の逆張り（上げ相場でのショート）＝そもそもレンジ戦略の前提外。
- **監視疲れ・乱発**: 高品質セットアップ以外に手を出す（BOT では「件数目標のための間口拡大」がこれに相当）。

## §7 E37 への対応表（cat_requirements §1.2.1 の言葉 ↔ 本 KB ↔ 実装のあるべき形）

| §1.2.1 の言葉 | 本 KB | E37 実装のあるべき形 |
|---|---|---|
| レンジ（横ばい）と判定した場面のみ | §2 繰り返し反応する S/R ゾーンの間 | タッチ実績（≥3回・ピボット束ね）のあるゾーンを上位足で機械検出し、上下ゾーンの間にいる時だけ入口を開く |
| ショートのみ | §3 レジスタンス拒否 | 上限ゾーン到達＋拒否確認で SHORT のみ（LONG 入口を作らない） |
| 長く持たず | §1/§4 保有1〜数十分・time-stop | 時間切れは分単位（60分 backstop 内） |
| net がプラスになる幅以上 | §4/§6 幅>往復コスト | TP 幅 ≥ maker 往復 0.028%＋α を建てる前に判定 |
| 小刻みに大量 | §1 高品質場面で数件/日〜 | 件数/日は一級基準。ただし乱発でなく「確認の取れた場面だけ」を回数で積む |
| E32b を邪魔しない | §5 破れたら黙る | レンジ破れ判定（出来高＋境界外終値）で停止＝下げトレンドを E32b に譲る |
| （逆 R:R の禁止） | §1/§4 勝ち側を大きく・SL 浅く | SL＝上限ゾーンのすぐ外（浅い）・SL 幅 < TP 幅 |
