## v3 — 2026-04-28（仮採用・視認改善・一致率横ばい）

### レシピ（5 要素全部）

| 要素 | 値 |
|------|-----|
| 上位 TF | **4h** MA50 傾き（5 バー≒20h・±0.3% flat）+ 4h ADX14 ≥ 25 |
| 中位 TF | **1h** MA20 傾き（10 バー≒10h・±0.2% flat）|
| 下位 TF | **15m** DI+/DI-（差 1.0 超で方向確定）|
| 統合 | **上位 4h trend (ADX≥25) AND (1h一致 OR 15m一致) → trend 確定・それ以外は range** |
| ヒステリシス | 1 時間連続で同判定なら切替 |
| 不一致時挙動 | range |
| 出力粒度 | 1 時間ごと |

### v2 → v3 変更点

- **統合ルールのみ変更**: 全層一致 AND → 上位 + 1 層一致 OR
- 期待効果: 3層 AND の確率的厳しさ (0.5^3=12.5%) → 上位+1層 (0.5*0.75=37.5%) で trend 検出感度↑
- 指標・ヒステリシス・出力粒度は v2 と同一

### 結果

| 指標 | v2 | v3 | 差分 |
|------|-----|-----|------|
| 分布 range | 88.1% | **66.0%** | −22.1pt |
| 分布 uptrend | 6.3% | **17.8%** | +11.5pt |
| 分布 downtrend | 5.7% | **16.2%** | +10.5pt |
| 一致率 1h | 38.9% | 38.87% | −0.03pt |
| 一致率 1d | 38.7% | 39.41% | +0.71pt |

理論予測（trend 比率 37.5%）に対し実測 34.0%・誤差 3.5pt 以内で予測通りの挙動。

### 代表期間 視認所見

- まこさん視認: 「v2 よりだいぶ良くなった」（2026-04-28）
- 分布が人間ラベル（dn 29.4% / rg 37.8% / up 32.8%）に近づいた（rg 88% → 66%）
- 一致率は実質横ばい → 視認改善は分布の正常化が主因

### 過去失敗との照合

- v1 「月単位/週単位固定」→ ✅ 該当しない（trend 比率 34% で固定なし）
- v2 「range 過剰 88%」→ ✅ 解消（66%へ低下）
- 第4軸（極端偏り 5%未満 or 80%超）→ ✅ 全 regime が範囲内

### 採否

**仮採用**（視認 OK / 一致率横ばいのため v4 で押し上げ試行）

### v4 への引継ぎ案

主要候補（要まこさん判断）:
- **C. ヒス延長 1h → 2h**（推奨・切替過多抑制と持続性向上が一致率に効く可能性高い）
- D. 4h ADX 閾値緩和 ≥25 → ≥20（trend 取りこぼし削減）
- E. 1h MA20 lookback 短縮 10 → 5（中位応答性↑）

### スクリプト/出力

- スクリプト: [`scripts/regime_classifier_prototype.py`](../../scripts/regime_classifier_prototype.py) (VERSION = "v3")
- 出力 JSON: `dashboard/regime_prototype/predictions_v3_*.json`
- ダッシュボード: タブ ⑪ → バージョン v3 を選択

## v2 — 2026-04-28（反復中・range 過剰）

### レシピ（5 要素全部）

| 要素 | 値 |
|------|-----|
| 上位 TF | **4h** MA50 傾き（5 バー≒20h・±0.3% flat）+ 4h ADX14 ≥ 25 |
| 中位 TF | **1h** MA20 傾き（10 バー≒10h・±0.2% flat）|
| 下位 TF | **15m** DI+/DI-（差 1.0 超で方向確定）|
| 統合 | 全層一致 → trend 確定・不一致 → range |
| ヒステリシス | 1 時間連続で同判定なら切替 |
| 不一致時挙動 | range（直前維持を廃止）|

### 結果

| 指標 | 値 |
|------|-----|
| 一致率 (1d) | 38.7% (707/1827) |
| 一致率 (1h) | 38.9% (17,071/43,814) |
| 分布 | range 88.1% / uptrend 6.3% / downtrend 5.7% |
| 切替頻度 | 高頻度（1 時間単位の chart 上で頻繁にストライプ模様）|

### 代表期間 視認所見

- **2024Q1 bull**: 3 月の上昇局面で uptrend が断続的に出現するが、間に range が頻繁に挟まる。trend 期間も range にされる過剰判定
- **2023 春 range**: 大半が range（実際の相場と合致）。3 月急騰部に uptrend bar が散在
- **2022Q2 bear**: 5-6 月の急落で downtrend が散在的に出現するが、range が支配的
- **2025-12 直近**: 12 月の上昇局面で uptrend が部分的に出るが、過半は range

### 過去失敗との照合

- v1 の「月単位/週単位固定」失敗の真逆方向に振れた
- range 88% は WORKFLOW §A の「月単位/週単位固定 = 不採用」とは別の問題（過剰 range は trend 局面取り逃しを生む）

### 採否

**反復中**（不採用ではない・修正余地あり）

### v3 への引継ぎ案

主要候補（要まこさん判断）:
- 統合を「全層一致 AND」→「上位 + 1 つ一致で trend 確定」に緩める
- ヒステリシスを 1h → 2h or 3h に延長（過剰切替を抑制）
- 4h ADX14 ≥ 25 → ≥ 20 に閾値緩和（trend 検出感度を上げる）

## v1 — 2026-04-28（不採用・月単位固定）

### レシピ（5 要素全部）

| 要素 | 値 |
|------|-----|
| 上位 TF | **日足** MA70 傾き（5 日 look-back・±0.5% flat）|
| 中位 TF | **4h** MA50 傾き（10 バー≒40h・±0.3% flat）+ 4h ADX14 ≥ 25 |
| 下位 TF | **1h** DI+/DI-（差 1.0 超で方向確定）|
| 統合 | 全層一致 → trend 確定・不一致 → 直前 regime を維持 |
| ヒステリシス | 2 時間連続で同判定なら切替 |
| 不一致時挙動 | 直前維持 |
| 出力粒度 | 1 時間ごと |

### 結果

| 指標 | 値 |
|------|-----|
| 一致率 | 未測定（視認時点で不採用確定）|
| 分布 | uptrend 50.1% / downtrend 45.5% / range 4.4% |
| 切替頻度 | 5 年間で 1〜2 回のみ（事実上四半期粒度）|

### 代表期間 視認所見

- **2024Q1 bull**: 3 か月すべて uptrend。1 月前半の $46k→$39k 下落も「uptrend」と判定（明確な誤り）
- **2022Q2 bear**: 4 月は明確に下落（$46k→$38k）なのに「uptrend」判定。5 月以降が downtrend
- **2023 春 range**: 3 か月すべて uptrend。実際の April-May レンジ（$27-30k）を完全に取り逃し
- **2025-12 直近**: 3 か月すべて downtrend。12 月の上昇局面（$86k→$97k）を逆方向判定

### 過去失敗との照合

- WORKFLOW §A の **不採用パターン「月単位/週単位で固定される判定」に直撃**
- L-126〜L-128 で散々警告されていた「日足 MA70 主軸では 5m 足ボット運用に意味を与えない」を再現

### 採否

**不採用**（構造的失敗）

### 構造的原因

1. 日足 MA70・5 日傾きは本質的に四半期トレンド指標（70 日 MA・5 日傾き）
2. 「全層一致 AND」+「不一致 → 直前維持」が固定を強化
3. 一度 trend 確定すると、その逆方向の明確な動きでも「直前維持」で維持される
4. range が出る隙が無い（4.4% は初期 warmup 期間のみ）

### v2 への引継ぎ

- 上位を日足 → 4h に変更（粒度を四半期 → 数週間に下げる）
- 不一致時挙動を「直前維持」→ 「range」に変更（range が自然に出るように）
- ヒステリシス 2h → 1h に短縮（応答性向上）

- 旧スクリプト状態: VERSION = "v1" 時の `regime_classifier_prototype.py`
