- 指標・ヒステリシス・出力粒度は v2 と同一

理論予測（trend 比率 37.5%）に対し実測 34.0%・誤差 3.5pt 以内で予測通りの挙動。

### 代表期間 視認所見

- まこさん視認: 「v2 よりだいぶ良くなった」（2026-04-28）

### 採否

**仮採用**（視認 OK / 一致率横ばいのため v4 で押し上げ試行）

### 結果

| 指標 | 値 |
|------|-----|

| 分布 | uptrend 50.1% / downtrend 45.5% / range 4.4% |
| 切替頻度 | 5 年間で 1〜2 回のみ（事実上四半期粒度）|

### 代表期間 視認所見

- **2024Q1 bull**: 3 か月すべて uptrend。1 月前半の $46k→$39k 下落も「uptrend」と判定（明確な誤り）
- **2022Q2 bear**: 4 月は明確に下落（$46k→$38k）なのに「uptrend」判定。5 月以降が downtrend
- **2023 春 range**: 3 か月すべて uptrend。実際の April-May レンジ（$27-30k）を完全に取り逃し
- **2025-12 直近**: 3 か月すべて downtrend。12 月の上昇局面（$86k→$97k）を逆方向判定

### 過去失敗との照合

- WORKFLOW §A の **不採用パターン「月単位/週単位で固定される判定」に直撃**
- L-126〜L-128 で散々警告されていた「日足 MA70 主軸では 5m 足ボット運用に意味を与えない」を再現

### 採否

**不採用**（構造的失敗）

### 構造的原因

1. 日足 MA70・5 日傾きは本質的に四半期トレンド指標（70 日 MA・5 日傾き）
2. 「全層一致 AND」+「不一致 → 直前維持」が固定を強化
3. 一度 trend 確定すると、その逆方向の明確な動きでも「直前維持」で維持される
4. range が出る隙が無い（4.4% は初期 warmup 期間のみ）

### v2 への引継ぎ

- 上位を日足 → 4h に変更（粒度を四半期 → 数週間に下げる）
- 不一致時挙動を「直前維持」→ 「range」に変更（range が自然に出るように）
