# 6. A6 — 「段ごとに絞る」形が捨てているものが、致命的でないか

## 6-1 答え

**致命的ではありません。実務上ありうる割り切りです。** ただし条件が1つあります。

## 6-2 ①この割り切りは致命的か

**致命的ではありません。** 理由は、外の標準が「段ごとに絞ること」を禁じていないためです。

- Guyon の検査項目8 の逐語＝"Do you know what to try first? If no, use a linear predictor. **Use a forward selection method**"。**＝最初にやることとして推奨されています。**
- 禁じられているのは「戻る段を永久に作らないこと」です。Pudil ら (1994) はこれを **nesting effect** と名付けました。逐語＝"in the case of the 'top down' search the discarded features cannot be re-selected… The result is that the methods are only **suboptimal**."（https://library.utia.cas.cz/separaty/historie/somol-floating%20search%20methods%20in%20feature%20selection.pdf ）

## 6-3 ②致命的でないとして、この工事の中で何をすべきか

**2つです。どちらも作業量は小さいです。**

1. **落とした候補の一覧と、落とした理由を残すこと。** 設計書は既にそう書いています（`law_check`・`dropped_by`・「落ちた候補も一覧から消しません」）。**これは そのまま残してください。** 段4（差し戻し）を後から作るときの材料になります。
2. **「拾い直す段（段4）を次の工事で作る」と設計書に明記すること。** 設計書 §3-1 の1 は「段4 と段5 を作らない」と書いていますが、**「いつ作るか」が M2-F〜M2-K と幅で書いてあります。** 番号を1つに決めて書いてください。

## 6-4 ③外の標準と照らして（差し戻しの代わりになるもの）

**業界には、段を全部やり直さずに拾い直す方法が4つあります。** どれも「段1 の結果を残しておけば、後から足せる」ものです。

| やり方 | 何をするか | 出典 |
|---|---|---|
| **ISIS（反復スクリーニング）** | 残差に対して、もう一度 単独の絞り込みを掛ける | Fan & Lv "we propose below an ISIS to enhance the methodological power"（https://arxiv.org/pdf/math/0612857 ） |
| **SFFS（floating search）** | 段を進めたあと、条件つきで段を戻す | Pudil ら "By means of conditional 'floating down and up' both the methods are freely allowed to correct wrong decisions made in the previous steps" |
| **stability selection** | 部分標本を何度も取り、選ばれ方の安定性を見る | Meinshausen & Bühlmann (2010) JRSS-B 72(4):417-473（https://arxiv.org/pdf/0809.2932 ） |
| **組み合わせた項を先に作る** | 交互作用を疑うなら、組んだ項を候補として最初から並べる | Guyon 検査項目3 "Do you suspect interdependence of features? If yes, expand your feature set by constructing conjunctive features or products of features" |

**★Fan & Lv は、この設計の段1 とまったく同じやり方（単独の相関で先に絞る＝SIS）の弱点も書いています。** 逐語＝"an important predictor that is marginally uncorrelated but jointly correlated with the response can not be picked by SIS and thus will not enter the estimated model"。
