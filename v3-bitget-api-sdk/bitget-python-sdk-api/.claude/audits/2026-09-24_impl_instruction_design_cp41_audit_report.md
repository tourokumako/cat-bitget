- 等級の選び方＝"be conservative when choosing the level"

URL: https://rustc-dev-guide.rust-lang.org/diagnostics.html

- 確かめる処理は当てる側が持つ＝"Your patch harness is responsible for interpreting the V4A diff format and applying changes"
