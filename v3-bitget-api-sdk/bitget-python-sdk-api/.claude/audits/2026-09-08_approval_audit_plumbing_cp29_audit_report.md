# 4. b51 の判定の裏返しは妥当か（依頼書 §3 の問い）

## 4-1 判定＝妥当です

**理由**＝ほかの11本の相手は「落ちることで守る検査」ですが、**b51 の相手は「通さないことで守るゲート」です。**守りを消すと、検査が落ちるのではなく、**通ってしまいます**（終了コードが 0 になります）。裏返さずにそのまま返すと、承認の道具は「壊しても落ちなかった」と読み、**穴が開いたのに『壊せていない』という逆の結論**になります。

**裏返しの向きも正しい**＝ゲートが通した（穴が開いた）＝1 ／ ゲートが止めた（穴が開いていない）＝0。承認の道具は「0 以外」を「壊すと落ちる」の証拠にするので、噛み合っています。

**この向きが本当に成り立つことを、監査が実測しました**＝P1（守りが在る＝ゲートは 2 で止める＝b51 は 0）と、b51 の本走（守りを消す＝ゲートは通る＝b51 は 1）。**＝この入力で b51 が 1 になる道は、守りを消したときだけです。**

**記録には、裏返しの向きが1文字も残りません。**
`<iter>.breaks.json` の #12 に残るのは `"code": 1` だけです。`run_breaks.py` はそれを **「✅ 止まった」** と表示します（同 .py の 303行＝`code not in (0, None)` なら「止まった」）。
