## 監査観点 (本監査固有・Q-A・Q-B)

### Q-A — net を上げる根拠が在る決まりはどれか（★主題・外部検索必須）

法則 R1〜R10・C1〜C10（`regime_detection_kb.md` L698-722）の**20件それぞれ**について、**「レンジ判定のふるいとして使うと net（または勝率・期待値）が上がる」という根拠が外の本文・研究に在るか**を1件ずつ断言する（在る＝出どころの URL と逐語／無い＝無い）。**一覧に無いが根拠のある決まり**が在れば挙げる。**根拠が「一覧に載っている」「正本に書いてある」だけのものは「根拠なし」と数える。**U・D・S・T の30件は、レンジの判定に関係する行だけ拾えばよい（全部は問わない）。

### Q-B — 材料で書けるか

事実データ3の材料（ta 43種 ＋ 法則の名指し）で、Q-A で「根拠あり」となった決まりを engine_tuner が条件として書けるか。**書けない決まりは、どの部品が要るか**（★一例の定数を持ち込む形でなく、「何を測る部品か」の形で）。あわせて、**いまの成績表の札（「強さ」＝ER の中央値）が、根拠ありの決まりで材料を選ぶ根拠になるか**を断言する。
