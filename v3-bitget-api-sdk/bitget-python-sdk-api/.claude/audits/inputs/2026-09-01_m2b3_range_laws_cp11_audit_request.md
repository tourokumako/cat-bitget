## 監査観点 (本監査固有・Q1-Q3)

### Q1 — 抜け（無い法則）

レンジ相場の判定（range regime detection）について、**業界・文献で確立している法則のうち、10件・共通 C1〜C10・既知の穴9件のどれにも無いもの**を挙げる。1件ごとに ①法則の一文（日本語） ②出どころ（本文を開いた URL か書名・逐語1つ） ③どの指標・部品で測るか を付ける。**出どころを開けなかったものは挙げない**（【要約】級は「要裏取り」と明記して分ける）。

### Q2 — 誤り（違う記述）

10件の一文と説明（L813-L869）を1件ずつ、出どころ（説明に書いてあるファイル・記事）と突き合わせ、**事実と違う記述・出典と食い違う記述・出典の帰属違い**を挙げる。1件ごとに「どの行の どの記述が、何と食い違うか（出典の逐語）」を付ける。数字の目安（ADX 20・CHOP 61.8 など）は「探す範囲の目安」であって固定値ではない（C9）＝目安の数字そのものの妥当性は誤りの対象にしない。

### Q3 — 重複（同じことを言っている対）

10件の中、および共通 C1〜C10 との間で、**同じことを言っている対**を挙げる。1対ごとに「どこが同じで、どこが違うか」を1行ずつ書き、**まとめる案（どちらに一本化するか）か、残す理由**を付ける。参考＝R3 と C4 は近い（C4＝上位足の部品が1本／R3＝ゾーン〔構造・位置〕が上位足）。R6 と R10 は同じ「ばらつき」の軸を見る（2026-08-30 の実データの順位相関＝worklog 20260830 §7（1））。これらを重複と裁定するかは監査の判定に任せる。
