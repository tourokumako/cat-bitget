### Q1 — 条件の形の一覧（11種）は過不足がないか

R3 の設計は、持たせる条件の形として **水準／帯／抜き帯／傾き／傾きの平均／クロス／連続／過去N本以内／差の量／タッチ／ローソクの向き** の11種を挙げている。

- **レンジのスキャルに必要な形で、この11種に無いものはあるか。** 一覧の出どころは V9（下げトレンドの SHORT）なので、担当する相場が違うことによる抜けを疑うこと
- **不要な形はあるか。** 探索空間を増やすだけで E37・E38 の役割では使われない形があるなら指摘せよ
- **★前回 CP1 監査は「4部品（環境認識／トリガー／十分性／位置）に分ける」枠組みを前提に、部品の中身の過不足を指摘した（提案6）。今回の R3 書き直しで、その枠組みは維持されているか、前提から変わったか。変わったなら CP1 の提案6 は今も有効か**

### Q2 — 条件のつなぎ方（3種）で足りるか

全部満たす／どれか満たす／入れ子 の3つ。

- この3つで、レンジのスキャルに必要な条件の組み立てが表現できるか
- **入れ子の深さに制限は要るか。** 制限しないと探索空間が爆発する。制限するなら何段までか、根拠は何か
- 業界標準のルールベース戦略の記述の枠組み（DSL・決定木・遺伝的プログラミング）と比べて十分か、過剰か

### Q3 — 出口の枝の一覧（11種）は過不足がないか。閉じた枝を再提案していないか

R13 の設計は、持たせる枝として **固定の利確／段階決済／損切り／時間切れ／時間切れの係数／建値待ち／ピークの停滞／ピークからの戻り／複合の枝／トレーリング／前提崩れ** の11種を挙げている。

- **★データ4 のとおり、E37 は「守りの枝の単独セルは実測で筋が閉じた」（L-334）と結論している。ピークの停滞・ピークからの戻り・トレーリングはその閉じた枝に含まれる。** R13 はこれを候補に残し、設計の中で「入口とセットで動かす」という条件を付けている。**この条件付けは、閉じた実測を回避する根拠として十分か。それとも同じ失敗の再演か**
- **トレーリングは両窓で符号が反転すると実測されている。** 候補に残す判断は妥当か
- レンジのスキャルの出口として、この11種に無いものはあるか
- **★データ4 で「次に筋のある組」と名指しされているクールダウン（機械退出後 N 本は再エントリー禁止）が、R3 にも R13 にも R14 にも入っていない。** 入口と出口の結合部の軸である。**入れるべきか。入れるならどの要件か**

### Q4 — R14（玉の持ち方）を要件にする判断は妥当か

- 平均建値の積み増しと、別々の玉として持つ形の両方を選べるようにする判断は妥当か
- **R13 の「枝が積み増しの回数で切り替わる」は、R14 が先に決まらないと成立しないと設計は主張している。この依存関係は正しいか**
- 予算 0.12 BTC が全採用戦略の共有枠であることと、積み増しの上限を探索の対象にすることは矛盾しないか

### Q5 — 探索空間が桁で増えることへの対処が設計に含まれているか

- **増加量を概算で示せ。** クロスと差の量は2本の列の組なので、同一時間足の中に限っても組は数万になる
