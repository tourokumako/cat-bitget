### Q6 目的に対して有効か — **業界の最下層（参照の存在確認）にとどまる**

**位置づけ（外部の分類に照らして）**

- テストの用語では、名前の存在確認は **weak assertion（弱い表明）**である。EvoSuite の論文は weak assertion を「**満たすのが容易で、対象が誤った振る舞いをしても何のエラーも起こさない**」と定義し、対処として **mutation analysis で weak assertion を捨てる**ことを示す。**今回の照合は、この定義に完全に当てはまる。**

**方向そのものは業界と合っている。**「**プロンプトだけの決まりは提案にすぎず、実行前に止める hook だけが上書きできない強制になる**」（AWS）。**まこさんの判断を変える必要はない。**
