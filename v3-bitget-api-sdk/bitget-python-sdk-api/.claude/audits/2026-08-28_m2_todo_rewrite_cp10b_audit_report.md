### 2-4 ★誤り2の前提｜`S-Rタッチ数` は「跳ね返り」を1度も数えていない

**実物＝`observe_diag.py` の 363-371行。逐語をそのまま貼ります。**

```python
def _sr_touch(c, h, l, win=288, tol=0.003):
    """いまの価格帯に、窓内で何回タッチしているか。"""
    out = np.full(len(c), np.nan)
    ca, ha, la = c.to_numpy(), h.to_numpy(), l.to_numpy()
    for i in range(win, len(ca)):
        lvl = ca[i]
        band = lvl * tol
        out[i] = int(((ha[i - win:i] >= lvl - band) & (la[i - win:i] <= lvl + band)).sum())
    return pd.Series(out, index=c.index)
```

- **水準は「いまの終値」**（`lvl = ca[i]`）＝構造から見つけた線ではありません。
- 数えているのは **「過去 win 本のうち、その足の値幅が いまの終値の帯と重なった本数」**。**通り抜けた足も1本と数えます。**
- **＝「跳ね返された（bounce）」を1度も数えていません。上下の対でもありません。**
- **＝R1（跳ね返された線が上下に在る）の代理ですらなく、R12（跳ね返り回数）でもありません。**測っているのは「いまの価格の近くで、過去にどれだけ時間を過ごしたか」です。
