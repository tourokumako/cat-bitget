## A. ヘッダ（hook が物理強制・無いと Write ブロック）
- ☐ 【群1】 `TARGET: scripts/priority_rebuild/<1ファイル>.py`（編集する実体1ファイル。複数ファイルに跨るなら分割 or 主ファイル＋やることに明記）
- ☐ 【群1】 `DESIGN_CONTRACT`（fenced json）= `impl_file` / `self_check_calls`（実装ソースに文字列で在る識別子）/ 必要なら `must_combine`
- ☐ 【群1】 **★新しくファイルを作るときだけ足す2行（2026-08-27・まこさん承認「進めて良い」・86番の直し）**＝`NEW_FILE: <新しく作るファイルのパス>`（カンマ区切りで複数可）と `MODEL: <手本にしたファイルのパス>`（カンマ区切り・1本以上）。**これを書くと、必読ゲートの A の検査が「その相手を開いたか」から「手本を開いたか」に変わる**（新しいファイルは存在しないので開けないため）。**★新規と書いたのに実在すると止まる**（宣言が嘘）。**★`TARGET:` の行の書き方は変えない**（その行を読む仕組みが5本 在るため）。**★見本を囲み（```）の中に書くときは、行の頭に空白を入れる**（囲みの中も宣言として読まれる＝113番）
