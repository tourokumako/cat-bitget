⑬ レジーム持続分布（連続区間長 run-length）

既存ラベルの「同一ラベルが連続するバー数 × 粒度」を時間単位で集計。
A: 4h 教師ラベル（まこさん肉眼・2022-2025） / B: v14 自動ラベル 1h（5年）。
run 定義: 時系列順で連続する同ラベル + timestamp 間隔=粒度（4h or 1h）。空ラベル/時間飛びは run 区切り。

ヒストグラム（持続時間 bin × run 数）

A. 4h 教師ラベル
B. v14 自動ラベル 1h
📖 ヒストグラム視認ガイド
・横軸 = 持続時間 bin（≤4h / 4-8h / ... / 1-2w / 2w-1M / >1M）
・縦軸 = その bin に入る run 数。ラベル絞り込みで UP/DT/RG/全体を切替
・「短い区間支配」: 左端（≤4h・4-8h）が高い山・右側がほぼゼロ
・「長い区間支配」: 12-24h〜2-3d に山・右側に尾を引く
・「二峰性」: 左端と中央に両方山 → 短期ノイズ + 長期 regime 混在
・4h 教師 vs v14 1h 比較で分かること：
  同じ形 → ラベル粒度に依存しない実構造（regime は本物）
  v14 が左寄り → 自動判定が短期切替を過剰検出している
  4h 教師の ≤4h 山が低い → 教師は「最低 1 日」を暗黙設定の可能性
判定基準（Frame 1: 単一ラベル方式の限界）:
  median 時間〜日オーダー → Frame 1 撤回（単一ラベル方式は妥当）
  median 分〜時間未満オーダー → Frame 1 有効（限界論復活）
