## §1 regime 判定ゴール（合格基準）

| 項目 | 基準 |
|------|------|
| 出力粒度 | 1 時間程度（5 分足ボット運用要件・WORKFLOW §A） |
| 切替頻度 | 1 日複数回〜数日に 1 回 |
| 持続時間 | 2-3 時間以上（取引平均保有 60-130 分より長い） |
| 視認一致 | 1h chart 上の局面切替と判定切替が目視で揃う |
| 補助一致 | 1826 日肉眼ラベルとの日単位一致率 |

不採用基準:
- ❌ 月単位/週単位で固定される判定
- ❌ 5 分や 1 分で頻繁切替する判定
- ❌ 人間ラベルそのものを入力に使う仕組み（look-ahead）
- ❌ 「月単位人間判定との一致率」だけで採否判定

## §3 現行試作版（v5・判定器逆算フェーズ）

スクリプト: [`scripts/regime/regime_inverter.py`](../../scripts/regime/regime_inverter.py)（VERSION = "v5"）
出力先: `dashboard/regime_prototype/predictions_v5_*.json`

| 要素 | v5 の値 |
|------|--------|
| 学習方式 | RandomForestClassifier(n_estimators=300, max_depth=4, class_weight="balanced") |
| 特徴量 | close_vs_ma20, close_vs_ma50, slope_4b, slope_8b, slope_12b, slope_ma20_5b, slope_ma50_5b, adx14, di_diff, rsi14（10種） |
| 学習解像度 | 4h（特徴量計算・学習・推論すべて 4h）|
| 推論展開 | 4h 予測を 1h に ffill 展開（L-141: スケール統一が重要）|
| ヒステリシス | 2 バー（8h）連続で同判定なら確定 |
| 教師データ | `data/regime_samples_4h.csv`（2025年 731バー） |
| CV 方式 | 区間単位 5-fold（同区間の隣接バーが train/test に混在しない）|

結果（2026-04-28 時点）:
- **2025年サンプル一致率: 63.7%**（目標 70%）
- CV 精度: 51.0%（2025年のみ学習では汎化が弱い）
- 分布: 1h 全期間 up/dn/rg 各 ~~%（タブ⑪で確認可）
- 視認所見: まこさん「６割くらいは合ってる感じ・もう少し調整したら使えるのでは」

次の反復方針（他年サンプル追加による CV 向上):
- まこさんがタブ⑫（年選択 2022〜2025）で他年の代表区間をラベル付け
- `regime_inverter.py` v6: 多年教師データで再学習 → CV 向上・一致率 70% 達成を狙う

詳細は [`regime_trial_log.md` §v5](regime_trial_log.md) 参照。

## §4 試行錯誤の操作要素（5 要素・全部変更対象）

| # | 要素 | 取り得る選択肢例 |
|---|------|----------------|
| 4-1 | 時間軸の組み合わせ | 5m / 15m / 30m / 1h / 4h / 6h / 12h / 1d から各層に割り当て |
| 4-2 | 指標 | MA系 / ADX系 / モメンタム系 / ボラ系 / 出来高系 / 外生（Funding/OI）|
| 4-3 | 統合ルール | 全層一致 AND / 多数決 / 重み付け / 階層型（上位優先）|
| 4-4 | ヒステリシス | 1h / 2h / 3h / 6h（持続条件）|
| 4-5 | 不一致時挙動 | range に落とす / 直前 regime を維持 / 不明（=Priority 全停止）|

> 1 反復で変更するのは原則 1〜数要素。同時に多数変えると効果分離不可。
