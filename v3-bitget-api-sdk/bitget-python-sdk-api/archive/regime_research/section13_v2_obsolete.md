### Step 1. 教師ラベル特徴分析（初回のみ）

**目的**: まこさんがラベル付けした up/dn/rg のバーで、各種指標がどういう値になっているかを**網羅的に**分析する。「どれを使うか」の絞り込みはここではしない。分布の事実だけを記録する。

#### 1-1. 分析対象の指標カテゴリ

カテゴリ 1〜7 を **すべて** × **時間軸 5m/1h/4h/1d** で計算する。
（カテゴリ 8〜9 は 1〜7 で足りなければ追加）

| # | カテゴリ | 中身の例 |
|---|---------|---------|
| 1 | トレンド系 | 移動平均(SMA/EMA)・MACD・Ichimoku・SuperTrend |
| 2 | モメンタム系 | RSI・Stochastic・Williams%R・ROC・CCI |
| 3 | ボラティリティ系 | ATR・Bollinger Bands・Keltner Channel・標準偏差 |
| 4 | 方向性強度系 | ADX・DMI（DI+/DI-差） |
| 5 | 出来高系 | 出来高そのもの・OBV・VWAP・MFI |
| 6 | プライスアクション系 | 高値/安値更新頻度・連続陽線/陰線本数・ローソク足パターン・ヒゲ長 |
| 7 | 価格位置系 | EMAからの乖離率・ピボット位置・直近高値/安値からの距離 |
| 8 | 統計系（後回し） | Hurst指数・自己相関・標準偏差・歪度 |
| 9 | 変化点検出系（後回し） | Change Point Detection・PELT・Bayesian Online CPD |

**多時間軸は外せない軸**として常に組み込む（5m/1h/4h/1d 全部で計算）。

#### 1-2. 分析の進め方

1. 各指標 × 各時間軸の値を、教師データ 4,745バー（2022〜2025）について計算
2. ラベル(up/dn/rg)ごとに値分布を出す:
   - 中央値・四分位（Q1/Q3）
   - ヒストグラム（matplotlib で画像保存）
3. 結果から各ラベルの特徴を言語化:
   - 「uptrend は RSI(14)・1h が中央値 X / 範囲 Y〜Z」のように
   - 各ラベルを1段落で記述

⚠️ **ここで「効く指標」「使えない指標」の絞り込みをしてはいけない。**
分布の記録と言語化だけ行い、判断はすべて Step 2 に持ち越す。

#### 1-3. 出力先

- `results/regime_research/`
  - `single_indicator_distribution.md`（各ラベルの指標分布表）
  - `label_definition.md`（各ラベルの言語化定義）
  - `charts/`（ヒストグラム画像）

※ `effective_indicators.md` は廃止。指標選定は Step 2 で行う。

#### 1-4. STOP

各カテゴリの結果を順次まこさんに提示 → 確認 → 次カテゴリへ。
全カテゴリ終了時に分布サマリを提示 → GO 待ち。

### Step 2. 判定ロジック設計

**目的**: Step 1 の分布データを根拠として、判定ロジックを設計する。**絞り込みはここで初めて行う。**

1. Step 1 の分布データを読み返す
2. 「ラベル間で分布が大きく違う指標」を明示し、採用候補に挙げる
   - 採用根拠には必ず【データ確認済】ラベルを付ける
3. 「ラベル間で分布が混ざっている指標」は除外候補にする
   - 除外根拠も同様に【データ確認済】で記述する
4. 採用候補指標の組み合わせで判定ロジック（条件式・閾値）を設計する
5. 設計したロジックを提示 → GO 待ち ← STOP

---

### Step 3. 検証

**目的**: 仮説をデータで裏取りする。

1. 仮説の成立例・反例を過去データから抽出
2. 「うまくいくケース」と「失敗するケース」の指標分布を比較
3. pandas で per-bar 集計して定量化（経験値・推測は禁止）
4. 判断材料の候補（指標・パターン・閾値範囲）を確認する

各候補に **根拠ラベル** を付ける:
- 【データ確認済】: 過去データで検証した結果に基づく
- 【参考値】: 文献・他案件の経験から借りた仮の値（未検証であることを明示）
- 【未検証・要検証】: 根拠なし・実装前にデータで確認が必要

→ 結果提示して GO 待ち ← STOP
