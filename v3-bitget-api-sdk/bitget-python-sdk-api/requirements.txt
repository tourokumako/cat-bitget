# ★なぜ版を固定するか
#   pandas と numpy の版が変わると、指標の計算結果が変わり、過去の売買記録・net の数字が全部 変わります。
#   ですからライブラリを足すときは、必ず恒等3本（S1・L1・S2 の売買記録の md5）が不変であることを確かめます。
#     python3 scripts/priority_rebuild/engine_tuner_exec.py --identity      # S2  165行 7b01f51b5a9b29b3c05a7b340c203ba1
#     python3 scripts/priority_rebuild/engine_tuner_exec.py --identity-l1   # L1  367行 96a9102ec8a34f94cf01e9e463f6aade
#     python3 scripts/priority_rebuild/engine_tuner_exec.py --identity-s1   # S1 6569行 18b3d31a5fe71c4a4b5f83cf1771a46c
#   md5 が1本でも変わったら、そこで止めてまこさんに出します（勝手に進めません）。
#
# ★入れ方（2026-08-09 実測の環境）
#   python 3.13.3（Homebrew）。この python は PEP 668 の「外部管理」扱いなので、pip はそのままでは入れられません。
#   既存のライブラリは全部 /usr/local/lib/python3.13/site-packages に入っています。同じ場所へ入れるには次の形です。
#     python3 -m pip install --break-system-packages -r requirements.txt
#   入れる前に、何が動くかを必ず先に見ます（--dry-run を付けると、実際には入れずに結果だけ出ます）。
#
# ★版はすべて 2026-08-09 に実際に入っている版を機械で読み取ったものです（手で書いた数字ではありません）。
